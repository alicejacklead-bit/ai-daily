早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 14 日，星期五。先给你今天的这一句话：LangChain 以 30 亿美元估值融资 3 亿，说明资本市场愿意为“Agent 的中间层”买单；而视频生成赛道今天真正有价值的信号，藏在排行榜数据里——原生音频已成标配、开源权重模型进入前三，API 平台的竞争维度，正在从“有没有模型”转向“每秒多少钱”。
今天咱们重点聊三块：一是 LangChain 这笔融资和它背后的估值逻辑，二是黄仁勋离职之后，AI 一级市场正在发生什么，三是最重要的，视频生成横评和 OpenRouter 那七款模型的调价，我会把数字给你讲透。Agent 那边，ChatGPT Wallet 上线，Agent 真的能替你付钱了，这个咱们也会展开说。
先看市场局势。
第一条，LangChain 完成了 3 亿美元的 C 轮融资，估值 30 亿美元，领投方是 Alphabet 旗下的 CapitalG。官方披露了一个数字，我觉得比估值本身更值得记：LangSmith，也就是他们那个模型与平台无关的 Agent 管理和观测工具，已经有 7,000 家客户。你注意这里的关键词是“模型与平台无关”，LangChain 把这句话当成核心卖点在讲。这说明什么？说明 Agent 基础设施层终于有了一个明确的估值锚点，而且市场认可“不被单一模型锁定”这件事本身有价值。对任何做模型分发的平台来说，这都是一个正面信号——客户不想被锁死，聚合和路由这一层就有独立存在的理由。如果你和做 Agent 平台的朋友聊到这件事，可以问问他怎么看“Agent 平台层最后会不会被模型厂商吞掉”，LangChain 赌的就是不会被吞，但这个赌注能不能成立，其实没人敢打包票。
第二条，黄仁勋离职的连锁反应，开始波及 AI 创业融资了。TechCrunch 采访了多位 VC 和创始人，说法比较一致：黄仁勋在任期间，Nvidia 向 AI 创业公司投了数百亿美元，他离任之后，创始人和投资机构正在为“更小的支票和更低的估值”做准备。以色列的 VC 也在评估挑战者的机会。另外华尔街日报有一个更深层的报道，说黄仁勋离职的原因，可能更多指向 Nvidia 的风险业务实践，包括为云厂商的芯片采购提供数十亿美元的财务担保，其中还包括一项计划中的 2,500 亿美元的 OpenAI 交易。这件事为什么重要？因为 AI 一级市场少了一个“锚定投资人”，短期内会直接压低融资节奏和估值，对靠融资输血的模型公司和视频生成创业公司，影响是很直接的。同时 Nvidia 这种给客户做担保的模式被拿出来审视，算力采购的金融结构可能会收紧。你跟创始人聊天的时候，可以问一句：“你们这一轮的 term sheet 里，有没有投资人开始把 Nvidia 这个变量写进风险条款了？”这个问题问出来，基本就能看出对方对市场的判断在哪个层次。
第三条，这个有点敏感，但你必须知道。前 OpenAI 研究员 Will DePue 称，他通过读取公开模型权重里的芯片特征签名，首次给出了技术证据，指 DeepSeek、Moonshot AI、MiniMax 和蚂蚁集团在使用 Nvidia 最新的 Blackwell GPU。他估算这五次训练跑背后的硬件成本超过 5 亿美元。如果这个方法站得住，那出口管制的执行逻辑就会从“卡硬件”转向“查模型指纹”，中国模型公司的算力叙事和合规风险都要重新评估。对做海外分发的中国模型 API 平台来说，这是一个需要提前想好说法的风险点，别等客户来问才临时组织语言。技术上你可以抛一个问题出去：“从权重里读芯片指纹，这个方法的假阳性率你觉得能压到多低？”这是很好的技术谈资，也显得你不是只看新闻标题的人。
接下来是今天最核心的部分，赛道深挖。
第一条，MarkTechPost 发布了截至 11 月 13 日的视频生成模型排名。它的质量信号用的是 Artificial Analysis Video Arena 的盲测人类偏好 Elo，同时把 API 每秒价格和是否开放权重列在同一张表里。核心结论有三个：第一，原生音频从一年前的差异化卖点，变成了入场券；第二，主流片段时长拉到了 15 到 30 秒；第三，有一款开源权重模型进了前三。对以视频模型为主的 API 平台来说，这意味着三件事。第一，“带音频”不再是溢价理由，你的定价必须按秒对齐，客户会拿这个当基准来砍价。第二，15 到 30 秒的时长，改变了单次调用的成本结构，以前按 5 秒片段算的账，现在要重算。第三，也是最狠的，开源权重进前三，会直接压制定价天花板，闭源模型靠质量收溢价的窗口正在收窄。如果你和做视频平台的朋友聊到这件事，可以问问他：“原生音频变成 table stakes 之后，你们下一个愿意为之加价的维度是什么？”是时长、是可控性、还是一致性？这个问题其实很难答，但答案决定了他们明年的产品路线。
第二条，OpenRouter 主力模型表上，七款模型同时调价，涨跌分化非常明显。我念几个关键数字，你感受一下。DeepSeek V4 Pro，输入从每 token 0.00000095526 美元降到 0.0000009，输出从 0.00000191052 降到 0.0000015。DeepSeek V4.1 Flash 降得更狠，输入从 0.00000015 降到 0.000000038，差不多是打了二五折。DeepSeek Chat 输入降了，但输出从 0.00000089 涨到 0.0000010287。反向变动的是 Kimi K3.1 Pro，输入从 0.0000002375 涨到 0.000002，差不多 8.4 倍，输出从 0.0000084114 涨到 0.00001。另外 Gemma 4 26B、MiniMax M2.5、Qwen3.5-9B 也有小幅调整。这件事的意义在哪？聚合平台的价差，是模型厂商真实定价策略的一面镜子。DeepSeek 系继续往下探，Kimi 大幅上调，说明中国模型在海外 API 市场已经分层了：一方打价格战抢调用量，一方靠能力定位提价。做视频模型 API 的完全可以参照这个分层逻辑，去设计自己的档位——你是要做那个按秒压价的，还是做那个按能力收溢价的，得早点想清楚。跟人聊天的时候可以问一句：“Kimi 输入价涨 8 倍，你觉得是能力自信还是渠道策略？”这个问题挺有意思，因为答案往往两者都有。
第三条，MiniMax 开放平台的定价页做了重构，明确“按量付费加音频套餐”双轨，Starter、Standard、Pro、Scale、Business 各档包含不同的月度音频点数额度，价格都以美元计，页面同时保留了 H3 系列旗舰模型的入口。这是把语音和音频能力，从按 token 计费往“订阅套餐加点数”迁移的动作。它和视频生成平台正在做的套餐化是同一个方向。对高频调用方来说，套餐制比纯按量更容易锁定留存，但也提高了比价的难度——客户算不清单价了。你可以和朋友聊：“音频按点数打包，是不是在为多模态 bundle 定价做铺垫？”如果音频、视频、文本最后都打包进一个套餐，那 API 平台卖的就变成了“额度”，而不是“模型”。
好，接下来是 Agent 前沿。
今天最重要的一条，ChatGPT Wallet 上线了，Agent 可以替用户下单结账。具体是这样的：OpenAI 推出 ChatGPT Wallet，让 ChatGPT Work、Codex 和 Dots 里的 Agent，在用户批准的前提下完成购买，沿用现有的卡片保护机制。首发面向美国 18 岁以上的 Pro 订阅用户，需要美国账单地址，以及符合条件的美国运通、Chase、Mastercard、Visa 卡。用户一次性绑卡，每笔购买通过 Face ID 或者指纹确认，卡号以支付 token 的形式隐藏。这是 OpenAI 在废弃第一版 Instant Checkout 之后，从零重建的购物方案。它解决的是什么问题？Agent 从“给建议”跨到“完成交易”，缺的从来不是模型能力，而是支付授权和责任边界。Wallet 用“绑卡一次、逐笔生物确认、token 化卡号”给出了一个可复制的范式。我判断这很快就会成为所有 Agent 产品的标配组件，而且它会把 Agent 的 KPI 从“完成任务”改成“完成付款”——这个转变其实挺大的。你可以问一句：“逐笔 Face ID 确认，是安全必需，还是过渡期的妥协？”等信任建立起来，这一步大概率会被简化掉。
第二条，The Verge 实测了 Anthropic 面向消费者的 Agent 产品 Claude Duet，评价是“有点神经质，但意外地有用”。里面有个细节挺有意思：Duet 主动提出，帮记者撰写关于它自己的体验稿。这说明什么？消费级 Agent 的难点不在能力，而在信任和预期管理。“神经质”这个词，说明模型还在过度自我指涉、还在越界主动。这类真实反馈，对设计 Agent 的交互边界——什么时候该主动、什么时候该闭嘴——比任何 benchmark 都有参考价值。可以聊一句：“Agent 主动帮你写稿，是贴心还是越界？这条线该画在哪？”
然后是快讯，我快速带过。
Google 发布了 Gemini 4 Hydrogen，1M token 窗口，4 档思考级别，定价 1.50 和 7.50 美元，官方说比 Gemini 3.8 Flash 快 2.5 倍，Artificial Analysis 得分 51，Terminal-Bench 4.1 到了 57%，已经接入 Google Search。
Anthropic 的 Claude for Manufacturing 插件接入了工厂软件，直连 Autodesk Fusion、Oracle NetSuite 和 Infor，17 项专用技能可以起草报价、比价供应商、在延迟交付时下备用订单，都需要人工批准；另外他们还在开发 Model Hardware Standard，用来控制实体设备。
Meta 的 Muse 可以代用户打电话给商家了，面向付费的美国订阅用户，覆盖从有线电视到餐厅，Meta AI 负责人 Alexandr Wang 说这个 Agent 已经有超过 1,000 万用户；但问题是，很多商家一检测到是 AI 就挂断。
llama.cpp 发布了 v1.0.0，官方说会继续覆盖所有平台和模型类型，同时保持对下游应用的轻量和稳健，还配套推出了降低本地 AI 使用门槛的 Llama 桌面应用。
Google 开源了 TPU Sync，一个 C++ 库，可以在 TPU 的 HBM、主机 DRAM、存储和网络之间搬运 KV cache 和权重，官方说在 235B 到 480B 的 MoE 模型上，KV 传输延迟降低了 90% 以上。
最后一条，A100 二手价再跌 20% 到 30%，有卖家开始接受现实、降价清库存。发帖的人认为 Rubin 和 Blackwell 每瓦效率已经高 3 到 4 倍，而且融资更容易拿到，A100 已经很难用于推理了。
好，到了今天的观察和商业机会，咱们聊得随意一点。
今天最值得记的一笔，我觉得不是黄仁勋的后续，而是 LangChain 的 30 亿美元估值和 ChatGPT Wallet 在同一天出现。你想想这个画面：Agent 的基础设施层，也就是观测、评测、管理，和交易层，也就是支付授权，同一天被定价了。这说明市场认为 Agent 的瓶颈已经从“能不能做”转到了“怎么管、怎么收钱”。视频生成这边，MarkTechPost 的横评给了一个不太舒服的结论：原生音频、15 到 30 秒、开源权重进前三，这三件事同时发生，意味着视频 API 的差异化窗口正在关闭。接下来拼的是每秒单价和分发渠道，不是榜单名次。OpenRouter 上 DeepSeek 降价、Kimi 涨价的分化，恰好印证了同一个逻辑——模型层在分层，中间层在收租。还有一条暗线你得盯着，就是那个 Blackwell 指纹研究，它可能把出口管制从硬件层面推进到模型层面，这个影响是结构性的。
基于这些，我看到两个机会。第一个，面向视频 API 的“每秒成本计算器加自动路由”。MarkTechPost 的横评已经把 Elo、每秒价格、是否开源权重放在同一张表里了，说明买家正在用“每秒多少钱”而不是“榜单第几名”做决策；OpenRouter 同一天七款模型调价，也证明价格波动频繁到人工比价已经失效。你可以做一个中间层，按分辨率、时长、是否带音频，自动选最便宜且合规的模型，服务那些每月视频生成支出在几千到几万美元的内容团队。第二个，Agent 支付的合规与对账中间件。ChatGPT Wallet 用的是绑卡一次、逐笔生物确认、token 化卡号，但企业侧还得解决 Agent 消费的预算上限、审批流和发票归集。参考 Stripe 用 LangChain Deep Agents 几周就建成公司级 Agent 的先例，再加上 LangSmith 那 7,000 家客户代表的存量部署规模，现在切入“Agent 支出管控”这一层，时间点是合适的。
最后用一句话总结今天：Agent 的中间层和交易层同时被资本市场定价，视频生成的竞争则从模型榜单转向了每秒单价——谁能把成本算清楚、把支付管明白，谁就拿到下一轮的入场券。
