早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 24 日，星期二。先给你今天的一句话：MiniMax 把视频生成 API 同时铺到 fal、MachGen、Nunchux 三家渠道，还给出首单免费，视频模型的竞争正在从"谁的效果好"转向"谁的分发渠道多、谁先让开发者零成本试"。
今天的内容挺密。市场层面，Nvidia 的 CEO 去留被白宫直接插手，Amazon 花 75 亿美元买一支优化团队给自家芯片铺路，还有头部模型公司开始当算力房东。赛道深挖部分是我们最该盯的：MiniMax 的多渠道定价、阿里云补上音频工具箱、OpenRouter 上开源模型集体涨价。Agent 前沿有两件事，指向同一个方向。最后我会聊聊今天最值得记住的判断，以及两个能落地的机会。我们开始。
先看市场局势。第一件大事，Nvidia 董事会全票让黄仁勋回归。要知道，距离 11 月 12 日他因为和 Megaspeed 高管 Alice Huang 的绯闻辞去 CEO，才过了大约两周。这次恢复的是总裁、CEO 和董事三个职务，即刻生效。更微妙的是政治介入被公开承认了：Trump 对 CNBC 说"I spoke to them… And I convinced them"，白宫通讯主任 Steven Cheung 说总统完全参与其中。CNBC 报道国会方面直接抨击这次回归是"性格的失败"，而黄仁勋已经定在 12 月 1 日去众议院作证，下周还有一场参议院听证。同时 Megaspeed 本身正在被推向美国黑名单。
这件事说明什么？全球最重要的 AI 芯片公司，治理结构被政治力量直接改写了，而且还跟对华芯片走私调查纠缠在一起。这意味着 Nvidia 的对华销售政策、出口合规口径，都可能随政治风向摆动，供应链的不确定性在上升。如果你和海外做基础设施或者模型训练的朋友聊到这件事，可以问问他：当一家芯片公司的 CEO 去留由白宫一个电话决定，"算力中立供应商"这个故事还讲得通吗？这个问题背后其实是很多公司在重新评估单一供应商风险。
第二件，Amazon 以 75 亿美元收购 Decart 的 AI 优化技术和研究团队。TechCrunch 的报道说得很清楚，背景是 Amazon 正准备对外销售自家的 Trainium 芯片。这是典型的"买软件和优化能力，来给自研芯片背书"。趋势是什么？云厂商的竞争重心正在从"卖算力"转向"卖被优化过的算力"，推理成本优化能力成了芯片销售的配套弹药。这会进一步压低推理侧的单位成本，对靠 API 差价吃饭的聚合平台是长期压力。谈资角度给你一个：芯片厂商开始收购推理优化团队，是不是意味着"优化层"最终会被硬件厂吞掉？如果你在跟做 API 聚合的创始人聊天，这个问题很能引出对方对自身护城河的思考。
第三件，SpaceXSI 转向"租算力而不是自建"。据纽约时报的报道，从 5 月起，SpaceXSI 一边向 Anthropic、Google 这些竞争对手出租算力，一边收缩自家 AI 项目，6 月 IPO 之后还解散了 60 人的 Grok Imagine 团队。数字很吓人：Anthropic 每月支付约 31 亿美元，Google 约 8 亿美元。这说明头部模型公司的算力开支已经到了月付十亿美元的量级，而部分玩家选择退出自研、改当算力房东。这既印证了训练和推理的资本开支规模，也说明视频生成这类重算力业务的入场门槛在被进一步抬高。可以问一句：当一家公司发现出租算力比做模型更赚钱，行业里还剩几家愿意继续烧模型？
好，进入今天最该关注的部分，赛道深挖。
第一条，也是今天的头条：MiniMax 的视频 API 接入了 fal、MachGen、Nunchux 三家第三方渠道。它的定价页新增了一张按 Provider 划分的表格：MiniMax-H3-Max-Turbo，支持文生视频、图生视频和参考生成，在 fal 上是 0.12 美元一次，前两次免费；MiniMax-H3-MG 在 MachGen 上是 0.10 美元；MiniMax-H3-NC 在 Nunchux AI 上前五次免费。同时，页面删掉了原来那段按资源计费的复杂说明，就是"每个任务前两张图免费、超出按张计费、输入视频按输出分辨率的时长计费"那一大段。
这件事的分量在哪？视频模型正在复制语言模型的分发路径：官方 API 之外，把模型挂到 fal 这类创作基础设施和多家区域渠道上，用首单免费换开发者试用。对做 API 聚合和分发的平台，这意味着上游模型方自己在建多渠道网络，中间层的议价空间被压缩；对下游创作工具，可选的供应商和价格档位变多了。特别值得注意的一个细节是，同一个模型按渠道给出不同单价，0.12 和 0.10，渠道本身正在变成定价变量。你作为 API 平台的 GTM 负责人，这里有个很实际的问题可以带去跟海外创始人聊：当上游开始自己铺渠道，聚合平台的价值到底是"列表更全"，还是"能拿到更好的档位"？这个区别会决定你接下来的商务谈判怎么打。
第二条，阿里云百炼上线两款 qwen-audio-3.1 模型。一个是 captioner，可以给录音里的语音、音效和背景声加上时间标记，还能描述整段录音的声学场景；另一个是 live，支持实时双工语音对话，并且可以委派后台任务。页面没有显示价格变动。
为什么这条对我们重要？带时间戳的音效和背景声标注，正是视频生成做音画同步、做"参考音频驱动"的前置能力；实时双工加后台任务委派，则是语音 Agent 的基础件。阿里把这两块放进同一个 API 平台，等于给视频和音频的创作链路补上了音频侧的工具箱。顺着这个可以想一个问题：视频模型的下一个差异化点，会不会是"音频理解"而不是画面质量？如果你在跟做视频生成的产品团队聊，可以问问他们音画同步现在是怎么解决的，是不是还在自己搭标注管线。
第三条，OpenRouter 的主力模型表大改。DeepSeek V4 系列集体涨价：deepseek-v4-flash-0731 的输入从每 token 0.0000000443 美元涨到 0.000000069，输出从 0.0000003 涨到 0.00000047；deepseek-v4-pro 输入从 0.0000009 涨到 0.00000128，输出从 0.0000015 涨到 0.00000256。也有降的，deepseek-v4.1-flash-1017 输入从 0.00000015 降到 0.00000003，输出从 0.0000006 降到 0.0000002。Kimi 这边，kimi-k2 和 kimi-k2-thinking 直接下架，kimi-k3 输入从 0.000000192 微涨到 0.0000002，输出维持 0.000016。另外新增了 google/gemma-4-26b-a4b-it、minimax/minimax-m3.1-flash 等条目，其中 minimax-m3.1-flash 输入从 0.000000075 涨到 0.00000015。
聚合平台上的价格表，是观察"谁在补贴、谁在收租"最快的窗口。DeepSeek 主力档位涨价、旧版 Kimi 直接下架，说明开源权重模型也在做版本收敛和价格回收。对依赖聚合平台选型的团队，成本模型得按周重算，不能按季度做预算了。这里有个谈资可以抛出去：开源权重模型开始涨价，是不是说明"开源等于便宜"这个假设正在失效？这个问题对做海外市场的团队特别有共鸣，因为很多客户的成本假设还停留在半年前。
接下来是 Agent 前沿。
第一条，Anthropic 推出 Claude Ship，让 Agent 自己 review、修、批准 GitHub 的 PR。它打包了三个组件：Code Review 已经正式可用，PR Steward 和 Claude Approvals 在 Team 和 Enterprise 套餐里公测。分工是，Code Review 负责审 PR，PR Steward 负责跟进修复，Claude Approvals 负责走完例行审批。它要解决的是"AI 生成的代码堆积之后，人工审批成了新瓶颈"这个问题。
为什么值得关注？这是把 Agent 从"写代码"推进到"管代码流程"，审批权本身被部分交给 Agent 了。对做 Agent 产品的人，这说明下一个高价值场景是流程里的决策节点，而不是内容生成节点；同时也把权限、审计、责任归属的问题摆上台面。可以问对方一句：你们敢让 Agent 直接 approve 一个 PR 吗？边界画在哪？这个问题的答案，往往能看出一个团队对 Agent 落地的真实成熟度。
第二条，Google DeepMind 用 Agent 团队加形式化验证，改进了聚变和化学领域的量子算法。核心思路是把"提出候选算法"和"机器可验证的正确性"接在一起。
这套"Agent 生成加形式化验证把关"的组合，是让 Agent 输出可以被信任的关键范式，而且可以迁移到代码、数学、芯片设计，任何有验证器的领域都行。对做 Agent 的人，它给出了一个工程答案：怎么让 Agent 的错误不流出系统。可以聊一个观点：Agent 的可靠性也许不靠更强的模型，而靠给它配一个验证器。这个判断跟前面 Claude Ship 那条放在一起看，方向是一致的。

模型发布这边，Z.ai 发布 GLM-5.4，750B 参数的 Loop Transformer，28 层跑两遍，号称可以对标 2 到 3 万亿参数的模型，API 和开放权重要等安全评估之后放出，定位是"Generalized Coding"，也就是代码也能生成视频、游戏和 CAD。OpenAI 那边，把 GPT-6.2 Sol 设成了 ChatGPT 聊天页的全球默认模型，内部测试里图像理解从 47.4% 提升到 71.7%，复杂指令正确率 78.1%。
监管这边，Oregon 和 Virginia 两个州分别起诉 SpaceX，指 Grok 的色情 deepfake 违反州消费者保护法，两州总检察长说它无视行业标准防护、虚假宣传平台安全性。
产品这边，Google 搜索的 AI Mode 接入了 Drive 和 Wallet，Gemini App 同步获得 Personal Intelligence，AI Mode 可以调用用户自有数据给出个性化回答。
融资这边，Supertake 融资 2000 万美元，让 AI Agent 把用户的市场判断直接转成股票组合，用户给观点，Agent 负责选股建仓。
好，到了今天的观察和商业机会，我用聊天的语气跟你展开。
今天最值得记住的，不是某个模型变强了，而是"分发"和"验证"两条线同时收紧。分发这条线，MiniMax 把视频模型拆到 fal、MachGen、Nunchux 多个渠道，还按渠道给出 0.12 和 0.10 的不同单价，这说明视频模型已经进入渠道战。对聚合层来说，价值取决于能不能拿到更好的档位，而不是列表更长。验证这条线，Claude Ship 把审批交给 Agent，DeepMind 用形式化验证保证正确性，指向同一个方向：Agent 开始接管流程里的决策节点，而可靠性靠外部验证器，不靠模型自觉。再加上 OpenRouter 上 DeepSeek 主力档位集体涨价、旧版 Kimi 直接下架，开源权重模型的低价红利在退潮。对做视频 API 的平台，这就是两头受挤：上游多渠道直供，下游按验证过的效果付费。
由此我看到两个机会。第一个，做"视频模型渠道比价加首单额度聚合"的开发者入口。依据就是今天这两条：MiniMax 在 fal、MachGen、Nunchux 给出 0.12 和 0.10 的单价和不同免费次数，OpenRouter 又在按周调价，中小创作团队根本没精力逐家比。谁能把"哪家便宜、哪家有免费额度、哪家效果好"做成一个实时更新的入口，谁就拿到了开发者的第一跳。
第二个，给 Agent 工作流配"可验证输出"的中间件。依据是 Claude Ship 和 DeepMind 这两条：一个把审批交给 Agent，一个用量子算法加形式化验证保证正确性，都说明企业采用 Agent 的卡点是"错了谁负责"。可以做一层轻中间件，把 Agent 输出接到测试、形式化检查、审批日志上，卖给正在把 Agent 推进生产流程的团队。这个方向对海外客户尤其好讲，因为合规和审计是他们采购时的硬门槛。
最后总结一句：视频模型在打渠道战，开源模型在收价格，Agent 在接管决策节点，而可靠性正在从模型能力变成系统工程。今天就是这样，我们明天见。
