早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 6 日，星期五。先给你今天的一句话：Google 把视频生成打到了 7 美分每秒，还顺手砍价 30%，叠加 OpenRouter 上 Gemini Omni Flash 两个版本同时上架——视频 API 的价格战，今天正式开打，靠“接入即卖”的平台，必须重新算毛利了。
今天的内容挺密。市场这边，AI 股集体暴跌，纳指单日跌了 5%，同时数据中心的地方公投 41 项输了 40 项，算力扩张开始撞上选票。赛道深挖部分是我们今天的重头：Google Gemini Omni 1.2 Flash 正式 GA，OpenAI 的图像模型上新，还有 OpenRouter 模型表的一次大换血。Agent 前沿会聊两个很实在的东西：一个泼冷水的基准，一个讲工程的方法论。最后是快讯和今天的观察。咱们一条条来。
先看市场局势。第一条，也是今天分量最重的一条：AI 股集体暴跌。纳指单日跌 5%，标普 500 跌超 3%。背景是中期选举之后，投资者大规模撤离 AI 交易。你要注意时间点——就在此前一天，刚传出 OpenAI 融资目标从 300 亿美元砍到 110 亿美元的重定价信号。这两件事连在一起看，味道就出来了：二级市场杀估值，会直接传导到一级市场的融资节奏，再传导到 GPU 采购承诺。而视频生成这种“高算力、慢回本”的赛道，会最先被要求证明单位经济。我的判断是，接下来一到两个季度，模型公司会更急着推高毛利的产品线。如果你和做视频平台的朋友聊到这件事，可以问问他怎么看“AI 资本开支的定价权，从投资人手里转回客户手里”这件事会不会提前到来。这个问题，海外创始人一般都有话说。
第二条，中期选举之后，数据中心公投 41 项输了 40 项。选民在 40 项地方公投里否决了新建数据中心，OpenAI 反应很快，马上发布了 National Community Compact 和 Compute Campus Policy Blueprint，作为自愿承诺。但要注意，这份承诺只覆盖自营设施，Oracle 这些伙伴建的部分不在里面。同一天 Meta 也警告，政治阻力会拖慢 AI 扩张。这条说明什么？算力扩张从“有钱就行”，变成了“有钱还得过地方政治关”。这会拉长供给周期、推高单位算力成本，最终会反映到视频生成这类重推理业务的 API 定价上——也就是说，刚才说的降价空间，会被供给侧吃掉一部分。这里有个判断我觉得挺值得聊：未来两年算力的瓶颈是电网和选票，不是 GPU。你可以拿这句话去试试对方的反应。
第三条比较轻：OpenAI 总裁 Brockman 在 WSJ 科技大会上说，公司 2027 年可能具备 IPO 条件，同时强调 OpenAI 在企业市场正在追赶已经先行一步的 Anthropic。IPO 叙事会把 OpenAI 的产品节奏推向“可审计的收入结构”，企业级 API 和 Agent 产品会更激进地打包售卖。对做分发层的平台来说，这既是压力也是机会。谈资角度：可以问对方，“OpenAI 上市前，会不会把 API 价格当成财报杠杆来用”。
好，接下来是今天的重点，赛道深挖。
第一条，Google Gemini Omni 1.2 Flash 正式 GA。几个关键数字你记一下：单条视频拉到 15 秒，720p 每秒 0.07 美元，比上一代便宜 30%，支持对话式逐步编辑。更关键的是，官方还主动提示：用低分辨率草稿，只对最终结果做超分，可以再省一笔。同一天，OpenRouter 的模型列表里新增了 gemini-omni-1.1-flash 和 1.2-flash 两个条目。这件事为什么是五星？因为 7 美分每秒，把 720p 视频的 API 成本压到了多数聚合平台难以加价的区间。而“草稿低清加终稿超分”这个建议，等于官方在教用户怎么少付钱。对视频 API 平台意味着什么？很简单：单纯转售 Google 的价差会迅速归零，你必须靠工作流、批量调度和超分链路去挣加工费。如果你和做视频平台的朋友聊，可以问他一个稍微尖锐点的问题：视频 API 会不会像图片一样，最后只剩两三家原厂，加一层薄薄的路由？
第二条，OpenAI 上线 GPT-Image-2.6 的两个版本，Flare 和 Sunburst。最快 6 秒出图，新增 GIF 输出、SVG 导出、标记编辑，还有一个 complexity 参数。Flare 主打速度，两个模型都支持动图和矢量导出。另外一个细节值得注意：WaveSpeedAI 的价格页已经把“GPT Image 2.6 is LIVE”放上了首页，同时撤下了“Kling 4.0 八折”的促销位。这条的趋势在哪？SVG 导出和 complexity 参数，是在把图像模型往“可交付的设计资产”推；GIF 则直接吃掉短视频平台的一部分轻量内容需求。对聚合平台来说，这既是上新即流量的机会，也意味着图像和视频的边界在 API 层被打通了，SKU 结构要重排。谈资角度送你一个挺有意思的问题：当图像模型能直出 GIF 和 SVG，视频生成的第一秒还值多少钱？
第三条，OpenRouter 模型表大换血。MiniMax 四代旧模型被清退，新增了 minimax-m2.7。DeepSeek V4 Pro 和 Gemma 4 反向涨价，deepseek-v4.1-flash 的 batch 档也涨了。这里我不逐条念价格，你只要记住一个结构性的信号：聚合平台上，“旧模型下架”和“小模型涨价”同时发生，说明低价小模型的补贴期在收缩，厂商也在收敛 SKU 数量。对做视频、图像 API 的平台是个很直接的提醒：靠低价开源模型做引流款的结构正在变贵，选品要往有毛利的中档模型挪。可以问对方一句：聚合平台的低价引流款，还能撑几个季度？
接下来是 Agent 前沿。
第一条，SemiAnalysis 出了个新基准，叫 GDPx。结论很扎心：没有任何一个 AI Agent 在真实知识工作上超过 12%。这个基准用模拟知识工作覆盖了从芯片设计到量化交易，Claude Opus 5.5 以微弱优势领先 Gemini 4 Carbon。当然也有批评者说，每个领域的任务数偏少、测试条件不均。但这条的价值在于，它把“Agent 能干活”的叙事拉回了现实——真实工作流的成功率还在个位数到十几个百分点。这意味着当下 Agent 产品的价值，更多在“人机协作提效”，而不是“替代”。做 Agent 的团队，评测口径应该从 demo 转向端到端任务完成率。谈资角度很直接：问对方，你们内部 Agent 的真实任务完成率是多少，敢不敢公开？
第二条，LangChain 提出“Agent 走向异步”。做法是异步子 Agent 让主循环保持响应，后台跑长任务。在 Deep Agents 里，由 orchestrator 负责派发、通知和审批，长任务交给后台 worker，避免主 Agent 被阻塞。这条为什么值得你关注？因为视频生成天然就是长任务，而异步子 Agent 的这套编排模式——派发、轮询、审批、回填——几乎就是视频 API 平台做 Agent 化产品时需要的骨架。你可以直接借鉴到“提交任务、等待渲染、交付”这条链路上。聊的时候可以说：Agent 的下一步，是不是从“更聪明”转向“更会排队”？
好，下面是快讯，我按主题串一下。
模型这边，OpenAI 发布了 GPT-6 Cyber，专攻漏洞发现和修复，测试中越界率从上一代的约 10% 降到不足 1%，已经在 Firefox 里挖出 81 个未知漏洞，在 Linux 内核构造了 948 条可用提权路径，成本大约 120 万美元。腾讯发布了 Hy4，这是它首个多模态模型，支持图像理解和自主操作软件，Artificial Analysis 智能指数 35 分，落后 Kimi K3.1 Pro，腾讯自己也承认在难数学和复杂图像上还大幅落后商业最强模型。百度开源了 ERNIE 5.5 Flash Base，280B 稀疏 MoE，14B 激活参数，33.5T token 预训练，而且是刻意不做中后训练，直接放基座。
基础设施和产品这边：Dropbox 花 3.5 亿美元收购了 Tigris Data，用来支撑面向 AI 模型和 Agent 开发者的 DBX Agent Cloud 存储平台。Perplexity 推出了常驻的 Teammates 工作 Agent，可以在同一个工作区里承担多个角色，复用已有项目、技能和记忆，和 Perplexity Computer 打通。Together AI 发布了 Together Compiler，用 Agent 驱动的持续编译循环，随流量变化重新优化推理前向，单模型 24 小时内比最佳 InferenceX 配置快至 2.6 倍 TPS。
好，到了今天的观察和商业机会，咱们聊得随意一点。
今天最强的信号，其实就一句话：视频 API 的定价权，正在被原厂直接收走。你看，Gemini Omni 1.2 Flash 用 7 美分每秒和 30% 的降幅，把价格锚定在了聚合平台几乎无法加价的位置；而 OpenRouter 上小模型涨价、旧模型清退，说明“低价开源引流”这个结构也在变贵。两边一夹，中间那层单纯做转售的空间，基本就没了。另一边，GDPx 基准告诉我们，没有 Agent 超过 12% 的真实工作完成率，所以 Agent 的竞争点短期不在能力，而在编排——异步、排队、审批这些“工程活”，才是差异化所在。再叠加 AI 股暴跌和数据中心公投 40 连败，算力成本的下降空间会被政治和资本两头挤压。所以对做视频 API 分发的平台来说，接下来半年就是一道二选一：要么往上做工作流，要么往下做价格。
具体的机会，我看到两个。
第一个，视频 API 的“草稿到超分”成本优化层。依据就是今天 Gemini Omni 1.2 Flash 的定价和官方建议——Google 明确说了，低分辨率草稿加只对终稿超分能更省钱，但大多数开发者不会自己搭这条链路。你可以做一层自动的草稿和超分调度，按“省下的钱”分成，这个商业模式很干净。
第二个，Agent 长任务的异步编排中间件。依据是今天 LangChain 那篇异步 Agent 的文章，加上 GDPx 的基准结果。异步子 Agent 的模式和视频生成“提交、渲染、交付”的形态高度同构，而 GDPx 显示 Agent 端到端成功率仍然很低，说明可靠的任务派发和状态回填是刚需。切入点建议从视频、图像批量生成这类高频长任务开始。
最后总结一句：原厂把价格打到底，中间层的活路只剩两条——往工作流里钻，或者往成本里抠。今天就聊到这儿，我们明天见。
