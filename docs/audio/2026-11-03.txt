早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 3 日，星期二。先给你今天的这一句话：OpenRouter 上一批主力模型的 API 价格集体上调两到五倍，而 Anthropic 带着接近九千亿美元的算力承诺和两百三十亿美元的亏损冲刺 IPO——便宜 token 的时代正在被算力资本化的时代取代，API 平台的分发议价权要重新算一遍。
今天的内容挺扎实。市场局势我们看三件事：Anthropic 招股前夜那份极端的资产负债表，Oracle 用发债的方式给 AI 基建加杠杆，还有版权诉讼第一次把矛头指向数据中间商。赛道深挖是今天的重头，OpenRouter 那轮涨价我会把具体数字一个个念给你听，另外还有字节 Seed 的人事变动和 Qwen 的开源承诺。Agent 前沿聊 LangChain 的托管运行时和 NVIDIA 的语义层。最后是快讯和今天的观察。咱们开始。
先说 Anthropic。多家媒体同一天报道，Anthropic 在递交 S-1 之后披露，三季度重新回到经营亏损，亏了 230 亿美元，同时营收同比增长大约 12 倍。更关键的是另一个数字：它 AI 相关的支出承诺已经膨胀到接近 9000 亿美元。注意，这是承诺，不是已经花掉的钱，是长期算力合约的总额。与此同时，Hacker News 上有文章说它的增长刚刚走平，TechPolicy 那边甚至刊文呼吁 SEC 阻止它 IPO。
这件事说明什么？这是一份以算力换增长的极端资产负债表。头部模型公司的成本结构，已经从人力成本转向了长期算力合约，一旦增速放缓，定价就必须往上走。而定价往上走，最直接的出口就是 API 单价。所以你今天看到 OpenRouter 上那轮涨价，其实不是孤立事件，它是这条链条的下游反应。如果你和做模型或者做投资的朋友聊到这件事，可以问问他怎么看 9000 亿承诺配 230 亿亏损这个组合——这到底是护城河，还是杠杆？这个问题没有标准答案，但每个人都会有自己的判断，很适合当饭桌上的开场话题。
第二件事，Oracle。11 月 2 日它提交文件，打算通过新股加债券合计募资 200 亿美元，专门用于 AI 数据中心建设。同一天还有两条消息可以放在一起看：沙特阿美用 26 亿美元收购了 AI 公司 Humain 49% 的股权，韩国则把最高性能主权 AI 模型写进了预算目标。
这三件事放在一起，指向同一个趋势：AI 基建的融资方式，正在从经营现金流转向资本市场直接加杠杆。这意味着什么？短期看，算力供给会继续扩张，这是好事；但成本被固化在债务上了，中长期云厂商一定会对模型 API 的毛利提出更高要求。换句话说，算力从租变成债，云厂商未来会不会把成本压力转成 API 涨价，这是很现实的问题。你跟做云或者做基础设施的朋友聊，可以问问他们内部是不是已经在算这笔账了。
第三件事，版权战升级。纽约时报、纽约每日新闻、芝加哥论坛报等多家媒体起诉了 Brave 浏览器，指控它非法抓取受版权保护的内容，分发给 Anthropic、Perplexity 这些 AI 客户，同时还允许用户绕过付费墙。
这条的重要性在于，诉讼的矛头第一次从模型公司转向了数据中间商。过去两年大家都在盯着 OpenAI、Anthropic 这些模型厂商被告，现在打的是抓取层。如果 Brave 这类中间商被认定侵权，模型厂商的数据获取成本就会上升，进而影响训练和检索类 API 的定价。所以你可以想一想，数据中间商会不会成为 AI 版权战里最先被打掉的一环？这个判断对做 API 聚合的团队其实挺重要，因为你的上游成本结构可能会变。
好，接下来是今天最重点的部分，赛道深挖。
第一条，也是今天最重要的一条：OpenRouter 上主力模型价格集体上调。我根据它模型价格接口的快照对比，把几个关键数字念给你听。
DeepSeek V4.1 Flash，也就是 deepseek-v4.1-flash-1017，prompt 从每百万 token 0.15 美元涨到 0.30 美元，completion 从 0.60 美元涨到 1.20 美元，正好翻倍。DeepSeek V4 Flash 0731 这个版本比较特别，输入从 0.119 降到 0.059，但输出从 0.238 涨到 0.30，输入降、输出大涨，这个结构变化很值得琢磨。GPT-OSS-120B 涨得最狠，从 0.029 和 0.107 涨到 0.15 和 0.60，大概五倍。MiniMax M3.1 Flash 从 0.075 和 0.30 翻倍到 0.15 和 0.60。Qwen3 Coder 30B A3B 从 0.07 和 0.28 涨到 0.15 和 0.60。也有降价的，Gemma 4 26B A4B 从 0.0675 和 0.225 降到 0.045 和 0.135，是少数派。
这些数字说明什么？聚合平台上的价格是渠道风向标。这轮上调集中在中小参数、高并发模型上，说明推理侧的真实成本压力已经传导到聚合层了。对做视频和图像 API 的平台来说，这意味着靠低价聚合获客的空间在收窄，你必须靠独家模型或者能力差异化来站住脚。这里有个谈资角度你可能会用上：聚合平台的价差红利是不是快吃完了，下一步靠什么留住开发者？如果你和做视频平台的朋友聊到这件事，可以问问他，他们内部是不是已经在重新算单位生成成本了，尤其是那些靠低价模型跑量的草稿生成环节。
第二条，周畅从字节 Seed 离职。36 氪报道，背后是团队内部关于多模态统一路线的分歧——理解和生成能不能在同一套架构下统一，这个技术路线长期存在争议。
这条对视频生成赛道是直接信号。如果统一多模态架构走不通，视频生成就仍然是独立的模型栈，意味着视频 API 的模型迭代节奏、成本结构都会和大语言模型分离，平台需要分别押注，不能指望 LLM 那边的进展自动溢出到视频侧。谈资角度是：多模态统一到底是不是伪命题，还是只是还没到时间点？这个问题特别适合问做视频生成的创始人，因为他们的技术选型本质上就是在赌这个答案。
第三条，Qwen 官方表态。r/LocalLLaMA 上流传的官方声明里，Qwen 负责人刘大一恒明确说，未来的 Qwen 4.0 和 Qwen 5.0 会继续开源，否认了 Qwen4 是最后一个开源系列的传闻，还强调 AI 的价值不应该只属于少数人。
这条的意义在于，开源权重意味着在视频和图像生成之外的模型层，仍然有低价替代品。API 平台可以据此构建开源模型托管加自研模型的双层供给，压低上游议价成本；对闭源模型厂商则是持续的价格压力。所以你可以想想，开源阵营的持续承诺，会不会让闭源 API 的溢价越来越难讲？这跟前面 OpenRouter 涨价那条正好形成对冲，一边是涨价，一边是开源托底，中间的聚合平台日子其实挺微妙的。
接下来是 Agent 前沿。
第一条，LangChain 推出了 Managed Deep Agents 的私有测试版。它提供持久化执行、沙箱、工具接入和 LangSmith 可观测性，开发者不用自己搭 runtime，就能把 deep agent 跑在生产环境。同一天它还发布了浏览器使用能力，让 Agent 操作真实浏览器，并且提供了一个人工接管登录的 handoff 机制。
它解决的是什么问题？是 Agent 从 demo 到生产之间最痛的那一环——长时任务的容错、状态持久化，还有浏览器登录态。这三件事以前每个团队都要自己造一遍，现在可以托管了。对做创作类 Agent 的团队来说，这意味着你可以把自动生成素材加登录平台发布，串成一条可运维的流水线。谈资角度：Agent 的运行时会不会像数据库一样，最终被少数托管服务垄断？这个问题值得你跟做 Agent 产品的朋友聊聊，因为它直接关系到未来谁掌握入口。
第二条，NVIDIA 开源了 Auto Ontology，Apache 2.0 许可。它从企业元数据自动生成语义层，把 Agent 生成的 SQL 锚定在经认证的定义上，并通过 MCP、CLI 和 API 提供上下文。
Agent 做数据分析，最大的失败原因不是模型不够强，而是字段理解错了。语义层把口径固化下来，等于给 Agent 加了一层可信底座，这是 Agent 进入企业数据场景的前置条件。所以谈资角度是：Agent 的可信度问题，最后是不是都要靠语义层加权限来解决，而不是靠模型更强？这个观点在海外创始人圈子里挺有共鸣的，你可以拿去用。
好，下面是快讯，我按主题串一下。
先看成本这条线。Y Combinator 的 Garry Tan 自曝，一年在 Agent token 上花掉最多 20 万美元，还说因为跟 Agent 协作太兴奋，几乎不睡。另一边，SpaceXSI 下调了 Grok Bot 的配额，马斯克说运营成本相对收入不可持续——注意，这距离他称这个产品是增长最快产品还不到两周。
然后是企业的态度。高盛禁止交易员和投行人员使用 Claude Code、GitHub Copilot 这类 AI 编码工具，只限工程师使用，理由是生产力和风险管理。
再看产品侧。Anthropic 更新了 Claude Code 的系统提示词，禁止用它复刻现有电子游戏，但原创游戏还是允许的。OpenAI 则把 ChatGPT 的 Chat 和 Work 标签页合并了，ChatGPT 和 Codex 将共用同一个用量配额池。
好，最后是今天的观察和商业机会，咱们聊得随意一点。
今天最值得注意的，其实不是某一条单点新闻，而是成本这个词同时出现在四个方向：Anthropic 的 9000 亿算力承诺、Oracle 的 200 亿债务融资、OpenRouter 上一批模型两到五倍的涨价，还有 Grok Bot 因为成本不可持续被砍配额。这四条放在一起看，结论很清楚：AI 供给侧的定价逻辑，正在从抢份额补贴切换到覆盖真实资本成本。过去一年 API 平台赖以获客的低价窗口，正在收窄。
但另一边，需求侧也在变。Qwen 承诺继续开源、NVIDIA 用语义层给 Agent 加可信底座、LangChain 把 Agent 运行时托管化——这些说明需求正在从调用模型转向跑通工作流，而这恰恰是低价模型替代不了的价值层。对视频生成 API 平台来说，单纯比单价的阶段接近尾声了，接下来拼的是独家模型、工作流封装和渠道绑定。
那具体有什么机会？我看到两个。
第一个，面向中小创作团队做成本可控的视频生成 API 网关。依据就是 OpenRouter 集体涨价和 Grok Bot 砍配额这两条事实——大量中小团队会同时面临单价上涨和配额收紧。谁能在聚合层之上做按任务类型自动路由，比如草稿用低价模型、成片用高质模型，并且给出可预测的月度成本上限，谁就能接住这批被涨价挤出来的需求。这个生意的核心不是模型更强，而是帮客户把成本变得可预期。
第二个，把 Agent 运行时能力封装成视频创作工作流产品。依据是 LangChain 的持久化执行和浏览器 handoff，加上 NVIDIA 的可信语义层，这两条让视频创作里最难自动化的三件事——多轮改稿、登录平台发布、素材口径管理——第一次有了工程基础。可以先服务需要批量产出短视频的营销和电商团队，他们最需要从生成到发布一条龙，而且对成本的敏感度高于对模型品牌的敏感度。
好，今天就聊到这里。一句话总结：便宜 token 的时代在退场，接下来拼的不是谁的单价低，而是谁能把成本变得可预期、把工作流跑得通。我是 Andy，我们明天见。
