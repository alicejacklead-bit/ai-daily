早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 7 日，星期五。先给你今天的一句话：模型 API 的竞争焦点，正从“每 token 多便宜”转向“Agent 用起来多顺”——fal 和 OpenRouter 的货架大换血、Perplexity 把常驻 Agent 卖到 200 美元一个月，都是在抢同一批愿意为“跑通任务”付钱的人。今天咱们重点聊三件事：第一，资本端对头部模型公司的定价开始松动了，Anthropic 的 IPO 估值被买方一路往下砍；第二，分发层的模型货架几天之内完成大换血，这背后是视频模型竞争的实时计分板；第三，Perplexity 用一个 200 美元每月的常驻 Agent，给整个行业扔出了一个新的价格锚。好，咱们一条一条来。
先说市场局势。今天最扎眼的一条，是 Anthropic 的 IPO 估值预期。据 Bloomberg 报道，在 AI 板块一轮抛售之后，买方把 Anthropic 的估值看到最低 1.1 万亿美元，而此前市场的预期是 1.5 万亿；另外还有报道说，部分讨论已经降到了 1.3 万亿。你注意这个方向，不是往上修，是一路往下修。这件事为什么重要？因为它意味着“高估值、高算力承诺、高融资”这个循环被打断了。过去两年，头部模型公司讲故事的方式是：我估值高，所以我能承诺巨额算力；我能承诺算力，所以投资人更愿意给高估值。现在这个飞轮的第一环松了。对咱们下游做 API 平台的来说，这里有个反直觉的判断：上游厂商的定价纪律可能反而会收紧，而不是继续降价。因为他们要拿估值，就得拿收入说话，而不是拿补贴换规模。所以如果你和做模型平台的朋友聊到这件事，可以问问他怎么看“模型公司到底该按收入估值，还是按算力承诺估值”——这是现在硅谷最尴尬的一个问题，基本没人愿意正面回答。
接着看 OpenAI。TechCrunch 报道，OpenAI 又融了 110 亿美元，估值 1.25 万亿美元，这是尚未关闭的一轮融资的一部分，预计未来几周内完成。你把这条和前几天“融资目标从 3000 亿砍到 110 亿”的报道放在一起看，就很有意思了：头部公司还在吸金，但单笔规模已经从“天文数字”回落到“可消化区间”。这说明这轮 AI 资本周期进入了一个新阶段——钱还在，但要价变挑剔了。这种挑剔会沿着链条往下传导，对中小模型公司和 API 平台的估值只会更严苛。跟创始人聊天的时候，你可以聊“现在融资是看模型能力还是看毛利”，我跟你讲，多数创始人会有切肤之痛，因为这直接关系到他们下一轮能不能活下去。
第三条，是今天我觉得最值得琢磨的数据。TechCrunch 引用 Ramp 的支出数据指出，AI 的使用量还在持续攀升，但企业支出已经停滞了。原因有两个：一是降价，二是头部客户在做更聪明的成本控制。这个信号出现的时间点很微妙，恰好是 Anthropic 临近 IPO 的时候。它直接挑战了“AI 超高速增长”这个叙事——token 消耗在涨，账单不涨，说明单价下行的速度已经快过用量增长的速度。对做模型 API 分发的平台，这条的结论很硬：你必须靠增值层赚钱，而不是靠转售差价。差价这个生意，正在被结构性压缩。所以下次见到客户，别问模型能力，直接问他“你们客户这个季度的 AI 账单是涨的还是平的”，这个数字比任何 benchmark 都能看出真实温度。
好，接下来是今天的重头戏，赛道深挖。咱们做视频生成 API 的，这部分得听仔细。
第一条，fal 的模型货架大换血。根据 fal 价格页的快照，图像侧新增了 Seedream 5.0、GPT Image 2.6、FLUX 3 Image、Nano Banana 2.1 和 Krea 3，同时删掉了 GPT Image 2.5、GPT Image 2、Flux 2、Nano Banana 2、Ideogram 4 和 Krea 2。视频侧更狠：新增 Kling 4.0、FLUX 3 Max、PixVerse V6 和 Grok Imagine Free，删掉了 Kling 3.0、Veo 3.1、Grok Imagine 1.5，还有 Happy Horse 1.1 和 Happy Oyster。连导航层都把“Text to Video”这个入口换成了“AI Video Generator”。你品一下这个动作：Kling 从 3.0 到 4.0，迭代周期已经压缩到月级；Veo 3.1 这种级别的模型，说下架就下架。这说明什么？聚合平台换模型的速度，就是视频模型竞争的真实计分板。对做 API 分发的平台来说，“模型上架速度”和“旧模型退役迁移”本身就是产品能力，同时也是客户流失点——你想想，一个客户的工作流是绑在 Veo 3.1 上的，你突然下架，他要么迁移，要么走人。所以这里有个特别好的谈资：你可以问做视频平台的朋友，“你们现在怎么决定一个模型什么时候下架？”我敢说，多数创始人没想清楚这件事，他们的下架决策往往是跟着上游走的，而不是跟着客户的工作流走的。
第二条，OpenRouter 的模型表变化。DeepSeek 全家桶价格大幅下调：DeepSeek V4 Pro 的 prompt 价格从 0.0000016 降到 0.00000069948，completion 从 0.0000032 降到 0.00000139896，大概打了四折；DeepSeek Chat 也有下调。但另一边，openai 的 gpt-oss-120b 反向涨价，按快照数值 completion 端大约涨到 2.5 倍。同时，平台上新增了 deepseek-v4-flash-0731 的 batch 档、minimax-m3 的 batch 档、qwen3.8-27b 的 batch 档等一批批量档位。这条说明两件事。第一，“开源便宜、闭源贵”的分层在固化——开源权重模型在聚合平台上继续打价格战，闭源小模型反而敢涨价。第二，也是我更在意的：batch 档位的密集出现，说明平台在把“非实时”流量单独定价。这件事对咱们太有参考价值了，因为视频生成天生就是长任务、天然可异步。文本侧已经把 batch 做成标准档位了，视频侧还没有人做完。所以这是个特别好的聊天话题：你可以问“batch 档位会不会成为视频 API 的标配定价层”，这题现在没人有答案，谁先聊清楚谁就占先机。
第三条，即梦的短剧工作室上线。量子位做了实测报道，即梦把 AI 短剧的制作流程打包成了工作室形态，剧本、分镜、预演一条龙，配合“伙伴计划”做长期扶持，底层用的是 Seedance 2.5，单秒成本压到了 0.15 元人民币。这条的重要性在于，它是一个完整的闭环案例：模型能力，到创作工作流，再到内容产能，三层打通了，而且价格已经低到可以支撑批量短剧生产。对咱们海外做 AI 视频创作平台的团队来说，这是一个明确的成本锚点。单秒 0.15 元人民币这个量级的生成成本，会重塑整个内容工作室的报价体系——海外客户会拿这个数来跟你比价，你没法回避。所以这里有个生死线级别的问题，你可以去问做视频平台的朋友：“你们的视频生成成本降到多少，客户才会从‘试用’变成‘批量生产’？”这个问题问出来，对方的回答基本就暴露了他现在的商业模式能不能撑住。
接下来是 Agent 前沿，这部分咱们积累认知。
第一条，Perplexity 推出了常驻 Agent，叫 Teammates，Max 档 200 美元一个月。这个产品的关键在“always-on”——它不是一问一答的会话，而是在各自的虚拟机上持续推进长期项目。定价 200 美元每月，明显高于 OpenAI 或 Anthropic 的同类产品。它解决的是什么问题？是“任务跨天、需要持续跟进”的问题。以前的 Agent 是你问一句它答一句，任务一断就没了；常驻 Agent 是它一直在那儿跑，你第二天回来它还在推进。为什么值得关注？因为它把 Agent 从“会话”变成了“常驻劳动力”，而且给出了一个高价锚点。对做模型 API 的平台，这意味着 Agent 场景的 token 消耗是持续型而不是脉冲型的，你的定价模型得重新设计——按调用次数计费在这种场景下会失效。这里有个现在没人有标准答案的问题，你可以拿去聊：“常驻 Agent 该按席位收费，还是按算力收费？”按席位简单，但会和真实消耗脱节；按算力公平，但客户不喜欢账单不可预测。这个矛盾，接下来半年会被反复讨论。
第二条，LangChain 的工程实践。他们发博客披露，对比了七种浏览器工具集，最终选用了 Browserbase 的 Stagehand，并且用 LangSmith 的 trace 和 eval 做调优，服务于他们的 Deep Agents。这条为什么值得关注？因为 Agent 落地最脏最累的一环就是浏览器操作，而这类工程细节的公开对比非常少见。它解决的是“Agent 在真实网页上稳定执行”的问题。对做 Agent 产品的团队，这是一份可以直接复用的选型参考，省了你大量试错时间。谈资角度也很实用：你可以问“你们 Agent 的浏览器层是自己写还是买？”我跟你讲，多数团队会在这个问题上倒苦水，因为自研维护成本高，买又担心被锁定，这是个典型的中间地带难题。
好，快速过一下快讯。Meta 为它的 Muse Agent 推出了 Spaces，可以在 Muse 里面构建购物中心、学校看板、音乐追踪器这类定制化的、像 app 一样的体验，本质是把 Agent 往“可搭建的应用层”推。Palo Alto Networks 正在洽购 AI Agent 安全公司 Clutch，作价大约 5 亿美元，而 Clutch 上一轮估值才 8500 万，投资方有 Lightspeed 和 SignalFire——注意这个溢价，Agent 安全这个赛道开始被大厂用真金白银定价了。Thinking Machines 发布了 Inkling 2 Small，5940 亿总参数、170 亿激活的 MoE，Artificial Analysis 智能指数 31 分，Apache 2.0 权重，训练用了 12T tokens、68 小时——西方开源权重模型又多了一个能打的。NVIDIA 发布了 Cosmos 3 开放模型，用于交互式世界模拟，面向机器人和世界模型的仿真场景。最后，据 Bloomberg 报道，微软正在逐步结束向 Oracle 租用 AI 云容量的协议，外部算力租赁在收缩，这跟前面资本端降温是同一条线索。
好，到了今天的观察和商业机会，咱们聊得随意一点。
今天最值得注意的，其实不是哪个模型更强，而是“钱和货架”在同时重排。你看，资本端：Anthropic 的 IPO 估值被买方砍到 1.1 到 1.3 万亿，OpenAI 这轮只补了 110 亿，Ramp 的数据又显示企业 AI 支出已经走平——这三条放一起，结论很清楚，资本端对“高增长”的耐心在下降。与此同时，分发端：fal 和 OpenRouter 的模型表在几天内完成大换血，Kling 3.0、Veo 3.1 被移出列表，batch 档位密集出现。这说明分发层正在用“上架速度加分层定价”来对冲单价下行。Agent 侧呢，Perplexity 用 200 美元每月的常驻 Agent 给出了新价格锚，而 LangChain 的浏览器工具实测说明，落地瓶颈仍然在工程细节上。合起来看就是一句话：模型能力的边际差异在缩小，竞争正转移到“谁能把任务跑通，并且把成本结构讲清楚”。
基于这个判断，我看到两个具体的商业机会。
第一个，面向视频生成 API 的“batch、非实时”定价层。依据就是今天 OpenRouter 在文本侧密集上线 batch 档位这件事——deepseek-v4-flash-0731、minimax-m3、qwen3.8-27b 都加了 batch 档。文本侧已经跑通的定价结构，视频侧还没有人做完，而视频生成天生是长任务、天然可异步，比文本更适合做批量档。所以做视频 API 的平台，可以率先把“标准、批量、预览”三档拆开，抢在聚合平台之前定义视频侧的定价结构。谁先定义，谁就拿走话语权。
第二个，Agent 常驻任务的“算力加席位”混合计费与托管。依据是 Perplexity 的 Teammates 用 200 美元每月卖常驻 Agent，说明市场愿意为“持续在跑”付费；但纯按席位计费，会和真实算力消耗脱节。再结合 Ramp 那个“用量涨、支出平”的数据，你会发现中小团队最大的痛点就是“Agent 跑起来账单失控”。所以这里有个空位：为中小团队提供按任务时长加 token 的混合计费，再加上运行托管，帮他们把账单变得可预测。这个生意不大，但很扎实。
最后总结一句：当模型能力的差距越来越小，能决定胜负的就不再是谁的模型更强，而是谁能把任务跑通、把成本讲清楚。好，今天的早报就到这里，希望你在通勤路上有所收获。我是 Andy，我们明天见。
