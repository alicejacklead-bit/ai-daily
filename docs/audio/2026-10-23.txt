早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 10 月 23 日，星期五。通勤路上这几分钟，我帮你把过去二十四小时 AI 圈最值得关心的事捋一遍。
先预告今天最重要的三件事。第一，Agent 基础设施今天可以说是三层同时落地：Google 给每个 Gemini Agent 发了独立硬件隔离的微虚拟机，Anthropic 把 Agent Skills 标准捐给了基金会，1Password 解决了 Agent 代登录但不接触密码的问题，运行时、协议、身份三个卡点一天之内各有解法。第二，图像生成这边，Canva 发布了首个自研模型 Canva Craft，用的是先规划后生成的两阶段架构，设计工具厂商开始自己下场做模型了。第三，模型 API 层面有两个信号，OpenAI 上线了 Decisions API，把决策能力拆成低价独立接口，Cohere 发了 Rerank 5，重排环节又多了个又强又便宜的选择。另外还有个不太妙的消息，Gartner 的调查说只有百分之十三的企业从 AI 拿到了真实回报，这个数字值得每个从业者停下来想一想。
好，我们一条一条展开。
先说 Canva Craft。Canva 昨天发布了它历史上第一个自研图像生成模型，名字叫 Canva Craft，面向全量用户开放。它最有意思的地方在架构：不是直接文生图，而是两阶段，先生成一个设计方案，再基于方案出图。官方主打的是更强的可控性和更低的成本。为什么这件事重要？因为过去两年图像生成的竞争基本集中在采样器和底座模型上，谁的图更漂亮、更真实。但 Canva 走的是另一条路：它不跟你比画质，它比的是在真实设计场景里，用户能不能稳定拿到想要的结果。设计工具的用户要的不是一张惊艳的图，是一张能改、能对齐品牌、能批量出的图。两阶段架构本质上就是把规划能力和渲染能力解耦，规划阶段负责布局、元素、风格，渲染阶段负责出像素。对从业者来说，这个思路非常值得抄。如果你在做模板类场景、电商主图、海报批量生成，完全可以对标它的先规划后生成，搭一条两阶段管线，把可控性做上去，成本反而可能更低。这条我个人认为是今天产品层面最重要的新闻。
接着是 OpenAI 的 Decisions API。OpenAI 上线了 Decisions API，把决策模型全面开放，定位是快速、聚焦、低成本的结构化决策能力，直接对标 Jev 那一类决策模型。这个动作的本质是什么？是把决策从通用对话里拆出来，做成一个独立的、便宜的 API。以前你要做客服分流、表单校验、Agent 的分支判断，往往是拿一个大模型去跑，贵而且慢，还容易话痨。现在这类路由和分类的调用可以迁到专门的决策接口上。对从业者的意义很直接：如果你有大量高频、低复杂度的判断型调用，赶紧去测一下迁过去的成本和准确率，这可能是一个立竿见影的降本点。而且这个信号本身也值得注意，基础模型厂商正在把细分能力一条条拆成低价独立接口，这对所有做 API 定价的人都是一个直接参照。
第三条，Google 的 Agent Compute Engine。Google 推出了一个专为 Agent 设计的运行时，叫 Agent Compute Engine，核心是给每个 Gemini Agent 独享一个硬件隔离的微虚拟机，同时把云端、混合和本地环境的 Agent 治理能力一起扩展了。这件事的重要性在于，Agent 基础设施正在从沙箱升级到硬件隔离的虚拟机。以前企业部署 Agent，最大的顾虑之一就是隔离和合规，一个 Agent 跑出问题会不会影响别的租户，数据边界在哪。硬件隔离 VM 把这层顾虑往下压了一大截，企业部署门槛明显下降。对从业者来说，如果你在面向企业客户讲 Agent 合规部署，隔离运行时现在可以作为一个明确的选型卖点写进方案里了。
第四条，Anthropic 的常驻 Agent 应用 Claude Duet。Anthropic 推出了一个叫 Claude Duet 的常驻 Agent 应用，基于 Claude Opus 5.5，接入了 Gmail、Slack、Stripe 等六千多个连接器，用户离线的时候它也能自主执行任务，敏感操作需要审批，目前对 Pro 和 Max 用户候补开放。这条的核心价值是 Agent 从被动响应转向了常驻后台主动执行。你不在的时候它也在干活，这是一个范式变化。而它真正的护城河是那六千多个连接器。对从业者来说，最实际的动作是评估把自家 SaaS 接入它的连接器目录，用一次集成换一个 Agent 分发入口，这笔账在很多场景下是划算的。
说完这四条，我们快速过一下其他新闻。
Agent 和基础设施这块，还有几条。Uber 把 ChatGPT Work 推广到了全部三万名员工，从小范围试点转成全公司部署，这说明大企业级 Agent 采购已经进入规模化阶段，做销售的可以把 Uber 这类案例做成素材去攻同类的万人规模客户。1Password 推出了让 AI Agent 代登录但不接触密码的方案，凭据对 Agent 不可见，这解决的是 Agent 自动化最大的卡点之一。但另一边，美国多家大行开始封堵用客户凭据登录的 AI Agent，摩根士丹利已经直接封禁，其他银行也在收紧，多数只打算开放只读访问。这两条放一起看很有意思：工具侧在解决凭据托管，机构侧在系统性反制凭据代持，所以做金融类 Agent 的朋友，优先走官方 API 和开放银行，别赌浏览器自动化。另外 Anthropic 把 Agent Skills 标准捐给了 Linux Foundation 下的 Agentic AI Foundation，和 MCP 走的是同一条路径，强调开放和厂商中立，跨厂商的 Agent 技能包有望互通，现在按 Skills 规范封装自家能力包，是在抢早期生态位。
安全这块有一条必须提。Symantec 发现了一种叫 Skynet 模式的攻击，能自主劫持网络上未设防的语言模型，用来攻击服务器、窃库、挖矿，可以无人干预运行到十万步，账单还由被劫持的模型方承担。这条对所有开放推理端点的平台都是警钟，API 平台必须加鉴权和行为审计，给自家 API 加用量异常检测和限流，顺便把安全审计做成增值项，反而是个机会。
模型和融资这块。DeepSeek 据报融资一百五十亿美元，就在美国要求联邦机构移除其技术的几天之后完成，是中国规模最大的融资轮之一。同时 DeepSeek 和 MiniMax 完成了中国 AI 出口新规备案，拿到了明确监管许可，可以继续向海外开源发布模型。一边是地缘限制，一边是资本加注和合规路径打通，开源模型的供给格局还在分化。对做多模型路由的团队来说，保留国产开源备选、规避单一供应商的政策风险，依然是对的。
企业侧还有两条。Gartner 调查了两千零二名 CIO，只有百分之十三的企业从 AI 获得了真实回报，百分之五十一预计 AI 反而推高运营成本，但百分之七十五的 CEO 仍计划继续加预算。这个反差就是今天最值得琢磨的数字。另外微软称其 AI 诊断工具在疑难病例上优于医生，基于 Science 刊载的研究，但报道也指出提升主要来自底层模型而不是微软系统本身，所以医疗类产品讲故事的时候，聚焦底层模型能力，别过度包装编排层。
工具和模型发布这块快速带过。Cohere 发布 Rerank 5，Pro 和 Fast 两档，三十二 K 上下文，支持段落抽取和校准相关性分数，Pro 在 BRIGHT 上拿到八十二点二，定价是每百万 token 五美分，做 RAG 的可以直接在现有管线里 A/B 替换测召回。Liquid AI 发布实时推理引擎 RIPL，单张 B200 上小模型的 p95 延迟比 vLLM 跑同级模型低十四到二十八倍，主打五十毫秒以内的场景，实时语音 Agent 值得试。IBM 开源了 Granite Speech 5.0 2B，Apache 2.0 许可，语音识别与翻译，Open ASR 排行榜第二，英语平均 WER 百分之五点六八，是多语种转写产品替代 Whisper 系的新选项。蚂蚁 Ling 同一天发布了第二个模型 Ling-3.0-flash-Sante，一百二十四 B 总参、五点一 B 激活、二百五十六 K 上下文，面向医疗推理和文献研究，权重已经上了 Hugging Face，医疗 Agent 现在可以自托管了。
开源项目里挑几个说。Recursive 开源了 Flint，一个四十 B 的 MoE 本地编码模型，二点五 B 激活，Apache 2.0，SWE-bench Verified 七十四点二，在 M4 Pro 的 MacBook Pro 上能跑到每秒一百二十五 token 以上，二百六十二 K 上下文。这个对预算有限的团队意义很大，编码 Agent 可以从云端 API 迁到本地，按 token 计费变成固定成本。NVIDIA 开源了 OpenShell，面向自主 Agent 集群的安全私有运行时，自建 Agent 平台可以直接复用做多租户隔离。Vercel 开源了 durable-harness，让编码 Agent 崩溃可续跑，记录每次模型和工具调用，崩溃、超时、重部署之后都能恢复，接入后可以主打不丢进度作为付费差异点。Kitten-TTS 2 是首个一点五八 bit 的开源 TTS，纯 CPU 实时运行，支持零样本音色克隆，有声内容和播客工具可以本地批量生成，省掉按字符计费的 TTS API。还有 vocabX，通过词表特化把小模型推理成本降了百分之七十七，不改权重只改词表，垂直场景性价比极高。
论文这块我挑重点说。FrontierCS 2 是个新基准，四十八个开放式任务，把原论文的贡献删掉让 Agent 在真实仓库里复原，以人类作者的代码为标尺，把 Agent 评测从写一个程序推进到了在科研环境里做贡献，筛编码 Agent 供应商比 SWE-bench 更贴近真实研发。VerifierBench 评测 Agent 生成可执行验证器的能力，二百二十二个任务、四千九百九十三个隐藏测试用例，做数据合成管线的时候可以用可执行验证器替代人工抽检做质量闸门。还有一篇 RAG Compositionality，系统检验了 embedding、分块、检索、重排、查询增强这些模块叠加之后单项收益是否还成立，直击 RAG 工程堆模块的迷信，建议按它的结论裁剪自家管线，砍掉无效模块就是降本。视频这边有一篇很重要，Rethinking Video Autoencoders for Interactive World Models，指出世界模型复用了为离线生成设计的视频自编码器，而压缩方式直接决定了每帧成本和动作生效延迟，也就是说交互式视频生成的成本瓶颈在自编码器，不在采样器。做实时视频生成产品的，优先重训或换掉 VAE，收益可能比换采样策略大得多。另外 JOLT 这个方法值得关注，Perplexity 和 NVIDIA 合作的师生合一强化学习，单模型同时当老师和学生，MATH 上以六点五倍更少的训练 token 达到 GRPO 同等准确率，后训练算力成本大幅下降，小团队也能做有效 RL 调优了。
好，下面是今天的观察。
今天最清晰的信号，是 Agent 基础设施的三层同时落地。运行时层，Google 给每个 Agent 发独立微虚拟机；协议层，Anthropic 把 Skills 标准捐给基金会走向厂商中立；身份层，1Password 解决了凭据代持。这三个卡点同一天各有解法，说明 Agent 的基础设施正在快速成熟。但与之对照的是需求侧的现实：Gartner 说只有百分之十三的企业拿到真实回报，银行开始封堵凭据代持型 Agent。这两件事放在一起，结论很清楚：能力供给跑在了治理和信任前面。接下来一段时间，谁能在合规、成本、可观测性上把企业客户的顾虑解决掉，谁就能吃到下一波。图像和视频侧也一样，Canva 的两阶段架构，加上那篇指出世界模型瓶颈在视频自编码器的论文，都在提示同一件事：生成质量的竞争，正在从采样器转向管线设计。模型 API 层面，OpenAI Decisions API 和 Cohere Rerank 5 都在把细分能力拆成低价独立接口，这对我们自己的定价结构是直接参照，值得回去重新审一遍自己的 API 价格表。
最后聊聊商业机会和研究建议，用聊天的语气说。
商业机会我看到三个。第一个是 Agent 的成本与用量治理。依据就是 Gartner 那个数字，百分之五十一的企业预计 AI 推高成本，只有百分之十三见到回报，而社区里 agent-usage-guard 这类工具已经出现需求苗头。你可以做一个面向企业的 Agent 用量与成本看板加额度守卫，现在切入正好赶上 CIO 的预算审查期。第二个是 Agent 身份与凭据托管的中间层。1Password 开放了代登录能力，但美国大行正在封堵凭据型访问，这个缝隙就是机会：做一个合规版的 Agent 授权网关，把 OAuth、开放银行这些官方通道和 Agent 编排对接起来，卖给金融、医疗这些强监管行业的 Agent 开发者。第三个是垂直小模型的词表特化服务。vocabX 报告了百分之七十七的推理成本下降而且不用重训模型，RIPL 又把小模型延迟压到了五十毫秒以内，你可以对客服、摘要、垂直检索类客户提供词表特化加推理栈调优的轻咨询交付，客单价不高但转化快。
研究建议也是三条。第一，亲手复现 JOLT 的 token 效率结论，在自有领域数据上用相同的 base model 分别跑 JOLT 和 GRPO，记录达到同等准确率所需的处理 token 数和 GPU 小时，判断值不值得替换现有后训练流程。第二，拆解 Canva Craft 的两阶段架构，用开源图像模型搭一个先出布局方案再渲染的对照管线，在电商主图或海报场景测一致性指标，验证规划阶段是不是真的带来了可控性提升。第三，读透那篇视频自编码器的论文并做替换实验，如果你手上有视频生成或世界模型的实验，把现成的 T2V 自编码器换成为交互式场景设计的版本，测每帧成本和动作生效延迟的变化，这可能是比换采样器更划算的优化点。
总结一句：Agent 的基础设施今天补齐了三块拼图，但企业真正拿到回报的还只有百分之十三，接下来拼的不是能力，是信任和成本。
