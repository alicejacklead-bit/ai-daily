早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 25 日，星期三。先给你今天的一句话：Anthropic 跌破发行价，加上内部人集体质疑自家模型的安全性，前沿实验室的“信任溢价”正在被资本市场和员工同时打折——模型能力不再是唯一叙事，可控性开始定价。今天咱们重点聊三件事：一是 Anthropic 上市后的连环坏消息，二是视频和图像 API 这条赛道上计价方式和货架的变化，三是 MCP 生态那个七亿下载的数字意味着什么。如果你在通勤路上，泡好咖啡，咱们开始。
先看市场局势。今天最大的新闻还是 Anthropic。继昨天首日破发之后，它的股价今天进一步跌破了 83 美元的 IPO 发行价。Reuters 和 TechCrunch 都用了差不多的定性，说这是“对 AI 创业公司令人担忧的信号”。你要知道，这次 IPO 定价 83 美元，募资 813 亿美元，是史上最大的一次 IPO，结果上市之后的上涨势头几天之内就完全逆转了。这件事说明什么呢？说明二级市场对前沿模型公司的估值逻辑正在切换——以前大家买的是“能力叙事”，你能做出最强的模型，估值就往上走；现在市场开始要求盈利可见性，要看到现金流。这个切换会向下传导到一级市场，中小模型公司和 API 平台的融资窗口会被压缩。所以如果你和做投资或者做平台的朋友聊到这件事，可以问问他：你觉得前沿实验室的估值锚，到底是模型能力，还是现金流？这个问题现在特别值得听真话。
第二条，也是今天分量最重的一条。Axios 爆料，OpenAI 和 Anthropic 内部有数十名员工认为，他们未发布的前沿模型已经超出了安全措施的可控范围。The Decoder 和 Yahoo Tech 都跟进了这条。更关键的是，两家公司内部正在就是否暂停发布、甚至是否停止训练展开辩论，员工对管理层的信任正在流失。这是“能力—安全”的张力第一次以内部人集体质疑的形式公开化。它有两个走向：如果真导致发布节奏放缓，那下游 API 平台的新模型供给节奏就会被打乱，你排好的路线图可能对不上货；如果只是舆论事件，那它会加速监管介入。两种走向都影响模型分发生意。谈资角度我建议你这样问：如果实验室自己都不确定模型能不能放出来，API 平台该怎么规划模型路线图？这个问题问出去，对方一般会愣一下，然后说出真心话。
第三条，Amazon 花了 75 亿美元收购 Decart。TechCrunch 的分析说，这笔收购的核心目的不是买产品，而是提升 Amazon 自研 Trainium 芯片的效率，走的是“软件优化补硬件”的路线。这背后的趋势是，云厂商在推理成本上的竞争，正在从买卡转向软件栈优化。长期看，这会压低推理单价。对靠 API 转售毛利吃饭的平台来说，这是结构性压力；但反过来，也是你跟上游采购议价时的筹码。可以问对方：你觉得推理成本的下一个十倍改进，会来自芯片还是来自软件栈？我个人的答案是软件栈，但我想听听做基础设施的人怎么说。
接下来是今天最该听的部分，赛道深挖。
第一条，fal 的价格页新增了 Seedance 2.5 和 PixVerse V6 两个视频模型入口。快照显示，视频模型列表里现在有 Seedance 2.5 API、PixVerse V6，同时还保留着 Kling 4.0、FLUX 3 Max、Wan 3.0、LTX 2.5 和 MiniMax H3 Max。页面没有公布各模型的具体单价。这件事的意义在于，聚合平台把 Seedance 2.5、PixVerse V6 和 Kling 4.0 放在同一个货架上，视频模型的比价权进一步从模型厂商转向了分发渠道。对你这样的自建 API 平台来说，渠道货架越全，单模型的差异化就越难卖。客户不会因为“你有这个模型”而来，因为 fal 也有。你要赢，得靠工作流、靠稳定性、靠交付质量。所以可以聊一个很有意思的问题：视频模型越来越多，客户最后到底是按模型选平台，还是按平台选模型？我的判断是后者会越来越明显，你可以验证一下。
第二条，火山方舟的价格页有两个变化。第一，Seedream 4.0 的组图场景改为按实际生成的图片数量计费。第二，Seedance 1.x 相关的计费行下线了，包括 Seedance 1.0 pro 和 pro fast 的在线、离线推理计费行，还有 doubao-seedream-5-0-lite 的 0.22、doubao-seedream-4-5 的 0.25 这些单价行也删掉了。这说明两件事：图像侧正在从“按 token、按次”转向“按实际出图数”计费，这是生成类 API 定价向“按产出付费”演进的明确信号；视频侧旧型号计费行下线，说明老一代视频模型正在退出主推货架。做视频 API 的平台要特别关注这种“计价单位”的迁移，因为它直接影响客户的成本预期和你的毛利结构。可以问对方：图像和视频 API 按实际产出计费，会不会成为行业默认？我觉得大概率会，但过渡期会有很多混乱，这本身就是机会。
第三条，OpenRouter 的主力模型表又调价了，而且这次调得很细。Kimi K3 的输入价从每 token 0.0000002 美元微降到 0.000000192，输出维持不变；Kimi K2 的 0905 版本直接下架了。DeepSeek V4 Flash 系列有涨有调，MiniMax M3.1 Flash 输入从 0.00000015 降到 0.000000075，输出从 0.0000006 降到 0.0000003，等于腰斩。而 Qwen3.8 27B 反过来，输入从 0.000000035 涨到 0.00000006，输出从 0.0000015 涨到 0.00000196，涨了大约七成。同一张表上，有的腰斩，有的涨七成，有的直接下架，这说明聚合平台的价格战已经进入“分模型精细调价”的阶段。对做视频 API 的平台，这意味着上游文本和多模态模型的成本波动会更频繁，你的定价策略必须留出更厚的缓冲，不能按季度调，可能得按月甚至按周看。可以问一句：聚合平台频繁调价，客户会不会转向锁价合同？这个趋势如果成立，对能提供稳定报价的平台是利好。
好，接下来是 Agent 前沿。
第一条，Anthropic 的 MCP SDK 月下载量突破了 7 亿次。MCP 发布两年，做到这个量级，同时协议还新增了三个能力：后台任务、追问用户、文件上传。这意味着 Claude 能更独立地执行长任务、主动向用户追问澄清、处理文件上传。7 亿月下载意味着什么？意味着生态锁定效应已经形成，MCP 成了 Agent 工具接入的事实标准。而“后台任务加追问”这两个能力，是把 Agent 从“单轮工具调用”推向“可持续运行的自主任务”的关键，它直接决定 Agent 产品能不能做长流程业务。比如你做一个视频生成的工作流 Agent，它要能自己排队、自己等渲染、自己追问客户要参数，这才叫长流程。所以可以问：MCP 生态这么大，Agent 产品的护城河到底在协议还是在工作流？我倾向于工作流，因为协议是公共的。
第二条，OpenAI 和 Cisco 开源了一个叫 Shirudo 的项目。它是一个 BSD 许可的 Linux eBPF 运行时，目前是预发布状态。它的做法是让 AI Agent 编写签名的“shields”，在运行中的系统上阻断漏洞利用路径，团队可以同时测试和 rollout 真正的补丁。这解决的是安全运维里“打补丁必须停机”的老问题。这是 Agent 从“写代码、查资料”进入“生产系统实时防护”的一个典型案例。它示范了 Agent 在高风险、强约束环境下的落地形态——输出不是文本，而是可验证的运行时策略。可以聊一个信任边界的问题：Agent 的输出从“建议”变成“直接改运行系统”，这条线该怎么划？这个问题在海外创始人圈子里现在很热。

最后是今天的观察和商业机会，咱们聊得随意一点。
今天最值得记的信号，我给它起个名字叫“信任折价”。你看，Anthropic 跌破发行价，同期内部人爆料自家模型安全性失控，资本市场和员工在同一周对前沿实验室投了不信任票。与此同时，分发层的竞争在加速：fal 把 Seedance 2.5、PixVerse V6 摆上货架，OpenRouter 对单模型做精细调价，火山方舟把图像计费改成按实际出图数。这三条线合起来看，结论很清楚：模型能力的稀缺性在下降，计价单位、渠道覆盖和可控性在上升。对做视频 API 的平台，护城河正从“你拿到哪个模型”转向“你怎么计价、怎么保证稳定交付”。
由此我看到两个商业机会。第一个，是面向视频和图像 API 客户的“计价单位咨询加成本模拟”服务。依据就是火山方舟把 Seedream 4.0 组图改成按实际出图数计费，加上 OpenRouter 同一张表上多模型涨跌分化，客户现在很难自己算清迁移之后的成本。为什么是现在做？因为计价单位正处在迁移期，客户的决策窗口很短，谁先帮他们算明白，谁就拿到信任。第二个，是为 Agent 产品提供“可验证运行时策略”能力的企业服务。依据是 OpenAI 和 Cisco 的 Shirudo 发布。它示范了 Agent 输出签名策略直接作用于生产系统的形态，但大多数团队没有 eBPF 和安全审计能力。为什么现在做？因为协议刚开源、还在预发布阶段，先做集成和托管，能吃到早期生态红利。
好，今天就聊到这儿。一句话总结：能力不再稀缺，计价、渠道和可控性才是新的护城河。感谢收听 Andy 的 AI 早报，我们明天见。
