早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 21 号，星期六。先给你今天的一句话：Anthropic 以 1.5 万亿美元估值完成了史上最大的 IPO，却在上市首日跌破发行价，还拖累纳斯达克回吐了 2026 年全年的涨幅。AI 资产的定价逻辑，正在从讲故事转向看现金流，而这个变化，会最先传导到模型 API 的定价和分发层。
今天的信息量不小。市场层面，Anthropic 的 IPO 破发是绝对的重心，另外还有 Nvidia 要买一家做扩散语言模型的初创公司，以及 Trump 对海外数据中心放狠话。赛道深挖部分，我会重点讲 OpenRouter 上 DeepSeek 系列的一次集体大降价，还有 Google DeepMind 的 Genie 4 向开发者开放，以及 AI 短剧赛道那个非常刺眼的估值崩塌。Agent 前沿有两条很值得琢磨，一条关于技能沉淀，一条关于小模型加纯强化学习。最后是几条快讯，和今天的观察跟商业机会。
咱们先从市场局势说起。
今天全球市场都在看一件事，Anthropic 上市了。它以每股 83 美元定价，发行了 11.27 亿股 Class A 普通股，估值 1.5 万亿美元，这是历史上规模最大的一次 IPO。开盘价冲到 111.5 美元，看着挺猛，但情绪很快就反转了，收盘 97.17 美元。这里有个细节要说清楚，收盘价其实还是高于 83 美元的发行价，但市场的解读是破发，因为盘中一度跌破发行价，而且华尔街日报的说法是，这次 IPO 的破发加深了华尔街那 4 万亿美元的 AI 市值蒸发，NBC 则报道纳斯达克已经抹平了 2026 年全年的涨幅。
这件事为什么重要？这是 AI 行业第一次用公开市场给一家基础模型公司定价。过去几年，一级市场给这些公司的估值，本质上是买一个叙事，买一个未来的可能性。现在公开市场给出的答案，是开始用折现率去审视高估值加持续烧钱的组合。这个信号会约束后面所有模型公司的融资节奏、API 补贴力度，甚至推理算力的采购节奏。如果你和做模型 API 的朋友聊到这件事，可以问问他，如果公开市场只愿意给基础模型公司 15 倍市销率，那模型 API 的补贴战还能打多久？这个问题，我觉得接下来半年会反复被提起。
第二条，Nvidia 要收购一家叫 Inception 的初创公司，金额至少 5 亿美元，这家公司才成立两年。它做的不是 ChatGPT 那种逐 token 自回归生成的语言模型，而是基于扩散过程的语言模型。Nvidia 买它，是为了补强自家的开源 Nemotron 系列和机器人方向。
这个信号很有意思。芯片厂商开始直接买非主流生成范式的模型团队，说明推理效率的竞争已经从硬件层延伸到架构层了。扩散式文本生成如果真能在延迟上有优势，那它会直接冲击现在按 token 计价的 API 商业模式。你可以想想，如果解码速度能快好几倍，按 token 收费这套定价体系是不是要重写？这也是一个很好的聊天话题，尤其是跟做推理基础设施的人聊的时候。
第三条，Trump 表示不会允许美国公司在美国境外建 AI 数据中心，并承诺对境外建设行为征收巨额税。与此同时，美国多个州和城市正在限制新建数据中心的申请。
这意味着算力基础设施的选址正在被政治化。结果就是美国境内数据中心的土地和电力成本会被推高，间接抬升推理单价。对依赖海外算力做视频生成的服务商来说，合规成本要提前算进模型里。如果你和做视频生成的朋友聊，可以问他，如果算力必须留在美国境内，视频生成这种高推理成本的品类，毛利结构会怎么变？这可能是明年定价策略里最容易被忽略的一个变量。
好，接下来是今天最核心的部分，赛道深挖。
第一条，也是今天对 API 平台最直接的一条：OpenRouter 上 DeepSeek 系列集体大降价。我念几个关键数字你感受一下。deepseek-v4-pro-0813，输入价维持在每百万 token 1.32 美元不变，但输出价从 11.5 美元直接砍到 3.96 美元。deepseek-v4.1-flash 更狠，输入从 0.30 美元降到 0.0507 美元，降了大约 83%，输出从 1.20 美元降到 0.2028 美元。还有 deepseek-v4-flash-vision-exp，输入从 0.44 降到 0.2156，输出从 1.32 降到 0.6468。同时平台上还新增了 qwen3.8-27b、minimax-m2.7、gemma-4-26b 这些新档位，batch 档位也同步下调了。
这不是一次普通的价格调整，这是腰斩式的下探，直接把中端推理的价格锚点拉低了一个数量级。对咱们做视频生成 API 的平台来说，含义非常明确：文本和多模态理解这一层的成本正在快速商品化，你没法再靠这一层做差异化，差异化只能往生成质量和分发体验上走。举个具体的例子，当 V4.1 Flash 的输入价降到每百万 token 5 美分，那在视频生成的工作流里，提示词理解这一环基本可以认为是免费的了。所以如果你跟做视频平台的朋友聊，可以问他，提示词理解成本归零之后，你们的价值主张准备往哪挪？
第二条，Google DeepMind 的 Genie 4 向开发者开放了。DeepMind 的博客确认 Genie 4 已经可用，Latent Space 的 AINews 把它和 Anthropic 的 IPO 并列，列为当天最重要的两件事之一。这是 Google 在交互式世界模型上最新一代的产品化落地。
Genie 系列代表的是可交互的生成环境。开放给开发者，意味着视频生成正在从出片段走向出可玩的场景。对视频 API 平台来说，这是一个非常明确的信号：下一波需求可能不是生成一段视频，而是生成一个可以被 Agent 操作的环境。换句话说，你的竞争对手可能不再是 Runway，而是游戏引擎。这个角度我觉得特别适合跟海外创始人聊，你可以问他，如果世界模型开放了，视频生成平台到底是往内容工具走，还是往环境基础设施走？
第三条，来自 36Kr 的报道，AI 短剧赛道出现了极端的估值背离。相关标的用 2.57% 的营收占比，撑起了 120% 的股价涨幅，然后三个跌停，蒸发 41 亿元市值。文章的核心论点是，定价权不在做剧的人手里。
这是 AI 视频内容侧最真实的一手信号。它说明产能已经过剩到让资本市场用脚投票了，真正稀缺的是分发渠道和 IP，不是生成能力。对视频生成 API 平台的含义是，客户要的已经不是更便宜的秒数，而是能直接对接分发和变现的工作流。你可以问问做短剧的朋友，产能已经不是瓶颈了，那视频生成 API 到底该往分发对接上加码，还是往质量提升上加码？我猜答案会越来越偏向分发。
好，说完了赛道，我们看看 Agent 前沿。
第一条，Nous Research 的开源 Hermes Agent 推出了一个叫 Collective Wisdom 的功能，中文可以理解成集体智慧。它能把单个员工摸索出来的 Agent 用法，沉淀成团队级的技能。报道还说，企业很快可以直接在 Microsoft Teams 里运行这个开源 Agent。
这条为什么值得关注？因为 Agent 落地真正的瓶颈，从来不是模型能力，而是经验没法复制。一个员工会用，不代表整个团队会用。把个人技巧自动转成组织资产，解决的是 Agent 从 demo 到规模化的最后一公里。而且它绑定 Teams，等于直接进入了企业的分发渠道。你可以想想，Agent 的护城河会不会根本不是模型，而是团队内部沉淀下来的那套技能库？这个问题，跟做企业软件的创始人聊会很有共鸣。
第二条，RadixArk 发布了 DaisyRose-27B，这是一个纯强化学习后训练的、单卡就能跑的 Agentic 编程模型。它基于 Qwen3.8-27B 做后训练，Apache 2.0 许可，只用强化学习，不做 SFT，把 Terminal Bench 4.1 的 pass@1 从基线提升了一倍以上，到 12.0，而且能在单张 GPU 上运行。
这条证明了一件事：小模型加纯 RL，能在 Agentic 任务上做出可用的性价比方案。单卡可跑意味着边缘部署和低成本 Agent 服务成为可能。对做 Agent 产品的团队来说，这是把推理成本压到极低的一条现实路径。你可以问一句，27B 纯 RL 就能把终端任务通过率翻倍，那大模型在 Agent 场景里的溢价还站得住吗？这个问题现在还没有定论，但值得持续跟踪。
下面是几条快讯，我按主题给你串一下。
安全方面有两条。OpenAI 强化了对抗蒸馏防护，针对 GPT-6.2 Astra 和 Sol 的推理内容提取攻击，自适应红队测试的成功率从 54% 降到了 0.2%，同时每周封禁数千到数万个参与协同蒸馏的账号。另一边，Signal 在 iOS 27 和 Android 上开始屏蔽截图，目的是阻止 Siri AI、Gemini、Meta Muse 这些 Agent 读取私聊，Signal 称这是对隐私的生存性威胁，但也承认 macOS 等平台的防护还不完整。
平台和入口方面。Apple 入局了设备控制型 AI Agent，在 Meta、OpenAI、Anthropic、Google 之后也开始自建能操作设备的 Agent，同时收紧第三方对其设备的访问。Google 搜索首页全球上线了可折叠侧栏，AI Mode 可以重开历史 AI 搜索、建 notebook，搜索进一步向 AI 答案引擎演化。
模型方面还有一条。NVIDIA 开源了 Nemotron-Labs-Sigma 连续扩散语言模型，14 个 3B 和 8B 的 checkpoint，在 16 维嵌入空间去噪，蒸馏到少步采样器，解码速度最高能达到自回归的 4.2 倍。这条可以和前面 Nvidia 收购 Inception 那条连起来看，Nvidia 在扩散语言模型上是双线下注。
好，最后是今天的观察和商业机会，我用聊天的语气跟你说。
今天所有信号的引力中心，其实就是 Anthropic 的 IPO 破发和纳斯达克回吐全年涨幅。它意味着资本市场不再无条件为 AI 叙事付费了，接下来我们会看到模型公司收敛补贴，更认真地做单位经济。与此同时，OpenRouter 上 DeepSeek 系的价格腰斩式下探，说明推理层正在快速商品化，模型能力的溢价窗口在收窄。这两股力量叠加，对视频生成 API 平台的结果是：靠接入更多模型已经不够了，价值必须往工作流、分发对接和生成质量上迁移。而 Agent 侧反而出现了反向信号，Hermes 的技能沉淀和 DaisyRose 的单卡纯 RL，都在把 Agent 的成本和复制门槛往下压，这恰恰是下一阶段可以承接视频生成能力的地方。
基于这个判断，我看到两个比较具体的机会。
第一个，面向 AI 短剧和短视频团队，做生成加分发对接的一体化 API 层。依据就是 36Kr 那条报道，2.57% 的营收撑起 120% 的涨幅，三个跌停蒸发 41 亿，产能已经过剩，分发才是稀缺资源。视频生成 API 平台完全可以把模型调用和平台侧的分发、投放、变现接口打包在一起，卖给那些已经过了能不能生成这个阶段的制作团队。
第二个，为 Agent 产品提供低成本的视频和图像生成工具调用层。依据是 DaisyRose-27B 单卡可跑，加上 Hermes Agent 的技能沉淀进 Teams 这两条。Agent 正在进入企业工作流，推理成本又在快速下降，而 Agent 需要生成素材这类工具能力。视频生成平台可以把自己封装成 Agent 能直接调用的标准工具，抢占 Agent 生态里的生成入口。
总结一句：叙事溢价的时代在退潮，谁能把生成能力嵌进分发和 Agent 的工作流里，谁就能拿到下一轮的定价权。今天就聊到这儿，我们明天见。
