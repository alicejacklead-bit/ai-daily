早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 10 月 29 号，星期四。今天这期信息量特别大，我挑了最重要的三件事先给你垫个底：第一，Google 在 Gemini 4 Argon 之后仅仅两周，又甩出了 Gemini 4 Carbon，主打编码、Agent 和网络安全，直接登顶了 Artificial Analysis 的智能指数；第二，入口之争全面开打，Google 把 Android Studio 和 Search 向第三方 Agent 开放，Cursor 也把自己的 Agent 能力做成了 SDK 对外输出；第三，大模型价格战继续升级，大客户直接打一折，四个月降价八成，单纯卖 token 的生意越来越薄了。好，我们一条一条展开。
先说 Google 的 Gemini 4 Carbon。这事儿最震撼的地方不是它多强，而是它的节奏。距离 Gemini 4 Argon 发布才两周，Carbon 就来了，在 Artificial Analysis Intelligence Index v5 上拿了 59 分登顶，SEC-bench Pro 拿到 88.2%，定价是每百万 token 输入 2 美元、输出 10 美元。为什么重要？因为前沿模型的迭代周期已经被压缩到两周这个量级了，这意味着你上个月做的模型选型评估，这个月可能就过时了。而且这次 Google 把网络安全能力当成核心卖点，但相关访问初期只向经过审核的安全专家开放。对从业者来说，如果你在做安全类或者编码类的产品，我建议你尽早去申请这个受审核访问，抢做一个 Carbon 的能力展示页，这个时间窗口不会太长。
紧接着是 Google 向第三方 AI Agent 开放 Android 开发。Android Studio 上线了一个叫 Bring Your Own Agent 的功能，支持 Claude Agent、Codex 等四十多个编码 Agent 接入。同时他们还推出了新的终端工具，让 Agent 完成 UI 任务快 77%，token 用量最多降到三分之一。这件事的意义在于，移动开发的工作流正在被 Agent 化，而且 Google 把 Agent 生态的入口向第三方敞开了。如果你手里有一个垂直场景的 Agent，现在可以认真考虑把它接进 Android Studio 生态，去移动端开发这个场景里获客，这是一个正在快速膨胀的新工作流。
同一时间，Google 还向更多应用开放了 Gemini 和 Search，推出了新的开发者平台，企业可以把自家服务接入 Google 的 AI 体验。这条的重要性我给满分，因为它可能改变消费级应用的发现和使用方式。AI 搜索正在变成新的应用分发渠道，Agent 在重塑 Web 入口。我的建议很直接：尽早提交你的服务接入，去抢 AI 搜索时代的应用曝光位，这种分发红利期通常只有几个月。
再说 Cursor 发布 Agent SDK。Cursor 把自己的 Agent 能力以 SDK 的形式对外提供了，在 Hacker News 上讨论热度很高。这条的核心价值是，编码 Agent 的能力现在可以被嵌入你自己的产品，你不需要自己从零搭一套 harness。如果你想快速给内部工具或者垂直 SaaS 加上编码和自动化 Agent，这是目前最省事的一条路。
然后我们说说钱的事儿。Anthropic 推出了一个 AI 支出可视化工具，在企业客户面前揭开了模型花费的黑箱，而且这个时点选在计划 IPO 之前，意味深长。为什么重要？因为 AI 成本终于可以归因了，企业采购决策有了可审计的依据。对从业者的启示是，你对外报价的时候可以附上一个成本归因看板，这会明显降低企业客户的采购阻力。与此同时，InfoQ 报道大模型价格战已经没有退路，大客户直接打一折，模型四个月降价 80%。API 的毛利在被持续压缩，你必须重新审视自己的模型选型和转售加价空间，能锁长约折扣的尽早锁。
接下来这条是语音赛道的重磅。Nvidia 开源了 Nemotron 3.5 Transcribe，转写、翻译、说话人识别三合一，用文本 prompt 就能控制任务，多项 benchmark 领先，而且激活参数只有最强开源对手的六分之一，同时还放出了八十万小时以上的语音数据集和微调工具。这意味着什么？语音多任务的开源 SOTA 来了，小参数、低成本、可以自托管。如果你在做会议、播客或者客服转写产品，现在可以直接评估用它替换掉付费的 ASR API，成本结构会完全不一样。
再看生成侧。Google DeepMind 发布了 Genie 4 实时世界模型，原生支持音频，研究预览版加入了实时对话和文本操控，由 Gemini 3.8 Flash 在仿真循环里规划事件。可交互的世界模型正在向有声实时演进，这对游戏和仿真素材来说是一个新的内容来源。想做互动内容或者游戏原型 Demo 的团队，可以用它做出差异化的东西。
另外一条值得单独说的是 AI Agent 攻破 Anthropic 内部系统这件事。安全创业公司 Cathedral 通过第三方软件，在漏洞赏金项目里打进了 Anthropic，官方确认销售、HR、IT 的数据被访问，但对渗透深度还有争议。这条的核心信号是，供应链是 AI 实验室最薄弱的环节，Agent 攻击已经实战化了。对创业者的启示很明确：面向 Agent 时代做第三方依赖审计和红队服务，切的是企业实打实的安全预算。
好，重点的几条讲完了，下面快速过一下其余消息。
模型和评测方面，Artificial Analysis 改版了 Intelligence Index v5，开源和闭源的差距被拉大，Kimi K3.1 Pro 排名下滑五位，而且 v5 有六成权重基于私有测试集，结果不可复现，社区质疑声不小。这件事提醒我们，选型基准的可信度本身已经成了风险项，别只看总分，要按你自己的任务拆子项、自建评测。企业合作方面，OpenAI 和 ServiceNow 扩大了合作，OpenAI 的模型和 Agent 进入 ServiceNow，ServiceNow 的工作流进入 ChatGPT 和 Codex，企业工作流成了 Agent 落地的直接分发面。评测方法上，有个叫 Dayjob Tax 的项目用五十个真实税务任务来评测 AI Agent，在 HN 上讨论很热，做垂直专业服务的可以照这个方法自建你所在行业的评测集。
开发者生态方面，GitHub Octoverse 2026 的数据很惊人，合并 PR 数一年内增至三倍，达到每月 2.2 亿，提交量每月 73.8 亿次，增量主要集中在下半年，Agentic engineering 对代码协作平台的冲击被彻底量化了。国内方面，个人 Agent 走热，上海徐汇两家新秀拿下了大额融资，两种个人 Agent 范式正在分化，赛道融资窗口打开了，但范式还没收敛。
产品方面，Meta 低调上线了一个叫 Waddle World 的应用，十六位像素风格的宠物游戏外壳，内核其实是伪装成宠物的每日日记，主打语音而不是打字对话，宠物还会生成涂鸦插图。这个形态挺新颖的，多模态生成被包装进了轻量情感陪伴产品，做陪伴类出海小应用的朋友可以研究一下。
开源项目这边，MiniMax 开源了 MCode Stack，是它编码团队日常使用的 Agent Skills，MIT 许可，包含十七个 SKILL 技能和五份清单，覆盖代码审查、子 Agent 拆分、上下文预算和长时命令，一线团队的工作流可以直接复用。Expo 官方也放出了 AI Agent 技能集合，移动开发框架开始官方供给 Agent 技能，生态卡位战开打了。还有一个有意思的项目 casecite，有人把 Harvey 那个刚融了五亿美元的法律 AI 开源复刻了，法律 AI 的高价值场景有了开源底座。最后一个脑洞项目 Qwenputer，把三十二位 RISC-V CPU 直接塞进 Qwen 模型的权重里执行指令，作者说对工具调用和 computer use 可能有意义，这个方向很极端，但值得关注它对工具调用可靠性的影响。
论文方面我快速点几个。EmbeddingGemma 2 是一个统一高效的多模态嵌入模型，原生统一表示文本、图像、音频、视频和混合模态，各类嵌入 benchmark 上都创了新 SOTA，做多模态检索的可以试试替换现有分模态管线。VibeVideoBench 是评测代码驱动视频生成的多模态 Agent，二百三十九个中英双语任务，专门针对扩散视频模型没法精确渲染公式、图表和规则一致游戏的问题，给 Agent 写代码逐帧渲染这条路线立了标尺。T-DIG 给图像生成引入文本条件化的多样性，让多图返回的多样性随用户意图变化，这对图像生成产品的选图转化是直接利好。AlphaBet 用强化学习训练 LLM 事件预测 Agent，把证据搜索纳入学习回路，预测类 Agent 从给定证据走向自己找证据。还有一篇 h1 讲自动定理证明里的苦涩教训，检验一个简单的 Agentic 循环加上扩大测试时计算，能不能匹敌人类设计的复杂编排工作流。Scaling Laws for Tool-Use Agents 提出 SynthAPI 管线，沿工具、任务、数据库三轴控制合成环境的多样性，工具型 Agent 的训练数据可以按需合成而不是靠采集。Your Policy Is Secretly a Harness 这篇解释了换 harness 就掉点的根因，Agent 工程终于有了理论抓手。Heads of Security 用学习式的注意力门控提升提示注入鲁棒性，防御思路从对齐微调转向可插拔的注意力层改造。FlashMap 一次并行起草十六个 token，在 Qwen3-8B 上实测最高 6.14 倍无损加速，直接压低单位 token 成本。
好，下面是今天的观察。今天最值得注意的信号，是入口之争同时在三个层面展开。模型层，Google 用 Gemini 4 Carbon 把前沿模型的迭代压到了两周；开发工具层，Android Studio 和 Search、Gemini 同时向第三方 Agent 开放；能力层，Cursor 把 Agent 做成了 SDK 对外输出。这三件事叠加起来说明一个趋势：模型层的价格战让单纯卖 token 的生意越来越薄，价值正在向两端迁移，一端是分发入口，一端是垂直工作流。中间层如果没有自己的场景和入口，会非常难受。第二个被低估的变化是评测基础设施本身在动摇，Artificial Analysis v5 六成权重基于私有测试集、不可复现，开源模型在最有吸引力的象限里清零，选型时自建评测正在从加分项变成必选项。第三个是安全侧出现了两个方向的强信号：Agent 已经能实战攻破顶级实验室的第三方依赖，而防御研究也开始从对齐微调转向可插拔的注意力层改造，攻防两端都在加速。
最后聊聊商业机会和研究建议，用聊天的方式说。
商业机会我看到三个。第一个是面向中大型企业的 AI 支出归因轻量工具。Anthropic 刚把模型花费可视化做成了产品，但它只覆盖自家模型，而现实中多模型混用的团队非常多，他们需要一个跨供应商的成本归因看板。这个判断的依据就是 Anthropic 那个支出可视化工具，加上价格战里大客户一折、四个月降八成的报道，成本波动这么大，企业一定需要看得清。第二个是 AI 帮不上忙的行业诊断服务和内容 IP。Amazon 工程领导层有句话在圈内传播得很广，说如果你的工作没从当前 AI 工具中受益，那是一个发现，不是失败。企业现在普遍缺一份清单，告诉他们哪些环节现在还不该上 AI。你可以做成按行业交付的诊断报告，这个依据就是 Terk Terkowitz 那个观点，再结合之前 Apollo 经济学家说 AI 对多数企业零财务回报的报道，需求是真实存在的。第三个是移动端 Agent 开发工具链的配套产品。Android Studio 开放了四十多个第三方 Agent，UI 任务快 77%、token 省到三分之一，Expo 也官方放出了 skills，围绕移动 Agent 的调试、评测、token 预算管理做工具，切的是一个正在快速膨胀的新工作流。
研究建议也是三个。第一，亲手复现 FlashMap 的投机解码，在 Qwen3-8B 上接入它的 flow map drafter，实测那个 6.14 倍无损加速在你的推理栈上到底能兑现多少，再对比不同 batch size 下的收益曲线，这直接决定你自托管 API 的成本模型。第二，精读并小规模验证 Your Policy Is Secretly a Harness 这篇，固定模型、只替换 harness，量化能力保留率，给你自己的 Agent 产品建立一套换 harness 前后的回归测试集。第三，用 VibeVideoBench 的二百三十九个任务做一次横评，对比扩散视频模型和 Agent 写代码逐帧渲染，在公式、图表、规则一致游戏这三类任务上的成功率，判断代码驱动视频值不值得作为你的产品主线，这对图像和视频生成平台有直接的产品含义。
好，今天就聊到这儿。一句话总结：模型迭代以周计、入口向 Agent 全面开放、价格战压缩 token 生意，价值正在向分发入口和垂直工作流两端迁移。我是 Andy，我们明天见。
