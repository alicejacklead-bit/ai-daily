今天信息挺密的，我给你捋三条主线。第一条，Anthropic 那边信用市场和舆论场同时冒烟，九千亿美元的债务承诺被华尔街按垃圾级来定价。第二条，也是我个人觉得今天最该盯的，OpenRouter 那张价格表，六款模型同一天涨跌分化，旗舰降价、小模型涨价，这对我们做视频生成 API 的人是直接的成本信号。第三条，Agent 这边出现了第一个真正意义上的“渠道对平台”谈判样本，Amazon 和 Meta 为了 Meta 的购物 Agent Muse，坐下来谈条件了。剩下还有阿里云百炼的模型变动、纽约州禁 AI 玩具、以及一串联快讯。我们一条一条来。
先说 Anthropic。华尔街日报报道，Anthropic 已经承诺出去的债务规模到了九千亿美元，而华尔街现在的预期是，它的债券会被评为 junk，也就是垃圾级。这个事得放在背景里看：它发生在 Anthropic IPO 破发、股价跌破 83 美元发行价之后。我的理解是这样，IPO 破发是二级市场的情绪，是投票；但九千亿债务被按垃圾级定价，这是信用市场的判决，是称重。这两件事性质完全不同。它意味着什么？意味着前沿实验室那套“用未来的算力承诺换当下的估值”的模式，开始被债权人打折了。债权人不看你的模型跑分，只看你的现金流久期和偿付能力。后续融资成本会上升，算力采购的节奏也会被挤压。这里有个特别好的谈资角度，如果你最近跟做基础设施或者做基金的朋友聊天，你可以问问他怎么看“实验室的债务久期比模型迭代周期还长”这件事——模型十八个月换一代，债务可能要还七年，这个错配谁来承担。
紧接着第二条，还是 Anthropic，但是换到舆论场。Dario Amodei 公开回应了竞争对手的指责，有人说他主张把人类的控制权让渡给 AI，他直接说这很荒谬。背景是，即便头部公司正在越来越多地自动化自身的研究和模型开发流程，他依然否认这个立场。同一天，杨立昆在另一个场合批评他，说渲染 AI 危险只是想让开源模型变成非法。你看，这就很有意思了。安全叙事正在从“技术共识”退化成“竞争武器”。我的判断是，当监管讨论进入实质阶段，谁定义“危险”，谁就定义了合规成本。这对我们这些做模型分发、做 API 转售的玩家来说，是一个直接的政策风险变量，不是远处的热闹。你也可以拿这个跟做开源的朋友聊：安全话语一旦被当成竞争工具，开源阵营和闭源阵营的监管游说会怎么分化，最后买单的是不是中间那层做分发的。
市场局势最后一条，稍微换个画风。纽约州通过了一个禁令，禁止面向儿童的 AI 聊天玩具，为期五年。依据是 Common Sense Media 的一份新研究，发现这类产品存在暴露不当内容、影响情绪发育这些安全失效。这是美国州级层面第一次对“具身化的对话 AI 消费硬件”下重手。做 C 端创作工具、做 Agent 产品的团队要注意一件事：面向未成年人的语音和对话交互，正在变成监管高压区，分龄设计不再是可选项，而是准入门槛。你可以想一想，AI 硬件的合规成本会不会把中小团队直接挤出儿童市场——这其实是个挺现实的问题，儿童市场本来单价就不高，合规成本一压，模型就崩了。
好，下面进今天最核心的部分，赛道深挖。
第一条，OpenRouter 主力模型表，六款模型同时重定价，涨跌剧烈分化。我念一下数字，你感受一下幅度。DeepSeek V4 Pro，输入价从每百万 token 1.28 美元降到 0.68 美元，输出价从 2.56 降到 1.55，基本是腰斩。但同一个家族的 DeepSeek V4.1 Flash 反向大涨，输入从 0.03 涨到 0.15，输出从 0.2 涨到 0.6，这是五倍和三倍。Qwen 那边四款同步调整：Qwen3.5 397B A17B，输入从 0.45 涨到 0.5，输出从 3 美元涨到 3.6；Qwen3.8 27B，输入从 0.06 降到 0.035，输出从 1.96 降到 1.5；Qwen3.6 35B A3B，输入从 0.05 涨到 0.1，输出从 0.7 涨到 0.89；Qwen3.5 9B，输入从 0.17 降到 0.1，输出持平在 0.25。
这里的关键不是涨还是跌，而是同一张表上，旗舰在降价、小模型在涨价。这说明什么？说明聚合平台做的不是统一让利，而是按算力稀缺度做动态定价——大模型那边产能上来了、竞争激烈，就往下压；小模型那边需求爆炸、推理请求量堆上来，就往上抬。说白了，聚合层开始用供需定价，而不是用成本定价。对我们做视频生成 API 分发的团队，这个信号非常直接：上游成本的波动会更快、更频繁地传导到终端报价，长周期锁价合同的对手方风险在上升。如果你跟做视频平台的朋友聊到这件事，我建议你问他一个很具体的问题：聚合平台把模型价格做成实时行情之后，模型厂商自己还剩多少定价权？这个问题现在没人有标准答案，但问出来就显得你在盯这条线。
第二条，阿里云百炼的模型列表有一个变动：decision-model，也就是结构化决策模型，正式上线转正，同时 decision-model-preview 被移除。页面没有体现价格变化，所以这是一次纯粹的从预览到正式版的替换。这件事看起来小，但方向很重要。结构化决策模型转正，意味着国内云厂商开始把“决策”当成一个独立的模型品类来正式售卖，而不是通用对话模型的一个子能力。对做 Agent 编排、做视频工作流自动化的团队来说，这类模型可能比通用大模型更适合干那些脏活：流程路由、素材筛选、批量判断哪个镜头能用哪个不能用。你可以顺着想一层：决策模型独立成品类之后，Agent 的编排层会不会变薄？以前编排层自己写一堆规则和判断逻辑，现在可能直接调一个决策模型就完事了，那中间层的价值就得重新找了。
第三条，量子位的一个实测。他们报道了一款工具，丢一个故事进去，直接生成 15 分钟的 AI 短片，定位是零门槛，“家里二舅也能上手”。同一天另一篇报道展示了商汤 SenseNova U1.6 的图像生成效果，说达到了“以为是摄影作品”的水准。这两条要连起来看。15 分钟连续叙事，这是视频生成从“片段工具”跨到“成片工具”的那道门槛线，它直接冲击的是 AI 视频创作平台的时长套餐设计。你想想，如果单次生成就能覆盖一部成片的长度，那按秒计费的 API 商业模式，就会被按“成片条数”计费挤压。这不是价格战的问题，是计价单位变了。跟做视频平台的人聊，你可以直接抛这个问题：当一次生成就能出 15 分钟成片，视频 API 还该按秒卖吗？我自己的答案是，按秒卖会退化成一种“素材批发”的定位，而成片交付会走向项目管理式的定价，中间那层按条卖的套餐，可能是最先被压掉的。
好，进 Agent 前沿。
第一件，也是今天最重要的 Agent 新闻：Amazon 和 Meta 正在谈判，讨论解除对 Meta 购物 Agent Muse 的封锁。Amazon 是今年 9 月把 Muse 踢出平台的，现在双方僵在几个点上——推荐哪些商品、以及这事对 Amazon 广告收入的影响。关键数字有两个：Amazon 的广告业务年收入 686 亿美元；而 Muse 已经占据了全部 agentic shopping 订单的 51%。超过一半。
这件事的分量在哪里？这是 Agent 商业化第一个真正的“渠道对平台”谈判样本。Muse 拿到 51% 的 agentic 订单份额，意味着 Agent 已经握住了流量入口，平台方手里只剩商品和广告库存。以前是平台掌握货架、掌握用户，现在用户不逛了，用户让 Agent 去逛，那平台就只剩供货这一个角色。做 Agent 产品的团队要看清一件事：议价权来自订单份额，不来自技术。你技术再漂亮，订单份额百分之三，没人跟你谈。反过来，你占了过半订单，平台就得坐下来。谈资角度我给你一个：Agent 占到一半订单之后，平台到底该收“过路费”，还是干脆自己也做一个？收过路费是短期现金流，自己做是长期控制权，但做的话又会跟所有第三方 Agent 对立，这个选择很难。
第二件，Google DeepMind 让 AI Agent 接管了一部分 Gemini 实验的算力。The Decoder 报道，DeepMind 已经用 Agent 自主运行面向下一代 Gemini 模型的实验。研究负责人 Koray Kavukcuoglu 说，实验室距离递归自我改进还很远；而且为了便于审查，他们故意不对 Agent 的内部思维链做训练。他还说，他衡量 AGI 的标准是日常用户的信任度，不是 benchmark。
这条我特别想多说两句，因为它有两个信号。第一个信号，这是前沿实验室第一次公开承认，Agent 进入了自身研发闭环的算力调度层。注意是算力调度层，不是辅助写代码那种外围。第二个信号更微妙：可审计性正在成为设计约束。他们为了能审查，主动放弃对思维链做训练——这是一个明确的取舍，牺牲一点能力换可解释。对做 Agent 基础设施的团队，这里的机会是，“Agent 跑实验”这类长周期、高容错的任务，会成为最先规模化的场景。你可以跟做模型的朋友聊这个：Agent 参与自己下一代的训练，可审计性到底该怎么设计才不拖慢迭代？这个矛盾现在没人解决，谁解决谁就有东西卖。

资金和资本这块：LangChain 完成了 3 亿美元的 C 轮，估值 30 亿美元，CapitalG 领投，钱主要投到 LangSmith 这个 Agent 工程平台上。同一时间，CrowdStrike 以大约 439 亿美元的全股票交易收购 Zscaler，计划把“AI kill switch”从 AI 网关延伸到网络层，用来切断失控 Agent 的访问权限。
产品这块：OpenAI 在测试一个叫 Private Inference 的东西，企业可以在 OpenAI 完全无法访问数据的前提下调用它最强的模型。另外 Anthropic 把 Claude Artifacts 做成了 macOS 和 Windows 的独立桌面应用，免费账户就能用，支持菜单栏项、通知和透明窗口。这两个动作其实是一个方向：一个往下沉到企业数据合规，一个往上浮到用户桌面。
基础设施这块，有个挺科幻的：FCC 批准 SpaceX 部署最多 100 万颗搭载 AI 芯片的数据中心卫星，项目叫 Starmind，这是美国监管机构第一次放行太空 AI 数据中心。一百万颗，这个数字先记住，是不是真能发上去另说，但监管口子开了。
好，下面是今天的观察和商业机会，我们放松一点聊。
今天最值得记的一笔，我认为不是某个模型发布，而是 OpenRouter 那张价格表。六款模型同日重定价，旗舰降价、小模型涨价，这个组合说明聚合层已经在用供需定价，而不是用成本定价。它跟 Muse 的谈判其实是同一件事的两面：OpenRouter 在模型这一侧重新分配定价权，Muse 在流量这一侧重新分配议价权。渠道和 Agent，正在从平台的附庸变成能上桌的角色。再看资金面，两极分化非常明显：LangChain 以 30 亿估值拿到 3 亿，而 Anthropic 的九千亿债务承诺被按垃圾级定价。这两件事放一起，结论很清楚——资本正在从“押注模型能力”转向“押注 Agent 工程层和分发层”。能力已经不那么稀缺了，能把能力送到用户手里、能把成本管住的这一层，反而稀缺。对我们做视频生成 API 的平台来说，结论就一句话：上游价格波动会更快更频繁，锁价能力比单价高低更重要。单价低是暂时的，锁价能力是结构性的。
基于这个判断，我看到两个具体的商业机会。
第一个，面向 AI 视频创作平台做“多模型成本路由加动态报价”的中间层。依据就是今天 OpenRouter 六款模型同日重定价这件事，以及之前 fal 和火山方舟连续调整视频模型计费和入口的事实。矛盾在哪？视频创作平台上游价格高频波动，但自己的套餐价格是静态的，改一次价要走市场、要走客服、要担心用户流失，所以跟不上。谁需要这个东西？中小 AI 视频创作平台，还有做出海短剧的工具。为什么是现在？因为聚合平台已经把模型价格做成了实时行情，上游有行情了，下游还是静态标价，这中间就存在一个可套利的定价管理缺口。这个缺口不会一直在，但至少未来半年是有的。
第二个，给 Agent 产品补“可审计执行轨迹”的能力，切入企业采购的合规环节。依据是三条：一是 DeepMind 故意不训练 Agent 的思维链以便审查，说明连最头部的实验室都把可审计性当约束在设计；二是 CrowdStrike 花 439 亿美元收购 Zscaler 去做 Agent kill switch，说明安全厂商已经用真金白银投这个方向；三是 Anthropic 自己的研究显示，接近五分之一的 AI 部署没有产生业务价值，卡点就是审查负荷和内部瓶颈。谁需要？正在把 Agent 往生产环境推的企业 IT 和安全团队。为什么是现在？因为 Agent 已经进了研发闭环和电商交易这种高风险环节，可审计性已经从“加分项”变成“采购的前置条件”。以前是出了事再补，现在是没这个就不让进采购流程。
好，今天就到这儿。一句话总结：模型能力不再稀缺，定价权和可审计性才是这一层的新地基。我是 Andy，我们明天见。
