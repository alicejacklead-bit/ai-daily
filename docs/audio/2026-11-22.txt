早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 22 号，星期日。先给你今天的一句话：Anthropic 万亿 IPO 之后一周内破发，纳指跌入熊市，英伟达单周暴跌 14%，AI 资产的定价锚正在从"叙事"切回"现金流"，而这件事会直接传导到模型 API 的定价和分发谈判上。今天咱们重点聊三块：一是资本端这轮重估到底意味着什么，二是 API 分销层那些特别值得抄的定价新玩法，三是 Agent 侧从"能力"转向"运维"的几个信号。如果你正在通勤路上，泡杯咖啡，咱们开始。
先看市场局势。这一周美股 AI 板块创下了疫情以来最差的单周表现，纳斯达克 100 已经进入技术性熊市。英伟达单周跌了 14%，而且 SEC 正在审查它的会计处理；Anthropic 更戏剧化，创纪录的 IPO 之后一天之内几乎回吐了全部涨幅。AI 质疑、丑闻、利率上行、政策逆风，几股力量同时砸在此前过热的估值上。这件事说明什么呢？算力和模型这两层资产在被同时重估，下游 API 平台的采购成本、融资环境、客户预算都会跟着收紧。采购关键词正在从"最强模型"换成"便宜且稳定"。如果你跟做视频平台的朋友聊到这件事，可以问问他怎么看"英伟达跌的是估值还是订单"——这个问题的答案能立刻区分出乐观派和谨慎派，特别好用。
第二条，Anthropic 万亿 IPO 的冲击波在往外溢。智谱、MiniMax 都出现了明显下跌。逻辑是这样的：Anthropic 一上市，那些没上市的模型公司就被强行拉进公开市场的参照系里，一级市场给模型公司的倍数，现在要经受二级市场对亏损和算力支出的审视。核心争议就是，这个倍数撑不撑得住。这对咱们意味着什么？一旦模型公司估值锚定公开市场，API 定价就不再只是竞争手段了，它得变成能支撑估值的收入来源。所以你会同时看到涨价压力和降价抢量并存，而平台侧的议价窗口反而是打开的。跟 CTO 聊天可以抛一句："模型公司最终该是 SaaS 倍数还是云厂商倍数？"这是现在所有人都在想的问题。
第三条比较敏感，据路透报道，Anthropic IPO 的承销银行已经关闭了原本用来稳定股价的持仓。说白了，上市初期托价的那只手撤了，股价接下来更直接地暴露在市场供需下。护盘退出是 IPO 之后最敏感的时点信号，如果股价继续走弱，"AI 估值过高"的叙事会加速扩散，整个模型层的融资节奏都会受影响。所以我的看法是，护盘撤退之后的第一个季度财报，才是真正给模型公司定价的时刻。

第一条，OpenRouter 的主力模型表又调价了，这次很有意思，DeepSeek V4.1 Flash 的两个版本价格一涨一降。不带日期的稳定别名版本，输入价从每 token 零点零零零零零零零五零七美元微降到零点零零零零零零零四九八，输出从零点零零零零零零二零二八降到零点零零零零零零一九九二，基本是毛毛雨。但带日期那个版本，也就是十月十七号那个快照，反向大涨：输入从零点零零零零零零零三六美元涨到零点零零零零零零一五，差不多四点二倍，输出也从零点零零零零零零五涨到零点零零零零零零六。同一个模型的两个 SKU，价格方向完全相反。这说明什么？聚合平台在用"稳定别名"做低价引流，用"固定版本"做溢价。这是 API 分销层非常典型的定价分层手法，我建议你直接借鉴到自己的价格页设计上。视频模型迭代那么快，客户对"输出可复现"的需求又特别强，这中间的溢价空间是实打实的。跟同行聊的时候可以问一句：你有没有注意到聚合平台开始对"版本锁定"单独收费了？这是 API 分销的新玩法。
第二条，OpenAI 发布了 GPT-Live-1.1，全双工语音模型上线 API，最大的变化是待机计费从每分钟五美分降到了两美分。新版本还改进了多语言口音和转写质量，新增了 standby 模式，WebRTC 空闲时段按两美分一分钟计费。为什么这条重要？语音 Agent 的成本大头一直是"连接挂着不说话"的空闲时长，待机费砍掉 60%，直接改变了语音类产品的单位经济模型。更重要的是它给视频和多模态平台发了个信号：计费颗粒度正在从"调用"走向"会话状态"。你可以想想，永远在线的语音 Agent 会不会因此变成默认产品形态？这个问题值得跟做语音的朋友碰一碰。
第三条偏技术但很实用。OpenAI 发布了 GPT-6.2 Astra 和 Sol 的新提示词模板，针对三类常见毛病：回答太短、多余追问、写代码时过度测试。同时 API 侧有个行为变化要特别注意：编辑会话历史可能会丢弃 reasoning 内容，导致回复质量下降。这条容易被忽略，但凡你在做多轮会话编排、上下文裁剪，如果还按老方式改 history，输出质量会无声无息地掉下来，属于必须排查的兼容性风险。这其实是所有做 Agent 编排的团队都会踩的坑，见面直接交换踩坑经验就行。
然后是 Agent 前沿。
第一条，LangChain 公开了他们内部"知识工厂"的做法，我觉得这是今天最值得抄的架构。机制是这样的：执行任务的 Agent 在工作中标记出缺失或过时的知识，然后由一个专门的 curator agent 在后台去补齐，形成一个持续更新的闭环。它解决的是 Agent 落地最实际的问题——知识库腐化。一次性灌文档谁都会，难的是让知识库一直新鲜。把"维护知识"这件事本身交给 Agent，才更接近生产可用。所以下次跟人聊，可以问一句：你们的知识库是"定期重建"还是"持续自愈"？这个问题能立刻看出对方 Agent 系统的成熟度。
第二条，字节跳动联合多所美国高校发布了 Axion 1.0，只用三个训练阶段就对标 OpenAI 和 Anthropic 的顶级模型，而且模型、数据、代码全部开源。研究团队说，性能提升主要来自精心筛选的训练数据，而不是更多的训练步数。如果"数据质量大于训练阶段数"这个判断成立，Agent 能力的门槛就会从算力转向数据工程，中小团队做垂直 Agent 的可行性会明显上升，开源 Agent 模型的竞争也会更快。训练阶段是不是被过度设计了，这是当下最值得跟做模型的人争一争的技术判断。

好，来到今天的观察和商业机会。今天的信号其实高度一致：资本端在给 AI 资产重新定价，纳指熊市、Anthropic 护盘退出、未上市模型公司跟跌；而产品端却在继续压低单位成本，GPT-Live 待机费砍 60%、Inkling 2 Mini 用六倍成本优势对标、英伟达质疑长上下文。这两股力量一夹，模型 API 的中间层，也就是聚合和分发，价值反而上升了。因为客户要的就是两件事：同等能力下更低的账单，还有跨供应商的 failover。同时 Agent 侧的技术焦点正从"能力"转向"运维"，知识库自愈、可观测性治理、本地小模型跑 Agent，都是在为规模化交付做准备。对视频生成这种高单价、高波动的品类，接下来最该盯的就是计费颗粒度会不会也向"会话状态"演进。
具体两个机会。第一，给视频和图像 API 做"版本锁定加稳定别名"的双层定价。依据就是今天 OpenRouter 对 DeepSeek V4.1 Flash 两个 SKU 的一涨一降：稳定别名微降引流，固定日期版本涨价溢价。视频模型迭代快，客户对输出可复现又有强需求，正好推出"锁定版本"付费档，用可复现性换溢价，同时用别名档承接价格敏感的客户。第二，把"待机计费"的思路引进视频生成工作流。依据是 GPT-Live-1.1 把空闲连接从五分钟降到两美分。视频创作是长会话、多轮改稿的场景，如果平台按"渲染队列等待、草稿挂起"分档计费，而不是按次计费，能显著降低创作者的心理成本，也能提高留存。这恰恰是现在视频 API 普遍按次计价留下的空档。
总结一句：资本在收紧，成本在下降，中间层的分发和计费设计，就是接下来最值钱的手艺。今天就聊到这儿，我们明天见。
