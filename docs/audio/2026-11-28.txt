早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 28 日，星期五。先给你今天的一句话：WaveSpeedAI 把 Seedance 2.5 的限时促销价摆上了首页，视频模型 API 的竞争，已经从“谁有模型”变成“谁能在黑色星期五把价格打到对手不敢跟”。
今天的内容挺密。市场层面有三件事：Nvidia 的出口管制从禁芯片升级成卡通道，马斯克公开承认 xAI 落后、同时拿 GPU 浪费开刀，还有 OpenAI 反诉 Apple。赛道深挖我们重点讲三个：WaveSpeedAI 的黑色星期五限时入口、OpenRouter 一口气上了八个模型条目并且价格剧烈分化，以及 Hugging Face 在 Trainium3 上跑视频生成。Agent 前沿是 OpenAI 的 Athena 语义层和多 Agent 评测方法论。最后聊聊今天最值得记的一条主线——成本纪律，以及从里面能挖出什么生意。我们开始。
先说市场局势的第一条，也是今天分量最重的一条。Nvidia 已经通知制造伙伴，暂停向马来西亚、新加坡、泰国、印尼这四个东南亚国家发货服务器，配合的是美国进一步收紧 AI 芯片流入中国的管制。注意，这次不是禁单颗芯片，而是卡整机和转口通道。同一时间彭博做了一轮调查，发现被禁的 Blackwell 芯片出现在了上海一处数据中心，序列号指向台湾厂商 Gigabyte。这两件事放在一起，信号非常清楚：东南亚过去两年扮演的“算力中转站”角色，正在被切断。
那这件事对谁最疼？其实不是大厂，是那些依赖海外算力部署的模型 API 平台。你想想，过去很多团队做海外推理节点，默认就是新加坡，因为延迟低、合规相对宽松、机房资源好拿。现在这个默认选项要重新算了。区域节点选址、合规成本、跨境数据路径，全部得推倒重来一遍。对做视频生成的平台来说更麻烦，因为视频推理是算力最密集的场景，节点一旦要迁，单位成本会立刻反映到 API 报价上。所以如果你和做视频平台的朋友聊到这件事，可以问问他，你们海外推理节点还放在新加坡吗？这几乎是当下最现实的架构问题，问出来对方一般都会愣一下，因为大多数人还没开始动。
第二条，马斯克这边。据 36Kr 报道，马斯克向员工承认，xAI 在 AI 模型竞赛中落后于对手，同时警告说，浪费 GPU 算力的人会被开除。这两句话放在一起看很有意思——一边承认落后，一边抓内部纪律。而且它不是孤立的，前几天还有 Nvidia 董事会让黄仁勋回归、白宫承认 Trump 介入的消息，整个叙事是一样的：算力和人事都在被重新收紧。
这说明什么趋势？头部厂商的竞争，正在从“堆参数”转向“算力纪律”。过去两年大家的逻辑是，只要卡够多、模型够大，就能追上。现在追赶者开始内部问责 GPU 利用率了，意味着模型层的边际投入回报正在被重新审视。这个变化会往上游传导：API 价格战的上游成本约束会变硬。也就是说，前两年那种“我先烧钱把价格打下去”的打法，底气没那么足了。这里有个很好的聊天角度，你可以和人聊：GPU 利用率是不是正在变成新一代模型公司的核心 KPI？这个指标其实比 benchmark 更能说明问题——benchmark 可以挑着报，利用率骗不了人。
第三条，OpenAI 和 Apple 彻底撕破脸了。OpenAI 在加州法院对 Apple 提起反诉，指控对方窃取商业机密、胁迫双方共用的供应商，这是对 Apple 今年夏天那起诉讼的回应。你回想一下，两年前这两家还在台上一起宣布把 ChatGPT 带进 iPhone，画面多和谐；现在 OpenAI 自建硬件，直接对标，关系从合作转向对抗。
这件事的本质，是模型公司和终端厂商之间，分发渠道正在被重新划分。对做 API 分发的平台来说，这是个必须盯住的变量：谁掌握终端入口，谁就掌握模型调用量。如果 OpenAI 真的把硬件做成了，那它的调用量就不再依赖别人的应用商店，反过来，Apple 那边也会更倾向于扶持自己的模型或者别的供应商。这里可以聊的话题是“模型公司到底要不要自己做硬件”，OpenAI 已经用一纸诉讼给出了它的答案。
好，接下来是我们最关心的赛道深挖。第一条，WaveSpeedAI。它的价格页上，原来那个“Seedance 2.5 Flash Now Live”的推荐位，被换成了“Seedance 2.5 Black Friday Edition — Limited-Time Deal”，直接导向 Video Generator。这是继前几天两档单价降幅从百分之五扩到百分之十之后的又一次动作，但性质变了——这次是限时促销，不是永久调价。
这个细节特别值得琢磨。聚合平台开始用电商式的限时折扣来卖视频模型调用了，这说明什么？说明视频生成 API 的获客成本压力，已经大到要靠节日促销来拉动。对我们做海外 GTM 的人来说，含义很直接：价格战接下来会以“促销”的形式反复出现，而不是一次性降价。这对定价体系是个坏消息，因为你的价格锚点不稳定了——对手今天挂个黑色星期五，明天挂个年终特惠，你永远不知道自己该对标哪个数。而且用户会被训练成等促销，这对复购和现金流都不友好。所以如果你和做视频平台的朋友聊，可以问他，视频 API 会不会变成黑色星期五式的季节性生意？这个问题听着轻，其实直接关系到他们明年的年度定价策略怎么定。
第二条，OpenRouter，这条信息量很大。它的主力模型表一次性新增了八个条目：deepseek-v4-flash-vision-exp、deepseek-v4-pro、deepseek-v4-pro-0813、deepseek-v4.1-flash、gemma-3-27b-it、gemma-3-4b-it、gemma-4-26b-a4b-it，还有 kimi-k2.5。价格分化非常剧烈。deepseek-v4-flash-vision-exp 的输入价几乎腰斩，降了大约百分之五十一，降到零点零零零零零零二一五六美元这个量级。而 kimi-k2.5 反过来，输入从零点零零零零零零五涨到零点零零零零零零六，输出从零点零零零零零零二五涨到零点零零零零零零三，各涨百分之二十。还有个细节，gemma-3-4b-it 的输入价反而上调了一点。
这三组数字放在一起，讲了一个很清楚的 story：视觉实验版在大幅降价，Kimi 在逆势涨价，小模型在试探性微调。翻译成平台语言就是——聚合平台上，“视觉能力”正在被当作引流品，而头部中文模型开始试探提价空间。对我们做 API 平台的人来说，选品结构会直接影响毛利：低价视觉模型负责带量、拉新、做活跃，高价文本模型负责带利润。你要做的不是每个模型都争，而是清楚哪个是钩子、哪个是现金牛。这里有个特别好的切口，可以和人聊“聚合平台的定价权到底在模型方还是渠道方”。Kimi 这次涨价就是最好的案例——它敢涨，说明它认为自己在某些场景里不可替代；那渠道方是接受，还是用别的模型替换它，就是定价权的直接体现。
第三条，Hugging Face 发了一篇博客，讲他们在 AWS 的 Trainium3 上实际跑 LTX-2.5 生成视频的实践。这是把视频生成从 Nvidia GPU 迁移到自研加速器的公开案例之一。
单个案例，但方向很重要。视频生成是算力最密集的推理场景之一，一旦非 Nvidia 路线跑通、跑稳、跑到成本可接受，视频 API 的单位成本结构会被整个改写。对以视频模型为主的平台来说，这是中期成本护城河的关键变量——注意是中期，不是明天。短期你还是得用 Nvidia，因为生态、工具链、稳定性都在那边；但中期如果你能有一半推理跑在非 Nvidia 上，你在价格战里就有了对手没有的空间。所以有个必答题，可以问对方：视频推理什么时候能不全靠 Nvidia？这个问题现在问，很多团队会说“还早”，但你能从他们的回答里听出他们有没有在认真准备第二方案。
好，接下来是 Agent 前沿。第一条，OpenAI 内部在做一个代号叫 Athena 的语义层，目的是给数据 Agent 提供统一的业务指标定义。起因是 ChatGPT Work 里的数据 Agent 准确率还不够——它经常答得挺像样，但数字对不上。
这个事要理解它的价值，得先明白 Agent 出错的一大来源是什么：不是模型不够聪明，而是指标口径不一致。你问“上个季度营收多少”，财务有一套定义，销售有一套定义，数据仓库里还有第三套。Agent 再聪明，它也得猜你用哪套。Athena 做的就是把这个猜测变成确定性的基础设施。这件事的分量在于，它解决的是企业级 Agent 落地的最后一公里，同时也意味着模型公司开始往数据栈上游走了——它可能直接和 Snowflake、Databricks 竞争。所以有个很好的聊天角度：Agent 的准确率瓶颈，是不是根本不在模型，而在语义层？这个问题和 CTO 们聊，会有很强的共鸣，因为大家被 Agent 的“看起来很对但数字错了”折磨过太多次。
第二条，Hugging Face 发了一篇叫“Swarms, Flocks, Gangs”的博客，系统梳理了多 Agent 系统的搭建、训练和评测方法。同期还有一个很硬的成绩：二十个 AI Agents 组队，四天里跑了三百五十次实验，把 Quickwit 的查询总耗时降了百分之三十一，最高降幅百分之八十七，超过了 ClickBench 的最佳公开成绩。
这两件事一起看，说明多 Agent 正在从“demo 炫技”进入“有评测方法论”的阶段。这个门槛很关键——有方法论意味着可以工程化复现，不再是碰运气。对准备进入 Agent 方向的团队，我的建议是：评测框架比框架选型更值得先建。因为多 Agent 系统的复杂度高，如果没有评测，你根本不知道改动是变好了还是变坏了。这里有个很好用的问题，可以问对方：你们的多 Agent 系统怎么评？大多数团队还答不上来，而答不上来的团队，通常也没法说清自己的系统到底稳不稳定。
下面是快讯，我用主题串一下。
基础设施和网关这块，nexos.ai 推出了一个 AI Gateway，把两百多个模型统一接入，还内置了预算限制和治理能力——这个方向和我们前面聊的成本纪律是同一个逻辑，企业现在要的不是更多模型，是能管住花多少钱。
支付这块有个英国的第一次：一个 AI Agent 在 Papa John's 完成了英国首笔无卡交易，涉及 FCA 和 TrueLayer 的参与。这件事的意义不在披萨，在于 Agent 开始被纳入正式的支付合规框架里了。
推理优化方面，腾讯开源了 DFly2 投机解码，在 64K 长上下文服务下吞吐最高提升百分之八十一，关键在于它的草稿层复用了目标模型的 KV cache 和 top-k 索引，不额外占草稿 KV 内存——对做推理成本的人来说，这类优化直接就是毛利。
模型发布方面，Sakana AI 发布了 Namazu Small 30B，是基于 Nemotron 3 Nano 的 30B-A3B 推理模型，在二十五项 benchmark 上平均六十点一分，超过了 120B 的 Nemotron 3 Super 的五十六点二分。小模型打赢大模型，这个趋势值得记住。

好，到了今天的观察和商业机会，我想用聊天的语气和你展开说说。今天最值得注意的，其实不是任何一个单点模型，而是“成本纪律”这个词同时出现在了三个完全不同的层面。上游，Nvidia 卡住了东南亚的转口通道，这是算力的地理层面；中游，马斯克因为 GPU 浪费要开除员工，这是公司内部的纪律层面；下游，OpenRouter 上视觉模型腰斩式降价、Kimi 逆势涨价，这是市场定价层面。三个层面同时收紧，说明视频和多模态推理的算力成本正在被重新分配，而谁能拿到便宜算力，谁就有定价权。WaveSpeedAI 用黑色星期五限时促销卖 Seedance 2.5，本质就是聚合平台在成本压力下，把价格战做成了季节性动作——它不是想降，是不得不降，但又不想把降价变成永久承诺。
Agent 这边，OpenAI 的 Athena 给了我们一个提醒：下一阶段的竞争不在模型能力，而在让 Agent“不出错”的基础设施。这个判断我觉得会越来越成立。
那从里面能挖出什么生意？我看到两个。
第一个，给视频 API 平台做“促销定价引擎”。依据很直接：WaveSpeedAI 把 Seedance 2.5 换成了黑色星期五限时入口，而且前几天的两档降幅还在反复调整。这说明什么？说明聚合平台需要一套能按节日、按模型、按渠道动态调价，同时能追踪对手价格页的系统。为什么是现在做？因为价格战已经从永久降价变成了高频促销，手工调价根本跟不上节奏。你想想，一个平台上有几十上百个模型，每个模型有输入价、输出价、不同档位，还要跟着节日和对手动作变，Excel 是撑不住的。
第二个，面向企业 Agent 的“指标语义层”轻量产品。依据是 OpenAI 的 Athena 要解决数据 Agent 口径不一致的问题，同时多 Agent 的评测方法论刚刚成形。中型企业没有自建语义层的能力，但它们非常迫切地需要让 Agent 的输出可以被核对——因为一旦 Agent 给的数字错了，业务方就再也不信它了。为什么现在切入？因为大厂刚刚验证了需求，标准还没形成，第三方还有窗口期。等 Snowflake 和 Databricks 把这事儿产品化，窗口就关了。
好，今天就聊到这儿。一句话总结：算力在被重新分配，价格战变成了季节性动作，而下一阶段的护城河，是让 Agent 不出错的基础设施。希望今天的内容能给你在通勤路上一点可以带进会议室的谈资。我是 Andy，我们明天见。
