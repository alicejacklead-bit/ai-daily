早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 2 日，星期一。先给你今天的一句话：OpenAI 把 ChatGPT 订阅改成 token 配额制，这是“无限 prompt”时代终结的第一张多米诺骨牌——按量计费会从 API 一路传导到所有 C 端创作工具。今天我们会重点聊三件事：第一，融资端和债务端同时收紧，支撑低价 API 的上游补贴正在退潮；第二，OpenAI 一边改配额一边封多账号，订阅制的套利空间被系统性堵死；第三，技术侧开始往架构提效走，DeepSeek 的 Router-Worker 把 p95 完成时间砍了一半。如果你在做视频生成的海外 GTM，今天这期信息密度不低，我们直接开始。
先看市场局势。今天最重磅的一条，是 OpenAI 这轮融资只募到 110 亿美元，而原本的目标是 300 亿。这不是小差距，是腰斩还多。同一时间，Google 承认 AI Mode 在伤害搜索收入，财报出来之后股价一度跌了 10%，被形容成 2004 年 IPO 以来最差的单日表现。这两件事放在一起说明什么？市场对“烧钱换增长”这套叙事的耐心，正在快速耗尽。对头部实验室来说，融资缩水会直接压缩两头的空间：上游的算力采购，下游的补贴。而对你们这种依赖低价 API 做分发的平台，最直接的影响是——上游补贴退潮，采购成本可能回升，你的定价策略要提前留出缓冲，别等到成本涨上来才改价。这里有个很好的谈资角度：如果你和做模型平台的朋友聊，可以问问他怎么看“融资额腰斩但算力承诺不变”这个剪刀差，钱到底从哪来？是债务，是收入，还是砍掉一部分长期投入？这个问题的答案，基本决定了明年的 API 价格曲线。
第二条，Meta 计划筹集近千亿美元规模的资金，Oracle 在这轮里报出了被称为“最后一笔”的份额。报道的核心疑问很直接：华尔街的耐心还剩多少，债券市场还愿不愿意继续为 AI 基建的巨额资本开支买单。这条的重要性在于，AI 基建的融资结构正在从股权转向债务。一旦债市收紧，数据中心和算力扩张的节奏会先于模型能力放缓，而这会影响未来 12 到 18 个月推理算力的供给和价格。这里有个细节值得你记住：债务融资撑起来的算力和股权融资撑起来的，对 API 定价的行为模式完全不一样。债务有还本付息的硬约束，厂商会更急于把算力变现，价格战可能更凶；但一旦现金流吃紧，涨价也会更突然。跟海外创始人聊天时，这是个很好的切入点，可以问问他们更怕哪一种。
第三条，Anthropic 的 Mythos 级模型据称泄露到了 Hugging Face，仓库名叫 numbat，Hacker News 上同时出现了两个讨论帖。目前还停留在“alleged”层面，Anthropic 没有确认。但这件事的意义不在于这一单个案例真假，而在于前沿模型权重泄露已经从传闻变成了反复出现的模式。这会让头部厂商进一步收紧 API 侧的能力暴露和反蒸馏措施，对做模型聚合和二次分发的平台是直接的合规风险。谈资角度给你一个：如果前沿权重真的会漏，闭源 API 的护城河到底靠什么维持？是算力规模、是工程效率，还是单纯的法务和信任？这个问题在海外创始人圈子里很有讨论度。
接下来是今天最核心的赛道深挖，这部分我们讲透一点。
第一条，OpenAI 把 ChatGPT 的 Chat 和 Work 两个模式合并成单一界面，并且从 12 月开始，Plus、Pro、Business 三档订阅共享一套基于 token 的配额，ChatGPT 和 Codex 共用。更复杂的模型消耗配额更多，简单的即时对话不计入。实际结果是什么？低价档的重度用户，能拿到的模型质量会下降。这是 C 端订阅从“包月无限”转向“按量计费”的标志性动作。为什么这对你特别重要？因为视频和图像生成这类品类，单次调用成本远高于文本，包月无限在数学上几乎必然走不通，一定会走向“基础额度加超额购买”。做 API 分发和创作工具的平台，现在就要重新设计套餐结构了。给你一个谈资角度，也是我认为所有创作工具都要回答的问题：视频生成按秒计费，订阅制还能撑多久？如果你和做视频平台的朋友聊到这件事，可以问问他，他们内部有没有算过重度用户的单位成本，以及超额购买的转化率假设是多少。
第二条紧接着，OpenAI 开始限制每台设备和每张支付卡可以绑定的付费账号数量。达到上限的用户没法新开订阅，受影响账号在该设备上不可用，而且登出也不会自动释放名额。这针对的就是同时持有多个低价订阅、最大化用量的那批用户，目的是把他们推向购买额外 credits 这类更贵的选项。这是订阅制“套利漏洞”被系统性封堵的信号。你要知道，多账号薅低价档这件事，在所有 AI 订阅产品里都普遍存在。头部厂商一旦验证这套风控有效，很快就会成为行业标配。所以做海外订阅分发的平台，要提前评估自己账号策略的合规边界，别等支付通道或者上游来问你。谈资角度：多账号薅订阅，到底是产品设计问题还是风控问题？我的看法是，当配额制上线之后，它就自动变成了风控问题，因为套利空间是配额制自己制造出来的。
第三条来自 Adobe，他们联合 UC San Diego 做了 EditAgent。思路很有意思：不是让一个通用编辑器反复重试，而是让 Agent 针对每个任务挑选合适的专用工具，再由标准语言模型基于可测量的图像数据选出最佳结果。方法有效，但代价是需要大约 10 倍算力。这给出了图像和视频编辑类 Agent 一条明确的技术路线——“工具路由加结果评估”优于“端到端重试”。对做 AI 视频创作平台的团队，这意味着什么？把生成模型封装成可以被 Agent 调用的专用工具，比做一个万能入口更有价值。同时 10 倍算力这个数字也说明，这条路目前只适合高价值场景，比如商业级修图、影视后期，而不是日常随手生成。谈资角度：编辑类 Agent 的瓶颈不在生成质量，在“选对工具”和“判断结果好不好”。这两件事恰恰是现在最缺基准测试的地方。
第四条是 Google 牵头的 StreamVibe，一个设计用来观看用户做饭或者组装家具、只在需要帮助时开口的视频 Agent。配套的 benchmark 显示，现有被测模型没有一个能在长视频里可靠地判断正确的介入时机，误差会累积，响应质量急剧下降。这是“实时视频理解加主动介入”这个方向的第一个明确的失败基线。对视频生成赛道来说，它划出了能力边界：长视频的时序理解仍然是硬骨头，做视频 Agent 产品时，“何时触发”比“生成什么”更难，也更可能是差异化所在。谈资角度很妙：视频 Agent 最难的不是看懂，是知道什么时候不该说话。你跟做视频产品的朋友聊，可以问问他，他们的产品里有没有“主动提示”这个功能，触发逻辑是怎么设计的。
好，接下来是 Agent 前沿，两条。
第一条，DeepSeek 开源了 dsh-superagent，MIT 许可的研究原型，采用 Router-Worker 架构，把 GitHub 和飞书上的请求转成并行的 worker 会话。在 DeepSeek 自己的模拟里，p95 任务完成时间从 29.5 分钟降到 15.7 分钟，几乎减半。官方明确说这只是验证技术路线的原型，不是正式产品，配套还有一篇设计文章叫《Exploring Super-agent Design》。为什么值得关注？因为 Router-Worker 把“任务分派”和“任务执行”解耦了，这是提升 Agent 吞吐最直接的结构性手段。p95 减半说明瓶颈在串行调度，而不在模型能力本身。对任何要做多步任务 Agent 的团队，这是可以直接借鉴的架构范式。谈资角度：Agent 的性能提升，一半来自模型，一半来自调度架构，你更愿意把钱投在哪边？我的答案是，模型你投不起，架构你可以马上改。
第二条，LangChain 的 Managed Deep Agents 发布 v0.10，新增浏览器操作能力，Agent 可以操作没有 API 的网站，需要登录时把浏览器窗口交给用户手动完成；同时加入异步子 Agent，用于后台任务。浏览器操作补上了 Agent 触达“没有 API 的长尾网站”这一环，而“把窗口交给用户登录”是很务实的权限设计。异步子 Agent 则让长任务不再阻塞主流程。这两点合起来，是把 Agent 从 demo 推向可交付产品的关键基础设施。谈资角度：Agent 要操作没有 API 的网站，“人类代登录”这个折中方案能撑多久？短期是刚需，长期大概率会被标准化的授权协议替代，值得盯一下这块的标准进展。
下面是快讯，我们快速带过。开源侧，Nace AI 开源了 Drex Max v1，一个 27B 的多模态决策模型，得分 67.52，可以在 Apple Silicon 上本地运行。模型修改工具 Heretic 发布 2.0，目前 37k GitHub stars、Hugging Face 上 8,500 多个模型、累计 8,800 万次下载，这次从“去审查”扩展到更通用的模型修改。多 Agent 协作那边有个很有意思的负面案例：50 支 Agent 团队在 Minecraft 里试图建文明，结果陷入“瘫痪性官僚主义”，没能建成可持续运转的文明。学术侧，西湖大学成立了世界模型研究中心，三年前开始布局，今年正式成立。安全侧，Parameter Labs 披露了一条针对 ChatGPT 账号接管的攻击链，利用的是 artifacts 里 HTML preview 的沙箱 iframe，可以触及 OpenAI API 和私有数据，OpenAI 已经修复。
最后是今天的观察和商业机会，我们用聊天的语气展开。
今天最值得记住的，其实不是某个模型，而是定价逻辑的集体转向。你看，OpenAI 一边把订阅改成 token 配额，一边封堵多账号套利，本质上是在承认一件事：“无限量”在推理成本面前不可持续。与此同时，融资端从 300 亿缩到 110 亿，Meta 转向千亿级债务融资，说明支撑低价 API 的上游补贴正在退潮。这两件事叠加，我的判断是：未来 6 到 12 个月，API 和 C 端订阅的价格大概率只会上不会下。而技术侧在往“架构提效”走，DeepSeek 的 Router-Worker 把 p95 砍半，LangChain 补上浏览器操作，都是在不换模型的前提下榨出产能。对视频生成这类单次成本高的品类，谁先把“基础额度加超额按量”的套餐设计跑通，谁就先拿到毛利。
基于这个判断，有两个商业机会值得你现在就看。第一个，给 AI 视频创作平台做“token 或者秒数配额”的套餐设计服务。依据就是 OpenAI 12 月起 Chat 和 Work 合并、共享 token 配额这条新闻——包月无限在视频品类必然失效。而中小创作工具团队普遍缺乏按量计费的产品和风控经验，他们需要现成的配额引擎、超额购买流程和多账号风控方案。现在正是他们被迫改造套餐的窗口期，而且这个窗口不会太长。第二个，面向海外中小团队做“Agent 工具路由”的中间层。依据是 Adobe EditAgent 的结论：选对专用工具优于反复重试通用模型，但需要 10 倍算力。你可以做一个把多家视频和图像生成模型封装成专用工具、由轻量模型做路由和结果评估的中间层，用更低的算力成本复现“专业级编辑 Agent”的效果，卖给做 AI 视频工作流的团队。这两个方向，一个吃定价转型的红利，一个吃架构转型的红利，都跟你现在的 GTM 位置很贴。
好，今天就到这里。一句话总结：补贴退潮、配额上线，AI 的定价逻辑正在从“无限”回到“按量”，而架构提效是这轮里唯一还能自己掌控的变量。感谢收听 Andy 的 AI 早报，我们明天见。
