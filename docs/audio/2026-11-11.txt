早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 11 日，星期三。先给你今天的一句话：Anthropic 以 70 到 78 美元每股启动 IPO 路演、目标估值最高 1.4 万亿美元，同时 Claude Fable 5.2 登顶模型榜——前沿实验室正把技术领先直接打包成公开市场资产，而模型价格战，在 Gemini 4 Carbon 那个先低价后翻倍的定价里，露出了新套路。
今天重点讲三块：一是 Anthropic 这场万亿级 IPO 路演，以及它对你上游成本意味着什么；二是纽约 AI 安全法落地和 Gemini 4 Carbon 的限期低价打法；三是赛道深挖里 MiniMax、WaveSpeedAI、OpenRouter 这几条货架和价格的变化。Agent 前沿有 Adobe 开放 MCP 和 eBay 封堵 Agent 一正一反两条，最后聊聊今天的观察和两个商业机会。
先看市场局势。第一条，也是今天分量最重的：Anthropic 在 11 月 10 日正式启动 Class A 普通股的 IPO 路演，发行价区间 70 到 78 美元每股，对应估值最高 1.4 万亿美元。同时它还通过私募，向 Google、Nvidia、Microsoft 这些锚定投资者募了 260 亿美元，公开募资规模最高 644 亿美元。更有意思的是结构：七位联合创始人都计划卖出相同数量的股份，按区间中值算，每人套现大约 2.5 亿美元，但公司控制权还留在手里。你要知道，此前市场预期一度从 1.5 万亿下修到 1.1 万亿，所以这次定价区间，是下修之后的正式确认，不是拍脑袋喊出来的高价。
这件事说明什么？这是 AI 实验室第一次以万亿级估值接受公开市场定价，等于把"前沿模型公司到底值多少钱"这件事，从一级市场的估值游戏，交给二级市场去投票。对你们这种 API 平台来说，上游供应商的资本结构和定价压力会跟着变——以前模型厂涨价，你只能接受；以后它涨价，股东和分析师会追问一句"凭什么"。如果你和做视频平台的朋友聊到这件事，可以问问他怎么看"创始人集体套现 2.5 亿、但仍然控盘"这个结构——这是对技术周期的信心，还是对估值窗口的判断？这个问题在海外创始人圈子里挺有讨论度的。
第二条，监管。纽约州开始执行它那部全面的 AI 安全法，要求 OpenAI、Anthropic 这类主要开发商注册、披露安全实践、上报重大事故，否则罚款。同一天，在马克龙的倡议下，八国政府和 OpenAI、Anthropic、Microsoft、Mistral AI 签署了"Paris Call for AI Safety and Security"，承诺建立关停机制、接受独立审计、披露已知风险——但注意，这个协议不含约束性制裁，也没有截止日期。
所以趋势很清楚：监管正在从"自愿承诺"转向"注册加上报加罚款"的硬约束，合规成本会变成模型厂商的固定开支，而且很可能沿着 API 链条往下传导。软性宣言和硬性立法并行，会是接下来一年的常态。这里有个很好的谈资角度：硬性注册制先在美国州一级落地了，你可以问对方，合规成本最终会由 API 调用方买单，还是压缩模型厂自己的毛利？这个问题没有标准答案，但特别适合在饭桌上听对方的判断。
第三条，Google。Gemini 4 Carbon 在两周的"网络安全防御者"限定测试之后正式向公众开放，Google 称它是最强模型，多项基准排名第一，部分场景领先 Anthropic 的 Fable 5.2，而且单任务成本不到后者一半。同步还预览了一个叫"/swarm"的功能，可以让多个 Agent 实时拆分复杂任务。但今天最值得注意的不是模型本身，是定价：输入 2 美元、输出 10 美元每百万 token，然后计划在 12 月 1 日翻倍到 4 和 20。
这是本轮最值得注意的定价信号——用上线低价加限期翻倍来抢开发者迁移，本质是把价格当获客工具用。对 API 聚合平台来说，这意味着 12 月之前有一波非常明确的迁移窗口，之后成本结构会突变。你可以问对方：这种限期低价再翻倍的打法，会不会变成前沿模型的标配？以及，敢不敢把生产流量押在这种定价上？这问题问出去，基本能看出对方是激进派还是稳健派。
接下来是今天的重点，赛道深挖，这块咱们讲透一点。
第一条，MiniMax 上线了基于 H3 的开放权重图像模型 MiniMax-H3-Image。定价页给得很细：输入 2.30 美元、输出 1.50 美元、合计 3.80 美元，Highspeed 版本 3.00 美元。同时推限时优惠，从现在到 11 月 17 日 16 点 UTC，H3 的 4K 图像生成总请求费用打五折。还有个细节值得注意：定价页把原来"视频套餐暂不支持 H3、需改用按量付费 API"的提示删掉了，改成引导到 LLM、Video、Image、Audio 全品类定价。
开放权重、低价、再加限时折扣，这是典型的"用价格换生态位"打法，直接对标 Seedream 5.5 的图像编辑场景。对你们 API 平台意味着什么？图像生成这一档的毛利空间会被进一步压缩，所以选品逻辑要更看重稳定性和多轮编辑能力，而不是单纯比单价。谈资角度给你一个：开放权重图像模型配上五折促销，你可以问对方，图像 API 会不会重演文本模型那条路——价格趋近于零，胜负全在稳定性？
第二条，WaveSpeedAI 的货架换血。它的定价页首页横幅，从"GPT Image 2.6 is LIVE — Flare & Sunburst"换成了"Seedream 5.5 is LIVE"，并引导到 Image Generator。这是继 fal 模型货架大换血之后，又一家聚合或推理平台把首页流量位让给了字节系的图像模型。
你要知道，聚合平台的首页横幅是最贵的流量位，换 banner 等于用真金白银投票。Seedream 5.5 在多家平台同时拿到主推位，说明它在多轮编辑上的能力已经被渠道侧认可，这会加速图像 API 的份额向少数模型集中。这里的问题很锋利：渠道主推位现在是不是比模型榜单更能决定模型的实际用量？如果你在跟海外创始人聊，这个问题能直接聊到他们的获客策略。
第三条，OpenRouter 的主力模型价格表又调了。新增了 google/gemini-4-carbon 和它的 batch 版，batch 版价格是标准版的一半。同时 deepseek/deepseek-v4.1-flash 的输入价大幅上调，输出价也涨了；而 minimax/minimax-m2.5 和 minimax-m3.1-flash 的输入价都在降。
同一张表上，一边涨价一边降价，这说明聚合平台上的"低价洼地"正在被逐个填平。对做成本优化的 API 平台，这意味着路由策略需要按周重算，而不是按季度。谈资角度：模型路由现在是不是已经变成一门需要每天盯盘的生意？这个问题问出去，做平台的人基本都有共鸣。
好，接下来是 Agent 前沿，两条，一正一反。
先说正的。Adobe 在 Max 大会上全面转向 Agentic AI，允许用户首选的第三方 AI Agent 通过 MCP 访问和修改 Creative Cloud 里的创意资产，同时更新了 Firefly Assistant；Photoshop、Lightroom、Premiere 新增自动去除物体、瑕疵等干扰元素的能力。Google 同一天宣布和 Adobe 深化合作，可以在 Drive 里编辑 PDF、在 Gemini 里用 Adobe 的 AI。
这件事解决的是什么问题？创意软件开放 MCP 入口，等于把"生成—编辑—交付"这条工作流交给外部 Agent 去调度，视频和图像生成模型就有机会从"出图工具"变成 Agent 工作流里的一个节点。它解决的正是 Agent 拿不到专业编辑能力这个痛点。值得关注的原因是，这直接改变了生成模型在价值链里的位置。谈资角度：Adobe 开放 MCP 之后，你可以问对方，生成模型会不会沦为 Agent 工作流里一个无差别的调用，品牌溢价还剩多少？
再说反的。据 The Verge 报道，eBay 似乎已经阻止包括 Meta Muse 在内的 AI Agent 浏览平台。一位读者说，他的 Muse Agent 连续几周在 eBay 上抓取并整理手表在售信息，最近被阻断了。这是 Agent 电商竞赛里最新一次"平台关门"。
这件事说明，Agent 的价值高度依赖能不能访问真实平台数据，平台一旦封堵，产品体验会瞬间退化。所以做 Agent 产品，必须提前设计"被平台拒绝"时的降级路径。这也说明 Agent 和平台的博弈才刚开始。谈资角度：平台开始按 UA 和行为封 Agent，你可以问对方，Agent 时代的数据获取，会不会重演当年爬虫和反爬那场军备竞赛？

好，到了今天的观察和商业机会，咱们聊得随意一点。
今天最值得记住的，其实不是某个模型，而是定价策略的分化。你看，Gemini 4 Carbon 用上线低价、12 月 1 日翻倍来抢迁移；MiniMax 用开放权重加限时五折来抢生态位；OpenRouter 上 DeepSeek 涨价、MiniMax 降价同时发生。价格已经变成获客和卡位的工具，而不是成本的自然反映。与此同时，上游资本面在收紧，Anthropic 以 70 到 78 美元路演、估值最高 1.4 万亿，等于把前沿实验室的定价权交给二级市场，以后模型想涨价，会更容易被追问"凭什么"。Agent 那两条线一正一反也很说明问题：Adobe 开放 MCP，让 Agent 进入专业创作流；eBay 封堵 Agent，则提醒所有人，Agent 的能力边界取决于平台是否开门。对你们视频和图像 API 平台来说，这意味着选品逻辑要从"谁便宜"转向"谁在多轮编辑和稳定性上被渠道反复验证"。
基于这些，今天有两个商业机会值得琢磨。
第一个，做"12 月 1 日定价切换"的成本路由服务。依据就是 Gemini 4 Carbon 会在 12 月 1 日从 2 和 10 翻倍到 4 和 20，而 OpenRouter 上 DeepSeek、MiniMax 多条线价格同一周也在动。需要按周重算模型路由的 API 平台和中小 SaaS 团队，缺的就是一个能自动比价、并在切换日前后自动重排流量的工具。这个窗口很明确，时间点也很硬。
第二个，为创意团队提供"Agent 可调用"的图像和视频生成中间层。依据是 Adobe 开放 MCP，让第三方 Agent 能访问并修改 Creative Cloud 内容，这意味着生成模型需要以 Agent 友好的方式暴露接口——稳定的多轮编辑、RGBA 透明输出、可回滚。而 Seedream 5.5 主打 100 轮编辑不偏色，MiniMax H3-Image 走开放权重低价路线，这两者正好可以组合成一个面向设计工作流的调用层。
好，今天就聊到这儿。一句话总结：当价格变成获客工具、估值交给二级市场、Agent 的边界取决于平台开不开门，API 平台的胜负手就从"拿到最便宜的模型"变成了"选对最稳的模型、算准每周的价格"。我是 Andy，我们明天见。
