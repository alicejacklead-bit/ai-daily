早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 5 日，星期四。先把今天的一句话讲给你听：OpenRouter 上六款主力模型价格同步下调，DeepSeek 单日吃掉全平台 53% 的 token——API 分发层的价格战和开源模型的市场份额争夺，正在同时加速。今天咱们重点聊三件事：第一，聚合平台这轮降价背后到底是谁在让利；第二，OpenAI 把图像模型推进到动图，对视频生成意味着什么；第三，Agent 的记忆和权限这两块基础设施，正在被谁补上。好，咱们开始。
先看市场局势。今天最扎眼的一条，是 OpenRouter 上主力模型价格集体下调。我念几个关键数字你就知道力度了：Kimi K3 的输入价从每 token 0.000000276 降到 0.000000192，输出端的降幅更明显；openai 的 gpt-oss-120b，输入从 0.00000015 直接砍到 0.00000002，输出从 0.0000006 降到 0.000000073，这个幅度已经不是打折，是换了个价位段；gpt-oss-20b、qwen3-235b、gemma-4-26b 也都在同步下调。有意思的是，deepseek-v4-pro 的输出端反而逆势微调上调了一点点。你要注意，这是继此前一轮集体涨价之后的反向修正，说明什么？说明开源权重模型的边际成本还在快速往下探，聚合层的竞争逻辑已经从"涨价试探"转成"抢份额"。对做 API 分发的平台来说，这是两头挤压：上游模型降价，下游客户立刻就会拿着截图来找你要求同步让价，毛利空间被夹在中间。如果你和做聚合平台或者做视频 API 的朋友聊到这件事，可以问问他，你觉得这轮是模型厂商主动降价抢量，还是平台自己在补贴换 token 份额？这个问题一问，对方基本就会露底。
紧接着第二条，是份额数据。有第三方统计显示，在 OpenRouter 单日 27 万亿 token 的调用量里，DeepSeek 一家就占了 53%，开源权重模型实验室合计占比超过 75%。这个数字非常关键，它说明海外开发者的调用重心已经明显偏向开源权重模型。对闭源 API 是实打实的定价压力，而对做模型分发的平台来说，这是一个选品信号：谁的模型在聚合层跑量，谁就掌握议价权。你手上如果有多模型接入的能力，那排在前面的应该是跑量最大的那几个，而不是名气最大的那几个。跟海外团队聊天的时候，这个问题很值得直接问：你们生产环境的 token，大概有多少比例跑在开源权重模型上？从闭源切到开源，触发点是什么，是价格、是延迟，还是某个具体能力？答案往往比新闻本身更有信息量。
第三条，美国中期选举。这次有 45 项数据中心相关措施进入 ballot，选民压倒性地投票反对相关开发；NBC 的出口民调还显示，只有 56% 的受访者把 AI 和数据中心列为重要因素，而腐败是 90%，生活成本是 89%——AI 议题在选民优先级里基本垫底。这意味着什么？算力扩张的地方审批环境正在收紧，选址和合规成本会往上走，最终会间接传导到推理和训练的单位成本。对视频生成这条重度依赖大规模 GPU 的赛道来说，这是一个中期成本变量，不是今天明天的事，但一定会来。聊到算力成本的时候，你可以问问对方，有没有已经在为"拿不到地"做分布式部署或者海外部署的预案。
好，接下来是今天的重头戏，赛道深挖。
第一条，OpenAI 上线了 Images 2.6，ChatGPT 第一次能原生生成动图 GIF。你可以用文字 prompt，也可以上传照片，生成动图之后还能调动画速度、逐帧编辑、直接分享。官方给了一个数字：用户每周生成的图片已经超过 40 亿张。而且 Images 2.6 的角色一致性，已经足够支撑那种逐帧"翻页动画"式的效果。这件事为什么对你要紧？因为图像模型开始往"轻量动态内容"延伸了，它直接侵入了短视频和动图素材的生产场景。对视频生成 API 平台来说，短期看是入口分流——那些简单的动效需求会被图像模型顺手吃掉，用户根本不会专门去开一个视频工具；中期看是能力边界的重新划分，谁能在"低成本动图"和"真视频"之间给出清晰的产品分层，谁就能守住付费转化。这里有个谈资角度特别好用：你可以问对方，你怎么看图像模型向上吃动图、视频模型向下做轻量动效，这两条产品线会不会正面撞上？做视频平台的朋友对这个问题的焦虑是真实的，问出来往往能聊很久。
第二条，国内这边，虎鲸文娱集团在 11 月 4 日推出了"鲸锐 AI"，号称是行业首个 AI 影视制作与管理平台，官方说法是能把 AI 视频的单分钟成本降低 30% 以上，覆盖制作和管理全流程。这条的重点不在"首个"这个词，而在那个成本数字。这是国内影视级 AI 视频从"工具"走向"平台加工作流"的信号，而且它直接打出了成本。对视频模型 API 平台意味着什么？意味着大客户以后会用"整条制作流水线的单分钟成本"来跟你谈判，而不是按 token、按秒跟你比价。你的定价叙事得从"我的模型能力多强"转向"你能帮我把成片成本压到多少"。这个转变对 GTM 来说是根本性的。你可以问问海外做影视 AI 的团队，他们给客户报价，是按生成秒数算，还是按成片分钟算？大部分还在按秒，但客户脑子里想的是分钟，这中间的错位就是机会。
第三条稍微轻一点，但很实用。BytePlus 的 ModelArk 价格页新增了一个入口，叫"退役模型迁移指南"，指向模型下线与迁移流程。这条看起来不起眼，但它说明模型生命周期管理正在成为 API 平台的标准配套。对做分发的平台，这是可以复用的信任资产：B 端客户最怕的从来不是贵，而是生产环境里的模型某天突然被下线。谁能把"退役到迁移"做成有文档、有过渡期、有一键切换的流程，谁在 B 端谈判里就多一张牌。你可以问对方，你们平台上模型的平均生命周期有多长，下线之前给客户留多久的迁移窗口？这个问题问出去，对方如果答不上来，那说明这块他还是空白。
再来看 Agent 前沿。
第一条，openJiuwen 发布了 Agent-Memory，让 Agent 第一次拥有"视听双流记忆"，长视频问答的时延最高降低 97%。它做的事情是给 Agent 加上视觉和听觉两条流的记忆机制，能对长视频做关键事件的召回，官方说长视频记忆精度显著提升。为什么值得关注？因为长视频一直是 Agent 记忆的短板——上下文根本塞不下，检索又抓不准。视听双流记忆把"看过的视频"变成可检索的结构化记忆，这直接打通了视频生成平台往"视频理解加创作 Agent"延伸的路径。你想想，一个创作 Agent 如果能记住用户前面改过什么、哪个镜头调过色、哪句台词被否掉过，体验就完全不一样了。可以问问对方，做视频创作 Agent，最难的是生成质量，还是"记住用户前面改过什么"？我猜很多人的答案是后者。
第二条，Google 发布了 Data Agent Kit，把 Agent 的安全防护拆成 Skill 层和 IAM 层两套机制。能力封装归能力封装，身份权限归身份权限，分开治理。这说明企业 Agent 落地的卡点，正在从"能不能做"转向"敢不敢给权限"。这个架构范式是可以被其他平台借鉴的，也解释了为什么大厂的 Agent 产品最近都开始强调权限边界，而不是一味强调模型能力。你可以问对方，企业客户在 POC 阶段最先问的，是效果，还是权限和审计？如果是后者，那你的销售材料顺序就得改。

好，到了今天的观察和商业机会，我用聊天的语气跟你说。
今天最值得记的是两条线，一条是价格与份额，一条是能力边界。价格这条线，OpenRouter 上六款主力模型同步降价，同时 DeepSeek 单日吃掉全平台 53% 的 token——你把这两件事放一起看就明白了，降价不是孤立的促销，它是在为开源权重模型抢份额服务的，聚合层的定价权正在从平台手里，转移到跑量最大的模型方手里。能力边界这条线，OpenAI 用 Images 2.6 把图像模型推进到动图，虎鲸文娱用"单分钟成本降 30%"把视频生成拉进影视流水线，两端同时往中间挤压。而 Agent 那边，Uber 上季度 4 单这个真实数据提醒我们，替代型 Agent 还很早，但记忆和权限这类基础设施正在快速补齐——下一波竞争会先发生在"Agent 能不能被信任地接进生产系统"，而不是"Agent 能不能做演示"。
那商业机会在哪？我看到两个。第一个，是面向视频创作平台的"模型生命周期与迁移"服务包。依据就是 BytePlus ModelArk 新增退役模型迁移指南这条。视频生成 API 平台可以主动向影视、广告类大客户提供模型版本锁定、下线预警和一键迁移方案，把客户最怕的"生产中断"变成一个可以付费的确定性服务。这东西成本不高，但谈单的时候特别好用。第二个，是为视频和图像 API 平台做"成片成本"定价层。依据是虎鲸文娱那个单分钟成本降 30%，加上 OpenAI 的动图能力这两条。你可以在按 token、按秒计价之外，增加按成片分钟、或者按可交付素材计价的套餐，直接对接影视和营销客户的预算口径，这样就不用陷在和开源模型比单价的泥潭里。
最后用一句话总结今天：价格在往下走，份额在往开源走，能力边界在往中间挤，而 Agent 真正的门槛，正在从"能不能做"变成"敢不敢用"。好，今天就聊到这儿，希望你在通勤路上有所收获。我是 Andy，我们明天见。
