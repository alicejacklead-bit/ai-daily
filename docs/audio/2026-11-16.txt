早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 16 日，星期一。先给你今天的一句话：OpenRouter 上六款主力模型同一天调价、涨跌互现，模型 API 的“货架价”已经从季度级波动变成周级波动，聚合平台正在变成模型定价的真实发现机制。今天咱们重点聊三件事：第一，芯片出口管制升级成立法加国会调查，算力成本这条线要重新算账；第二，美团用昇腾跑出一个 1.6 万亿参数的 Agent 模型，全程没碰 Nvidia；第三，也是最贴近你日常的，OpenRouter 和 WaveSpeedAI 这些聚合平台的货架正在快速换血，比价窗口明显在缩短。好，咱们一条一条来。
先看市场局势。第一条，黄仁勋辞任之后的连锁反应又升级了。The Verge 报道，民主党和共和党都表态支持多项收紧 AI 芯片出口的法案，还要求黄仁勋等 Nvidia 高管到国会作证。另一边，The Decoder 引用华尔街日报的说法，黄仁勋的前伴侣 Alice Huang 拥有的公司 Megaspeed，在 2024 到 2025 年间为中方企业安排了接近 120 亿美元的 Nvidia 芯片订单。做空机构 Culper Research 估算，Nvidia 实际的中国营收占比超过 20%，远高于官方披露的 7%。这件事说明什么？芯片出口已经从单纯的行政管制，升级成了立法加国会调查的组合拳。行政管制可以随政府更替松动，但一旦写进法律、配上国会听证，合规成本就变成了长期的结构性成本，而不只是一次性冲击。对算力供给和模型训练成本的传导会滞后，但会持续。如果你和做算力或者模型训练的朋友聊到这件事，可以问问他：如果实际中国营收占比是官方数字的三倍，那大家一直挂在嘴边的“算力稀缺”定价假设，是不是该重新估一遍了？
第二条，美团发布了 LongCat-2.5，1.6 万亿参数的 Agent 模型，全程没有用 Nvidia GPU。这个模型是面向 AI Agent 场景的，在 Terminal Bench 上拿到 88.4 分，仅次于 Claude Opus 5。示例部署跑在 194 颗华为昇腾芯片上，官方通稿里一个字都没提 Nvidia。这条的意义在于，它是“国产算力到底能不能撑起前沿 Agent 模型”的一次公开答卷。如果这个结果可以被复现，那就意味着 Agent 模型的训练供给不再单一依赖 Nvidia 生态，对模型 API 的长期成本曲线来说，这是一个明确的利好变量。跟人聊天的时候你可以抛这个问题：1.6 万亿参数跑在昇腾上拿到 88.4 分，你会把它当成“中国版 Opus”，还是当成“算力去美化”的信号？这两个解读，指向的商业判断完全不一样。
第三条比较轻，但值得放在观察列表里。Anthropic 官网的 news 页面新增了一条 11 月 15 日的条目，页面快照能看到这个日期，但摘要里没有给出标题和正文。在 IPO 路演窗口期，Anthropic 任何官方页面更新都可能牵动估值叙事，不过这条信息量确实不够，只能当待跟踪信号，不宜过度解读。真要和创始人聊，可以问一句：IPO 前夜，官网每一条更新都会被放大，你更盯它的产品线，还是更盯它的合规口径？
接下来是今天的重头戏，赛道深挖。第一条，OpenRouter 主力模型表六款同时调价，涨跌分化，还新增了 gpt-5.6-sol 和 gpt-oss-20b 两个档位。咱们把数字过一遍，你感受一下这个分化有多明显。deepseek-r1-0528 输入价降了大约 12%，输出价也小幅下调。deepseek-v4.1-flash-1017 降得最狠，输入降了大约 47%，输出降了大约 78%。但有意思的是它的 batch 版本，输入降了，输出反而涨了大约 69%。再看涨价这边，openai/gpt-5.6-sol 输入输出都涨了大约 10%；qwen3.5-9b 输入涨了大约 37%，输出涨了大约 36%；gpt-oss-20b 输入涨了一倍多，输出没动。另外 qwen3-vl-30b-a3b-thinking 直接从表里移除了。这说明什么？DeepSeek 系在大幅降价，OpenAI 和 Qwen 的小模型在涨价，聚合平台上的价格已经按“任务分层”重新定价了——便宜的模型继续卷推理成本，贵的模型卷能力溢价，不再是整体涨或整体跌。对做视频模型 API 的平台来说，这意味着“同一个货架上摆多个模型”的比价压力，会更快地传导到视频侧。这里有个特别值得琢磨的细节：batch 版的输出价反而涨了 69%。如果你和做视频平台的朋友聊到这件事，可以问问他怎么看——批处理折扣这件事，是不是正在被重新定义？以前 batch 等于便宜，现在可能等于“便宜的是输入，贵的是输出”。
第二条，WaveSpeedAI 首页主推位换血了。价格页快照显示，新增了“Seedance 2.5 Flash Now Live”的横幅，同时撤下了“Seedream 5.5 is LIVE”那条。这已经不是第一次了，之前是 Seedream 5.5 上主推位、GPT Image 2.6 撤下，现在又轮到图像模型下、视频模型上。为什么这条对你特别重要？因为视频模型聚合平台的主推位，是需求侧最灵敏的那根指针。从图像模型主推切回视频模型主推，说明平台判断当下的流量和付费意愿都在视频侧。对视频生成 API 平台来说，货架位就是渠道话语权，谁占住首页横幅，谁就拿到第一波试用流量。跟同行聊的时候可以问：聚合平台的主推位从图像切回视频，你觉得是需求变了，还是供给变了，也就是有新模型上了？这两个答案，决定你该盯用户增长还是盯模型发布节奏。
第三条，Replicate 价格页删掉了 CPU Small 档位，也就是 cpu-small，原来标价是每秒 0.000025 美元、每小时 0.09 美元、2GB 内存。快照显示这个低价 CPU 实例条目整体从价格页移除了，其他 GPU 档位没看到对应的新增。这个档位平时不起眼，但它通常是轻量推理、预处理、Agent 工具调用的入口。入口档位消失，可能意味着平台在把低价流量往 GPU 或者托管推理上收。对依赖廉价 CPU 跑预处理管线的视频、图像工作流来说，这是一个成本信号，尤其是那些把抽帧、缩放、格式转换放在 CPU 上跑的小团队，得提前算算账。可以问一句：聚合平台砍掉最便宜的 CPU 档，是在清理低毛利流量，还是在为托管推理让路？
好，换到 Agent 前沿。第一条，GitLab 19.5 把智能体开发纳入了可治理的 DevOps 平台能力。具体说，就是把 Agent 的开发流程接进统一的 DevOps 治理体系，Agent 的构建、权限和发布都纳入既有平台管控。这条解决的是什么问题？Agent 从“个人脚本”走向“企业资产”，卡点从来不是模型能力，而是治理——谁批准、谁能改、出了问题谁负责。把 Agent 纳入 DevOps 治理，等于给 Agent 上生产补上了组织流程这一环。这是个很值得关注的信号，因为企业采购 Agent 的时候，第一个问题往往不是“你模型多强”，而是“出了事谁签字”。跟做企业客户的创始人聊，可以问他：Agent 上生产最大的阻力，是模型不行，还是没人敢给它发布权限？
第二条，多用户、多 Agent 的记忆提取，谁该记住什么、什么必须保密。有一篇叫 MixUA 的论文，提出了一套多粒度记忆系统，把独立的用户和 Agent 交互轨迹蒸馏成“经验”，然后为每条经验判定：哪个用户、哪类异构 Agent 能从中受益，哪些信息必须保持私有。这解决的是自进化 Agent 共享经验时最大的隐患——跨用户信息泄露和经验错配。这条把“记忆共享”从工程技巧升级成了权限与隐私问题，是 Agent 产品做多租户时必须回答的问题。你可以这样问对方：Agent 之间共享“经验”的时候，你更担心它学错，还是更担心它把别人的东西学走？这两个担心，对应的是完全不同的产品设计。
下面是快讯，我按主题串一下。模型能力这边，Anthropic 的 Claude Fable 5.2 很有意思，它不“生成”图像，而是“画”图像——不算像素，而是写 Python 代码在虚拟画布上落几十万笔模拟笔触，一张写实停车场场景大概 70 万笔。语音这边，Bland 发布了 Tofu-1 全双工语音模型，面向嘈杂、高风险的电话通话场景，目前是企业研究预览，没有公开基准、参数量，也没定价。就业这边，澳大利亚央行发现 AI 先冲击年轻劳动者，软件开发和客服这类暴露度高的岗位，15 到 24 岁群体的招聘和就业自 ChatGPT 发布以来下滑幅度大于年长群体，不过作者也提醒，商业周期和远程办公趋势可能也是解释因素。人事这边，李沐加入 Aimotion，联合打造产业级世界模型，这条对做视频生成的人值得留意。开源社区这边，AG-UI 协议单日涨了 393 个 star，这个协议是把 Agent 接入前端应用的 Agent-User 交互协议，热度在持续升温；同一天 Univer 办公 SDK 涨了 1041 个 star。
好，到了今天的观察和商业机会，咱们聊得随意一点。今天我的整体感受是，价格信号比模型信号更值得读。你看 OpenRouter 上，DeepSeek 系大幅降价、OpenAI 和 Qwen 小模型涨价、batch 输出价反向上涨，这三件事放在一起，说明聚合平台已经按“任务分层”重新定价，而不是整体涨或整体跌。供给端同时出现了两条分叉：美团用昇腾跑出 1.6 万亿参数的 Agent 模型，Anthropic 用“写代码画画”绕开像素生成，这俩都在证明，前沿能力不必沿着同一条算力和架构路径走。需求侧呢，WaveSpeedAI 主推位从图像切回视频，Replicate 砍掉最低价 CPU 档，这是渠道在重新分配流量和毛利。对视频模型 API 平台来说，比价窗口正在从季度压缩到周，货架位和档位设计本身就是竞争力。
顺着这个判断，我看到两个具体机会。第一个，做“跨聚合平台视频模型比价与成本路由”这一层。依据就是今天这三条事实：OpenRouter 六款模型同日调价、WaveSpeedAI 货架轮换、Replicate 砍低价 CPU 档。视频和图像工作流的调用成本已经进入周级波动，面向中小 AI 创作团队，提供一个按任务自动选模型、自动切档的路由服务，解决“同一个提示词在不同平台价差和质量差都很大”的问题。这个生意的窗口期，恰恰就是比价从季度变成周的这个阶段。第二个，为多租户 Agent 产品提供“记忆权限”中间件。依据是 MixUA 论文指出的跨用户经验共享和隐私边界问题，再加上 GitLab 19.5 把 Agent 纳入治理体系这个方向。面向正在把 Agent 推向企业客户的团队，提供经验蒸馏时的可见性判定和审计能力。为什么是现在？因为 Agent 正从单用户脚本进入多租户生产环境，治理缺口会先于需求暴露出来，谁先补上，谁就拿到企业单子的入场券。
最后用一句话总结今天：模型价格在按任务分层重定价，算力路径在分叉，渠道货架在周级轮换——对做视频模型 API 的你来说，盯住货架和档位，比盯住榜单更重要。好，今天的早报就到这里，我们明天见。
