早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 10 月 27 号，星期二。通勤路上这几分钟，我帮你把过去二十四小时里最值得关心的 AI 动静捋一遍。
今天最重要的三件事：第一，OpenAI 发布中端模型 GPT-6.1 Terra，API 价格直接腰斩，每美元智能创了新高，这会实打实地压低所有 Agent 的推理成本；第二，Anthropic 正式递交 S-1，准备以 ANT 这个代码登陆纳斯达克，这是第一家 IPO 的前沿实验室，财务底牌第一次摊在桌面上；第三，Agent 的围墙开始出现了，二手奢侈品平台 The RealReal 升级反爬，专门封堵 AI 购物 Agent。另外还有一条值得单独拎出来说：非英语 prompt 的“分词器税”被量化了，多语言产品的成本模型得重算。
我们先从价格这条最硬的信号说起。
OpenAI 这次推出的 GPT-6.1 Terra，定位是中端模型，但 API 价格比前代减半，在 Artificial Analysis 上拿到 48 分，日常任务和计算机控制场景下的“每美元智能”创了新高。这件事为什么重要？因为它意味着你用中端价位就能拿到接近旗舰的智能水平。过去大家做 Agent，最大的成本项就是推理，尤其是那种要跑几十步、反复调工具的任务，token 烧得飞快。现在价格砍半、分数还涨，等于直接把 Agent 的推理成本打下来一大截。
对在座各位从业者意味着什么？最直接的动作，就是把你们平台的默认模型切到 Terra 去跑批量任务，把省下来的预算投到视频生成、图像生成这些更烧钱但也更能做出差异化的地方。另外，结合今天 Meta 计划最高发售 950 亿美元股票为 AI 基建融资、SpaceX 和 Apollo 锁定 400 亿美元 GPU 融资这两条消息看，推理供给还在猛加，中端价位的价格战远没到头。所以如果你正在跟供应商谈长约锁价，我的建议是先缓一缓，中端模型的价格还有下探空间。
接下来说 Anthropic 的 IPO。这家公司正式向 SEC 递交了 S-1，拟以 ANT 登陆纳斯达克。招股书里的数字很扎眼：季度营收 116 亿美元，首次实现经营利润，老客户支出同比增长 9 倍。但同时，它也背着大约 8000 亿美元的长期算力承诺。这是首家 IPO 的前沿实验室，意义在于，前沿模型的财务底牌第一次公开、可对比了。以前大家只能靠传闻猜哪家赚钱哪家在烧钱，现在有了统一口径的报表。
对从业者来说，招股书里最值得抄的其实不是财务数字，而是它披露的企业交叉销售打法。你可以把它的思路搬进自家 API 平台的大客户续约话术里——老客户支出能同比增长 9 倍，靠的不是不断拉新，而是让已有客户在同一个账户里越用越多。这个逻辑对所有做 API 生意的人都成立。
同一份招股书里还藏着一个容易被忽略的信号：Anthropic 承认数据中心越来越依赖天然气供电，并说与电力供应和数据中心选址的竞争“非常激烈”。这条单独看像花边，但放在一起看就很清楚——算力扩张的瓶颈正在从芯片转向电力，成本结构会长期上移。所以如果你做的是面向欧洲或者合规要求高的客户的 API，把“能效”写进营销材料，会是一个很实际的差异化点。
第三条重点，是 Agent 撞墙。The RealReal 这家二手奢侈品平台，在 The Verge 曝光它的预订系统可以被 Agent 利用之后，更新了 bot 防御，让 AI Agent 更难在它站点下单。这条的重要性我给满分，因为它标志着一个分裂：电商对 Agent 的态度，从“欢迎接入”分成了“接入”和“封锁”两派。Agent 电商的基础设施缺口一下子就暴露出来了。
对做 Agent 购物场景的团队，两个动作：一是优先选有开放接口的商家合作，别把宝押在靠模拟点击硬闯的路径上；二是在产品设计里预留“被封之后的降级路径”，比如自动转人工、或者切到备用商家。今天商业机会环节我还会展开讲这块，因为我觉得这是一个正卡在需求爆发前的窗口。
再来是那条“分词器税”。Rest of World 报道说，同样的内容用非英语表达会消耗更多 token，导致非英语用户的模型使用成本系统性偏高。这件事的核心价值在于，多语言产品的成本模型里存在隐性的不平等，你现在的定价和配额设计可能得重算。
举个具体场景：如果你给全球用户统一定价，那些说高 token 消耗语言的用户，实际上在悄悄吃穿你的毛利。所以应用上的建议是，给非英语市场做单独的 token 预算和定价档，别用一刀切的统一价。这条对做出海产品的团队尤其重要。
最后一条重点，我想讲讲代码安全 Agent 的商用落地。CodeRabbit 用 GPT-6.1 Sol 做代码库安全审查，让安全 Agent 在复杂代码库里排查风险，再让开发者复核发现和修复建议。同时 Greptile 用 GPT-6 Astra 把 bug 检测扩展到了代码审查之外，通过测试用户工作流、强化安全、减少返工，形成一个完整的开发闭环。
这两条放在一起看，说明编码 Agent 的竞争点正在从“生成代码”转向“验证与回归”。生成代码这件事已经卷得差不多了，真正值钱的是能不能保证代码不出事。对 API 平台来说，把安全审查做成增值插件、按仓库数或者扫描次数计费，是一条已经被验证的付费路径。而在自家 Agent 产品里加一个“工作流级测试”环节，会成为对开发者很有说服力的卖点。
好，重点讲完，下面快速过一遍其余消息。
模型和资本层面：Meta 拟最高发售 950 亿美元股票为 AI 基建融资，说明超大规模资本开支还在加码，推理供给中期看涨，价格战还会继续。SpaceX 与 Apollo 锁定 400 亿美元 GPU 融资，算力资产证券化在加速，非模型公司也在抢 GPU 供给，你可以关注 GPU 租赁市场报价的变化，作为自建还是租用推理容量的决策依据。
人事和组织层面：微软向最多 6 万名员工开放自愿离职，覆盖美国、英国、加拿大、印度，大厂人力结构继续向 AI 基建倾斜，工程管理岗位承压。Proton 更激进，要对员工“重新面试”评估 AI 能力来决定去留，把 AI 熟练度直接绑定了雇佣关系。这两条对做企业培训、AI 能力评估类产品的团队是好消息，需求是实打实的。
应用落地层面：Fanatics 用 OpenAI 做“搭配推荐”，大约 3 万件 MLB 商品测试中互动率提升 10%，这是图像和商品理解类 AI 在电商转化上少见的可量化收益样本。IEEE Xplore 上线了 AI 研究助手，基于数百万篇同行评审全文，回答都 grounded 在可验证的科研结果上，作为可选订阅升级提供，这说明垂直文献库加检索增强，是订阅制 AI 很稳的一条变现路径。
内容生产层面：有三个 AI Agent 开始“当记者”，积极向编辑推销报道选题和调查稿，Agent 已经进入内容生产的上游，编辑流程和署名规范面临挑战。而另一边，首部 AI 院线电影上映三天只收百万票房，百人团队做了两年、成本千万，市场反响冷淡。这两条对比很说明问题：AI 长片的瓶颈在叙事和发行，不在生成能力。
开源和社区层面：Agent-Reach 这个 CLI 让 Agent 零 API 费用读取和搜索 Twitter、Reddit、YouTube、GitHub、Bilibili、小红书，做舆情和选题 Agent 的可以先接它跑通链路。ECC 是 Agent harness 的性能优化系统，覆盖 skills、instincts、memory、security，harness 层正在成为独立的优化对象。NVIDIA 的 SkillSpector 是 Agent skill 安全扫描器，检测漏洞、恶意模式、prompt injection 和数据外泄。openbot 把多 Agent 并行做成了桌面级产品，每个模型有自己的工作区和任务队列。huashu-design 能一句话拿回可编辑的设计交付物，含 84 种风格库。postiz-app 是 Agent 驱动的社媒排期工具。另外，r/opensource 全面封禁 AI 相关项目，还催生了一个新分区 r/TrueOpenSource，开源社区对 AI 项目的排斥情绪实体化了，分发渠道在分裂。Torvalds 也表了态：AI 对合格开发者没问题，但别来那种“顺手提交”的补丁。
好，下面是今天的观察。
今天最硬的信号是价格。GPT-6.1 Terra 把中端 API 价格砍半还拿到 48 分，配合 Meta 的 950 亿美元增发、SpaceX 的 400 亿 GPU 融资，说明推理供给还在猛加，中端价位会持续被压。这不是一次性的促销，而是一个结构性趋势，所有靠模型差价吃饭的中间层都要重新算账。
第二条线是 Agent 的“围墙”开始出现。The RealReal 直接封 Agent，而今天那篇 Kolab 论文指出，人类真正需要的是可以中途改计划的协作，不是全自动。这两件事其实是一体两面：Agent 想进真实世界，既会遇到商家的防御，也会遇到人类协作习惯的门槛。谁能把这两头都处理好，谁就能吃到下一波。
第三条是安全和溯源成为新基建。NVIDIA 的 SkillSpector、OS 级的包防火墙、还有那篇“Git 记录不了 AI 贡献”的研究，指向的是同一个缺口：AI 用得越多，越需要一套能说清楚“谁改了什么、AI 贡献了多少”的机制。这个缺口现在还没人填好。
内容侧则相反，是冷热分明：AI 长片票房遇冷，但短剧剧本、设计交付、社媒排期这些短周期场景在快速成熟。规律很清楚——越短周期、越高转化，越先跑通。
最后聊聊商业机会和研究建议，用聊天的方式说。
第一个机会，给做 Agent 电商的团队。商家开始封 Agent 了，The RealReal 就是活例子，那这里就需要一个“跨商家可用性探测加自动降级”的路由层——实时知道哪家能进、哪家封了，封了之后自动切到人工或者开放接口。这个需求正卡在爆发前，现在做，时机很好。
第二个机会，给面向高校实验室和投稿作者的团队。PaperFormalizer 证明了 Lean 形式化可以接进真实写作流程，而期刊和资助方已经在要求 AI 披露，就是那篇“Git 记录不了 AI 贡献”讲的问题。这两件事凑在一起，你可以做一个“投稿前 AI 贡献审计加形式化自检”的订阅工具，按篇收费，客户是高校和实验室。
第三个机会，给非英语市场的 API 转售和聚合商。分词器税被量化之后，统一的美元定价在高 token 语言上会亏钱。你可以做按语言分档的定价和配额产品，把成本差异直接转成定价优势。这条依据就是 Rest of World 那篇报道。
研究建议三条。第一，亲手复现 Token Collapse，拿 G-Retriever 在三个小图上跑一遍，确认软提示 token 塌缩会不会在你的数据上出现，再决定知识图谱方案要不要换。第二，试试 MultiAgent-OPD 的联合训练思路，用一个小 Leader 加两个子 Agent 做蒸馏对比实验，看端到端训练相比手工编排，在成本和成功率上到底差多少。第三，用 RoboJudge-Bench 给手上任意一个视频生成模型打一次分，重点看物理合理性和指令忠实度的分歧点，这比看 demo 更能判断它能不能进生产。
好，今天就聊到这儿。一句话总结：价格在往下走，围墙在往上砌，谁能把成本和协作这两件事同时处理好，谁就能拿到下一轮的入场券。感谢收听 Andy 的 AI 早报，我们明天见。
