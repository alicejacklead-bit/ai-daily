早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 9 号，星期一。先报今天的这一句话：OpenRouter 上 DeepSeek V4.1 Flash 的输入价被砍到了原来的二十五分之一，模型 API 的价格战，正在从“降价”变成“重定价”，聚合层的毛利结构会被重新洗牌。
今天这期，咱们重点讲三件事。第一，钱在往哪儿走——OpenAI 的估值没到预期，Anthropic 自己去买电，资本在从世界模型撤退，这三条放一起看，信号非常一致。第二，模型 API 这条赛道的价格结构今天被重排了一次，Flash 级模型基本被压到电费价，这对做视频生成 API 的我们来说，是必须重新算账的一天。第三，Agent 这边今天最热的不是新模型，而是浏览器运行时和评审门禁这类工程脚手架，这个转向值得你花几分钟听透。好，咱们开始。
先看市场局势。
第一条，OpenAI 以 1.25 万亿美元的估值完成了 110 亿美元融资，比它最初想要的 1.4 万亿低了大概 10%。之前首轮交割的消息已经传过，这次是把融资细节完整披露出来。这件事说明什么呢？头部实验室的估值锚，正在从“讲故事的上限”回落到“能成交的区间”。而且这不是孤例，Anthropic 的 IPO 估值从 1.5 万亿一路下修到 1.1 万亿，方向完全一样。资本对前沿模型的定价在收敛，这对二线模型公司的影响更直接——融资窗口会更窄。如果你和海外创始人聊到这件事，可以问问他，1.25 万亿这个数字里，到底有多少是算力资产、多少是分发渠道，而不是模型能力本身。这个问题一问出来，对方基本就知道你不是只看新闻标题的人。
第二条，Anthropic 签了一笔 34 亿美元的燃气发电协议，专门给数据中心供电。这个时间点很关键——中期选举之后，多州的数据中心公投集体受挫，电网接入越来越紧，所以模型公司干脆自己下场买电。这意味着模型公司的成本结构，正在从“租算力”转向“自建电力”，电力获取能力开始变成竞争壁垒。对依赖第三方云的中小 API 平台来说，上游算力成本的分化会加剧，价格优势更难维持。这里有个很好的谈资角度：你可以问对方，未来模型公司的 CFO，是不是得先是个能源采购负责人。听着像玩笑，但这条新闻说明它正在变成现实。
第三条，Nvidia 董事会就 CEO 黄仁勋和一名疑似中国间谍的关系，启动了独立调查。黄仁勋在致全员的备忘录里承认存在婚外情，涉事方是 Megaspeed 的高管 Alice Huang，据报被中国国家安全部招募，用于刺探 Nvidia。董事会说已经启动独立调查。这件事的分量在于，它是当前 AI 算力供应链上最关键那家公司的高层治理风险，而且直接牵涉对华出口管制——之前已经有“H200 放行、但获批名单公司的办公室是空的”这种报道。短期它会影响 Nvidia 的合规叙事和对华业务节奏，也会让海外 AI 公司的创始人在董事会层面重新审视高管背景审查这件事。谈资角度是：AI 公司的高管背景审查，现在是不是该和模型安全审查放到同一个优先级上。
好，接下来是今天的重头戏，赛道深挖。
第一条，也是今天最重要的一条：OpenRouter 的模型表又重定价了。按接口快照对比，DeepSeek V4.1 Flash 的 prompt 价从 0.00000015 降到 0.000000006，也就是降到了原来的二十五分之一；completion 价从 0.0000006 降到 0.0000005。它的 batch 版更狠，prompt 从 0.000000112 降到 0.000000011，completion 从 0.000000336 降到 0.0000002。Kimi K3 的 batch 版，prompt 从 0.00000228 降到 0.000000917，completion 从 0.0000114 降到 0.000006，输出价近乎腰斩。DeepSeek V4 Pro 的 prompt 从 0.000000515214 降到 0.0000002088，completion 从 0.000001030428 降到 0.0000004176。同时新增了 Qwen3.6 27B，prompt 0.00000032、completion 0.0000032；OpenAI 的 gpt-oss-120b 的 prompt 也从 0.000000029 降到 0.000000017。
这些数字念起来有点绕，但你只要抓住一个判断：这不是普遍降价，而是结构性重排。Flash 级模型被压到了近乎“电费定价”，而 batch 通道的折扣幅度明显大于标准通道，说明推理批处理正在变成独立的价格战场。对 API 平台来说，靠 Flash 级模型赚差价的空间基本消失了，价值必须往路由、SLA、多模态，还有视频这类高单价品类迁移。如果你和做视频平台的朋友聊到这件事，可以问问他：Flash 级模型价格打到这个位置之后，聚合平台还剩什么护城河。这个问题现在特别值得问，因为答案很可能不在模型层，而在工程和交付层。
第二条，阿里推出了 Co-Design Bench，用真实用户请求来测试编码 Agent，而且这些请求都是此前在实战中让 Agent 失败过的。结果，表现最好的 GPT-6 Astra 也只完整解决了 26.4% 的任务，而同一批模型在旧基准上得分超过 99%。99% 到 26.4%，这个落差说明现有编码 Agent 基准已经严重饱和、彻底失去区分度。对做 Agent 产品的团队来说，这意味着“benchmark 分数”作为卖点正在失效，真实返工率才是采购方会问的指标。这也直接呼应了之前 GDPx 基准的结论——没有一个 Agent 在真实知识工作上超过 12%。谈资角度：你可以问对方，你们内部评估 Agent 的时候，还敢用公开 benchmark 的数字对外讲吗。这句话问出去，基本能听出对方的产品是真做过交付，还是只做过 demo。
第三条，资本正在撤离“世界模型”。量子位报道说，财务资本正在从这个世界模型方向撤出。有意思的是，这跟 Nvidia 刚发布 Cosmos 3 开放模型、用于交互式世界模拟形成了鲜明对照——大厂还在继续投入，财务资本却在退潮。世界模型是视频生成往上走的重要技术路径之一，资本退潮会拖慢独立团队的迭代节奏，把这条路线更多交给有算力和现金流的巨头。对视频生成 API 平台来说，中短期能采购到的第三方世界模型供给可能会变少，自研或者绑定大厂的必要性在上升。谈资角度是：世界模型到底是技术没到位，还是商业化路径没讲清楚。这个问题，现在问做世界模型的团队，他们的回答会很有意思。
接下来是 Agent 前沿。
第一条，Vercel 开源了 agent-browser，单日涨了 812 个 star。这是 vercel-labs 发布的一个面向 AI Agent 的浏览器自动化 CLI。同期，LangChain 的 Managed Deep Agents 也已经内置了浏览器运行能力，还提供人工接管登录的 handoff。这件事的意义在于，浏览器正在从“Agent 的一个工具”变成“Agent 的标准运行时”，而且竞争焦点已经从“能不能点”转向上下文效率和登录态交接这类工程细节。对任何要做 Agent 产品的团队来说，浏览器层的选型已经不能拖到后期再定了。你可以问对方，浏览器层你们是自研还是直接用 CLI，登录态怎么处理。这个问题很实操，一问就知道对方踩没踩过坑。
第二条，Google 发布了 Elephant-Goldfish 插件，思路是让编码 Agent 先写 spec，然后在任何代码生成之前，先跑 5 轮零上下文评审，通过了才允许写代码。同一天，Anthropic 的 Agent Skills 仓库单日涨了 793 个 star。这个插件针对的正是“九成代码 AI 写、没人审”这个痛点，把评审从人工后置，改成 Agent 流程内的前置门禁。它和刚才说的 Co-Design Bench 其实是同一个问题的两种解法——一个把问题测出来，一个给出流程约束。做 Agent 编排的团队，可以直接借鉴这个“多阶段零上下文评审”的结构。谈资角度：spec-first 加多轮评审，会不会把 Agent 的速度优势吃掉？这是个真问题，值得跟做编码 Agent 的朋友掰扯掰扯。
好，下面是快讯，我按主题串一下，快速带过。
先看落地反转这一类。Goldman Sachs 正在把 Claude Code 从银行家和交易员手里撤下来，这条在 HN 上热度 490 分、305 条评论，是今天讨论度最高的 AI 落地反转事件。大机构用起来又收回去，这个信号值得留意。
再看大厂动作。Apple 的 CEO 在给软件负责人施压，要求加快 Siri 的路线图，目标是做出能对标 OpenAI Dots 和 Meta Muse 的强 Agent，Bloomberg 的 Gurman 说 Ternus 正要求 Federighi 加速交付。
版权这边，猫王和 Eminem 的版权方起诉了 Suno，指控它非法生成模仿这些艺人的音乐和歌词，其中猫王案还援引了田纳西州的相关法律。生成式内容的版权压力还在加码。
开发者圈子里有两件事。Karpathy 用一个周末做出了一个策展视频平台，用 Claude Opus 5.5 从 4300 万条 Hacker News 评论里筛出 6,454 条视频，他说效果比 YouTube 自己的推荐还好。另一件是 Lovable 复盘了 10 万次 PR，结论之一是删掉了几乎全部 Agent 代码，官方博客说他们的教训是持续重建 Agent 层。这两条放一起看挺有意思——一个是个人用 AI 做出产品，一个是团队发现 Agent 层得反复重写。
好，到了今天的观察和商业机会，咱们聊得松一点。
今天最强的信号，我总结成一句话，叫“价格与能力的双重去泡沫”。你看，OpenRouter 上 Flash 级模型被压到近乎电费定价，说明模型能力本身在快速商品化；可与此同时，Co-Design Bench 用 26.4% 的真实通过率，戳破了 99% 的旧基准，说明被商品化的只是“看起来能做”，而不是“真能交付”。资本侧也是同向收敛——OpenAI 估值低于初始预期，Anthropic 的 IPO 估值一路下修，世界模型被资本撤离。钱正在从“模型叙事”，转向电力、分发、流程约束这些更硬的环节。Agent 侧的进展也印证了这一点：今天最热的不是新模型，而是浏览器运行时、spec-first 评审门禁、Skills 仓库这类工程脚手架。
顺着这个判断，我看到两个具体的商业机会。
第一个，是面向 Agent 采购方的“真实任务通过率”评测服务。依据就是阿里 Co-Design Bench 那条——旧基准已经饱和，真实通过率只有 26.4%，而企业采购 Agent 的时候，最缺的恰恰是可信的返工率数据。这个生意可以先从编码和浏览器操作这两个高频场景切入，按行业沉淀“实战失败请求集”，卖给正在选型 Agent 的中大型企业。它的壁垒不在模型，在数据积累和行业理解，这反而是小团队能做的。
第二个，是视频生成 API 的“批量与预览”分层定价。依据是 OpenRouter 的价格快照——batch 通道的折扣幅度显著大于标准通道，比如 DeepSeek V4.1 Flash 的 batch completion 价，只有标准档的 40% 左右，说明批处理正在成为独立的价格战场。视频生成单条成本高、返工又多，完全可以照这个思路设计“预览低价档加批量渲染折扣档”，去承接短剧、电商素材这类高频重试的场景。这件事对咱们做视频生成 API 的来说，几乎是现成的作业可以抄。
最后总结一句：今天真正值钱的不是哪个模型又便宜了，而是谁能在能力商品化之后，把交付、电力和流程这些硬环节攥在手里。好，今天就聊到这儿，我们明天见。
