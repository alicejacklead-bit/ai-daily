早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 18 日，星期三。先给你今天的一句话：OpenAI 用 GPT-6.2 Astra 把前沿价格打到 8 美元输入、40 美元输出，同时推出 2 美元、10 美元的 Sol，"旗舰降价加廉价档补位"，正在把模型 API 变成一门拼毛利、而不是拼能力的生意。今天我们会重点聊三件事：一是英伟达这份又惊人又诡异的财报，二是 OpenAI 这轮定价对整个 API 中间层的挤压，三是 Perplexity 把 16 个 Agent 互检做成了付费档位，而学术界刚好泼了一盆冷水。如果你在通勤路上，戴好耳机，我们开始。
先看市场局势。今天最戏剧性的新闻来自英伟达。Q3 财报出来了，营收首次突破一千亿美元，临时 CEO Colette Kress 说创纪录的增长还会继续。但同一场财报里还有另外三件事：第一，董事会主席 Harvey Jones 明确表示不打算让黄仁勋复职；第二，公司确认不再向中国销售芯片；第三，据华尔街日报报道，SEC 已经就黄仁勋离职展开调查。一家公司同时经历 CEO 丑闻、监管调查、最大市场退出和史上最高营收，这件事本身就说明一个问题：算力需求和治理能力已经脱钩了。对下游的 API 平台来说，短期供给不缺货，但地缘和合规风险会持续传导到价格和可用性上。这里给你一个谈资角度：如果你和做基础设施采购的朋友聊到这件事，可以问问他，如果算力供给不再由一家公司的治理稳定性决定，你们采购时会怎么给"供应商政治风险"定价？这个问题在海外创始人圈子里现在很真实。
第二条，Anthropic IPO 之后，Amazon 和 Google 合计持股接近 30%。具体是 Amazon 略低于 15%，而且还有继续增持的选择权，Google 紧随其后接近 14%。这意味着什么？前沿模型公司正在变成云厂商的控股型资产。对 API 平台来说，Claude 系列的价格和配额，未来会越来越受 AWS 和 GCP 的商业目标影响，而不是单纯的市场竞争。你可以和人聊：当一家模型公司的两大股东是互相竞争的云厂商，它的 API 定价到底听谁的？这个问题没有标准答案，但问出来就很有分量。
第三条，美国收紧第三国数据中心的芯片许可。新加坡、马来西亚这些地方的数据中心买英伟达芯片，现在需要美国许可证，等于堵住了中国企业租用海外算力的通道。与此同时，路透的调查显示，中国正在以工业级规模蒸馏美国模型，来弥补硬件缺口。出口管制从"卖芯片"延伸到了"租算力"，会推高全球推理成本的区域分化。做海外 GTM 的平台，需要重新评估模型托管地和合规叙事。谈资角度是：如果算力按国籍分区，模型 API 的"产地"会不会变成下一个合规标签？这个问题，你在和东南亚、中东的本地云厂商聊天时特别好用。
接下来是今天最核心的部分，赛道深挖。
第一条，OpenAI 在 11 月 17 日发布了 GPT-6.2 Astra 和 Sol。Astra 定位前沿模型，输入 8 美元、输出 40 美元每百万 token，恰好和 Claude Fable 5.2 同价，两者都是前代 10 美元、50 美元的八折。Sol 定位日常高效模型，2 美元、10 美元，batch 档再减半到 1 美元、5 美元。性能上，Astra 在 Artificial Analysis 智能指数上排第二，仅次于 Fable 5.2，而且它是 OpenAI 自家"AI 自我改进"量表上第一个达到 High 阈值的已发布模型，OpenAI 自己把这一项列为风险。OpenRouter 同步上架了 astra、astra-pro、sol、sol-pro 和各自的 batch 档。这件事的重要性在于，前沿模型的价格被锁定在了 8 美元、40 美元这个锚点上，而廉价档 Sol 压到 2 美元、10 美元，直接压缩了中转和聚合平台的加价空间。对视频生成 API 平台来说，启示很明确：文本侧的成本正在快速商品化，差异化只能来自多模态能力和工作流，而不是 token 转售。如果你和做视频平台的朋友聊到这件事，可以问问他：当旗舰模型都主动降到前代八折，你们还怎么向客户解释 API 加价？
第二条，OpenRouter 的主力模型表今天也大更新。除了 Astra 和 Sol 全系，还新增了 deepseek-v4.1-flash，输入 0.051 美元、输出 0.567 美元；kimi-k2.7-code，0.7 美元、3.75 美元；qwen3.8-27b，0.06 美元、2.2 美元等等。同时多款模型调价，注意这里的结构很有意思：deepseek-v4.1-flash 输入从 0.14 降到 0.051，降了大约 64%，但输出从 0.42 升到 0.567；qwen3.8-27b 输入从 0.15 降到 0.06，输出从 1.875 升到 2.2。输入端普遍下探、输出端分化上调，这说明推理厂商在抢输入侧流量，靠输出侧回收成本。这对任何做 token 转售的平台都是一个毛利结构信号。聚合平台的价格表，现在就是观察模型定价战最好的仪表盘。谈资角度：开源模型输入价跌到每百万 token 几分钱，聚合平台还靠什么留住用户？
第三条，印度的 Sarvam 推出了 Token Factory，托管 8 个开源模型的 OpenAI 兼容 API。包括 Sarvam 105B、GLM 5.3、DeepSeek V4.1 Flash、Kimi K3.1 Pro、Gemma 4 31B 等等，全部跑在印度本地的 GPU 集群上，统一走 OpenAI 兼容接口，向所有人开放。区域主权推理正在成为分发渠道的新变量，"数据不出境加 OpenAI 兼容"，是对全球聚合平台的直接替代。你做海外 GTM 的时候要记住，这类本地玩家会是最难打的竞争对手，但也最可能是本地化的合作对象。可以问客户一个问题：客户要的是最便宜的 token，还是"数据留在本国"的 token？在很多市场，答案后者更多。
好，进入 Agent 前沿。
今天第一条，Perplexity Computer 上线了 Multiagent。在 Ultra 档之上新增了一个"effort level"，由一个 lead agent 调度最多 16 个 Agent，分别跑在 Claude、GPT、Gemini 上，共享发现，互相检查对方的工作。同一天 Perplexity 宣布达到 10 亿美元收入的年化 run rate，2026 年增长 4 倍。这是"异构模型编排加互检"第一次作为消费级产品档位出售，把多 Agent 从框架层推到了定价层。它解决的是单模型自洽性差的问题，但代价是把推理成本推高好几倍，而这正好对应今天 Astra 和 Sol 降价的时间点，供给变便宜了，消耗变贵了。谈资角度：多 Agent 互检提升的是准确率，还是只是把成本乘了 16 倍？
第二条正好接上。有一篇论文汇总了 9 项实证评估、516 个多 Agent 配置，按六维资源向量和四级基线阶梯来组织。结论是：和单次贪心解码的基线相比，多 Agent 的准确率差异整体是负的。也就是说，此前"多 Agent 更强"的印象，很大程度上混淆了协调机制、样本数量和推理算力。这篇研究给当前的多 Agent 热潮泼了一盆冷水，但也给出了正确的对照实验方法。做 Agent 产品的人应该据此重新审视：你卖的到底是协调架构，还是只是更贵的采样？可以问对方：你们的多 Agent 系统做过"同等算力单模型"的对照吗？这个问题现在很扎人。
下面是快讯，我按主题串一下。
Agent 落地方面，Google 把 Spark Agent 改名成了 Tasks，并且免费开放，由 Gemini 4 Hydrogen 驱动，能做餐食计划、日历管理、翻邮件找重复订阅，美国用户先行。OpenAI 的计算机使用 Agent 进入了美国医疗行政流程，Luna 处理事先授权大约 8.5 美分一次，CVS Health 和 Cigna Healthcare 已经部署。融资方面，Model ML 拿了 2.5 亿美元，用 Agent 自动化投行的建模和材料更新这类基础工作；Isomorphic Labs 半年内第二笔超大额融资，5 亿美元，此前六个月刚完成 21 亿美元，目前还没有获批药物，资金用于推进管线进入临床。最后一条和隐私有关，Gemini 聊天记录保留期从 72 小时延长到 2 个月，即使用户关闭历史记录也生效，未来几周全球推送。这条对你和海外客户聊合规时是个现成的例子。
最后是今日观察和商业机会，我们聊得随意一点。
今天最清晰的信号，是模型 API 的价格锚点被重新钉死了。Astra 和 Fable 5.2 同为 8 美元、40 美元，Sol 压到 2 美元、10 美元，前沿能力正在以前代八折的节奏商品化。与此同时，Perplexity 把 16 个异构 Agent 互检做成了付费档位，而学术侧刚刚证明多 Agent 的增益大多来自算力而不是协调。供给变便宜、消耗变贵，中间层的毛利被两头挤压。聚合平台和区域主权推理从两侧夹击 token 转售生意，纯做"转发"的空间在快速消失。对视频生成赛道来说，文本侧的成本塌陷意味着，多模态工作流和创作体验才是能收钱的地方。
基于这个判断，有两个商业机会我觉得现在就能动手。第一个，面向视频创作平台的"多模型编排加成本护栏"中间层。依据就是今天 Astra、Sol 降价和 Perplexity Multiagent 这两条新闻。视频生成工作流天然需要脚本模型、分镜模型、视频模型串联起来，客户既想用多 Agent 互检提升质量，又怕成本失控。做一个按任务预算自动选模型的编排层，旗舰档和廉价档动态切换，再叠加 batch 档调度，这是现在就能卖的能力。第二个，为区域合规市场做"本地托管加 OpenAI 兼容"的白标推理网关。依据是 Sarvam Token Factory 和美国收紧第三国芯片许可这两条。东南亚、中东、拉美的本地云和行业客户，需要"数据不出境、接口不改"的方案。把开源权重模型打包成区域托管的兼容 API，比直接和全球聚合平台拼价格更可行。
一句话总结今天：模型能力在降价，Agent 消耗在涨价，真正值钱的是夹在中间、能控住成本的那层工作流。感谢收听，我们明天见。
