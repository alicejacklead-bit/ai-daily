早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 12 号，星期四。先给你今天的一句话：视频生成的价格战，已经从“每秒多少钱”打进了“每像素多少钱”——火山方舟开始按输出分辨率分档计费，这说明厂商现在拼的不是模型参数，而是计费颗粒度。今天重点三块：第一，Nvidia 那边出了大事，董事会据报准备罢免黄仁勋；第二，火山方舟的视频计价改版，直接关系到我们做视频 API 的毛利结构；第三，Google 上线了一个 Decisions API，把“判断”这件事做成了廉价接口，Agent 架构可能要变天。咱们一条一条来。
先看市场局势。今天最大的变量，毫无疑问是 Nvidia。据华尔街日报和纽约时报报道，Nvidia 董事会最早可能在周三晚决定，是否罢免任职 33 年的创始人兼 CEO 黄仁勋。导火索是治理层面的问题：他承认与一名被指为中国情报人员的女性有婚外情，随后又曝出与一名直接向他汇报的 Nvidia 高管存在第二段关系。消息出来股价应声下跌，众议院共和党人还要求他在当天结束前答复闭门简报的要求。这件事为什么重要？因为 Nvidia 是全球 AI 算力供给里单一最大的节点，现在这个节点出现了治理真空的风险。短期看是股价和供应链情绪，中期看，Nvidia 的路线连续性、还有对华出口政策的博弈，都会被重新定价。如果你和做跨境算力的朋友聊到这件事，可以问问他：如果 CEO 真的换人，Nvidia 对华出口的强硬派立场会不会松动？这是现在所有做跨境算力的人最想知道的问题。
第二条，OpenAI 的账本。它这个季度营收环比增长 50%，到了 100 亿美元，但调整后的经营亏损升到了 109 亿美元，也就是说亏得比赚得多。对比之下，Anthropic 在 170 亿美元营收的规模上，运营效率明显更高。为了缩小差距，OpenAI 正在企业客户上主动挑起价格战。这说明什么？头部模型公司“营收增长不等于盈利”这件事已经公开化了，价格战从 API 单价一路蔓延到企业合同。对下游 API 平台来说，上游成本可能继续下探，这是好事，但供应商的稳定性要重新评估。你跟创业公司的朋友聊，可以抛这个问题：当 OpenAI 用亏损换企业份额，你该选“最便宜的”，还是“最不会突然改价的”供应商？
第三条，Anthropic 放了个挺炸的消息。它说内部模型 Mythos 在几乎无人工干预的情况下，三天就把 Claude 迁移到了 AMD 的 GPU 上，而传统流程要几个月。现在 Claude 同时跑在 AWS 的 Trainium、Google 的 TPU、NVIDIA 的 GPU 和 AMD 的 GPU 四个芯片家族上。这件事的意义在于，多芯片并行直接压低了推理成本，也削弱了单一供应商的议价权。对视频生成这种算力密集型业务来说，“换芯片”的成本曲线，会决定未来一年你的 API 报价还有多少空间。谈资角度很直接：如果换芯片从几个月缩到几天，模型公司还会为 CUDA 生态付溢价吗？
好，接下来是今天的重头戏，赛道深挖。第一条，火山方舟的价格页改版，这条我建议你反复听。它新增了一个“输出视频分辨率 4K”的计费维度，按像素分档：小于等于 2.61M 像素是 0.30，超过 2.61M 像素直接变成 0.60，也就是跨过这个阈值，单价翻倍。另一档是 0.15 和 0.30 的关系，逻辑一样。同时页面把“千 token、元每百万 token”统一改写成“K token、元每 M token”，还新增了按输入长度区间分档计费的例子：输入 200K、输出 14K 的时候，全部 token 按输入 4.8 元每百万、输出 24 元每百万来算。视频侧还有两个示例，一个是 30K token 每次乘以 80 元每百万 token，另一个是 30K token 每次乘以 60 元每百万 token。这条为什么给五星？因为视频 API 的计价单位正在从“秒”转向“像素乘 token”，高分辨率不再是线性加价，而是跳档翻倍。对做聚合和转售的平台来说，4K 档的毛利结构要整个重算；但反过来，这也给了你“标清走量、4K 走溢价”的产品分层空间。这里有个特别值得琢磨的反噬点：按像素跳档计费，客户会不会干脆把 4K 需求降级到 2.6M 像素以下？这是定价设计里最容易被反噬的地方。如果你和做视频平台的朋友聊，可以问问他：你们的套餐是按秒卖，还是准备按像素卖？
第二条，OpenRouter 的主力模型表又洗牌了。openai 的 gpt-5.6-sol 从 prompt 0.000004、completion 0.00002，上调到 0.0000044 和 0.000022，大约涨了 10%。minimax 的 m3.1-flash 直接翻倍，从 0.000000075 和 0.0000003，涨到 0.00000015 和 0.0000006。反过来，google 的 gemma-3-27b-it 输出价从 0.00000045 降到了 0.00000035。DeepSeek 三个 flash 变体有涨有跌，qwen 的 2.5-7b-instruct 被移出，qwen3.5-9b 保留但调了价。这条说明什么？聚合平台的价格波动，就是上游定价策略的即时投影。你注意，小模型和大模型的价格在反向移动，这说明“廉价 Agent 底座”这一层正在被重新分层，做 Agent 产品的选型成本，每个月都在变。谈资角度：小模型涨价、大模型微涨，是不是说明“用便宜模型跑 Agent”的红利期正在收尾？
第三条，Adobe Max 2026 的实验项目。它公布了几项实验性功能：可以把静态图片转成可探索的 3D 场景，可以通过对话设计 AI 角色，还把照片编辑变成了复制粘贴式的操作。此前 Adobe 已经宣布，第三方 Agent 可以通过 MCP 访问并修改 Creative Cloud 的内容。这条的重要性我给三星，但它对咱们赛道的含义不小：图像转 3D 可探索场景，是视频生成的上游能力，一旦产品化，会挤压“图生视频”这一层的独立工具价值。换句话说，Adobe 是在从素材端往上吞。你跟做创作工具的朋友聊，可以问：当 PS 里一张图直接变成能走进去的 3D 空间，“图生视频”工具还剩多少独立价值？
接下来是 Agent 前沿。今天最值得记的一笔，是 Google 的 Gemini Decisions API。它由 Gemini Decision 1 驱动，可以对文本、图像、音频、视频、PDF 上的最多 1000 个封闭问题返回校准后的概率，问题可以是是或否、多选、或者评分标准 rubric。延迟只有 150 到 250 毫秒，成本大约是 Gemini 3.5 Flash-Lite 的五分之一。定价是 0.10 美元每百万输入 token，输出免费，和 GPT-6 Luna 的决策模型一致；Jev 还是最便宜的，4.2 美分每百万。它解决什么问题？它把“判断”从生成模型里剥离出来，做成一个专用 API，等于给 Agent 提供了一个廉价、低延迟的裁决层。批量评分、内容审核、Agent 自我校验这类高频小判断，成本结构会被彻底改写。为什么值得关注？因为当“判断”比“生成”便宜两个数量级，Agent 架构会自然分化成“贵模型干活、便宜模型打分”。你跟做 Agent 的朋友聊，可以问：你们的架构里，判断和生成是分开的吗？
第二条，LangChain 连发两篇 Deep Agents 的上下文工程。核心有两点：一是上下文工程要从检索开始，避免笨拙的搜索、超大的结果和过期的数据；二是长任务要通过卸载到外部、摘要、技能化、子 Agent 和记忆，来防止上下文膨胀导致的性能退化。这条说明，长时运行 Agent 的瓶颈，已经从“模型能力”转向“上下文管理”。这套方法论可以直接复用到视频生成类 Agent 上，比如多轮分镜、素材记忆，这是产品差异化的工程抓手。谈资角度：你们的 Agent 上下文是“越攒越多”，还是“该忘就忘”？这已经是区分工程水平的分水岭了。
下面快速过几条快讯。航空这边，United Airlines 禁止个人 AI Agent 代订机票，理由是隐私和监管顾虑，不过他们说目前实际尝试的人并不多。芯片融资这边，英国的 Fractile 完成了 7.2 亿美元融资，成为专用 AI 芯片赛道融资额最高的玩家之一。数据这边，Mercor 完成 7.5 亿美元 D 轮，估值 200 亿美元，年化 30 亿美元，AI 训练数据和强化学习环境供应商的估值还在走高。另一条相关的，美国的数据经纪商向中国实验室卖出了大约 5 亿美元的强化学习训练环境，ChinaTalk 的调查说涉及至少 9 家公司，其中还包括此前为 OpenAI 和 Anthropic 构建过环境的，而出口管制几乎不适用。最后一条，Google 发布了 AlphaGenome 2，一个条件式 DNA 序列模型，能按细胞类型预测调控活性和变异效应，通过 AlphaGenome API 面向非商业研究开放。
好，到了今天的观察和商业机会，咱们聊得随意一点。今天所有新闻串起来看，其实是一条主线：上游的成本和供应稳定性，同时变得不可预测。你看，火山方舟把视频 API 的定价从“按秒”精细到“按像素乘 token”，4K 档直接翻倍，这说明厂商不再靠模型参数讲故事，而是靠计费颗粒度做产品分层。这对聚合平台是毛利重算，对创作工具是套餐重构。与此同时，OpenAI 用 109 亿美元的季度亏损换企业份额，Anthropic 三天换芯片，一个说明价格战还没到底，一个说明算力成本曲线还在往下走。Agent 侧最值得记的，就是 Decisions API，把“判断”做成 0.10 美元每百万 token 的廉价裁决层。而黄仁勋的治理危机，是今天最大的不确定性变量，它不改变技术趋势，但会改变未来两个季度的算力预期。
基于这些，我看到两个具体的商业机会。第一个，是视频 API 的“分辨率分档”转售层。火山方舟按 2.61M 像素跳档翻倍计费，这意味着大量客户会主动降级到阈值以下。你可以做一层自动分辨率适配加成本预估的网关，帮创作平台在画质和单价之间自动选档。这个判断的依据，就是火山方舟价格页上的像素分档规则。第二个，是 Agent 的“廉价裁决层”封装。Gemini Decisions API 输出免费，单次能判 1000 个问题，延迟 150 到 250 毫秒，特别适合做成通用的批量质检和评分中间件，服务内容审核、视频生成质量打分、Agent 自我校验这些场景。依据就是 Decisions API 的定价和吞吐参数。这两个方向，一个吃的是定价结构变化，一个吃的是判断成本下降，都挺适合咱们这种做 API 平台的团队去试。
最后用一句话总结今天：定价颗粒度正在取代模型参数成为竞争焦点，而算力供应的治理风险，是未来两个季度最需要盯住的变量。好，今天的早报就到这里，希望能陪你走完这段通勤路。我是 Andy，我们明天见。
