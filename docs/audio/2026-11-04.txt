早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 4 日，星期三。先给你今天的一句话：fal 估值半年翻倍到 160 亿美元，OpenRouter 上主力模型价格集体调整——生成媒体的"卖水人"，也就是推理和分发这一层，正在同时收割需求红利和定价权，而纯做模型 API 转售的中间层，压力会越来越大。今天咱们重点聊三件事：第一，生成媒体推理层的估值逻辑正在被资本市场重新定价；第二，聚合平台的价格战从"全面下探"转向"分层定价"，选型逻辑要变；第三，Agent 基础设施在往"更省"和"更可审计"两个方向同时下沉。好，咱们一条一条来。
先看市场局势。今天最重的一条，fal 以 160 亿美元的估值融资 13 亿美元，Bessemer 领投，估值半年直接翻倍。这家公司成立五年，做的是生成媒体的推理平台，它是 Kling 这类第三方视频模型的主要分发渠道之一，同时自己也建推理栈。上一轮估值还是 80 亿，半年时间翻到 160 亿，这个速度说明什么？说明资本市场给"生成媒体推理层"的定价，远远高于单纯的模型层。渠道和推理优化本身，正在变成一项独立的高价值资产。对咱们做视频模型 API 的平台来说，这意味着上游分发方的话语权在快速膨胀。你想想，模型方要触达开发者，越来越依赖 fal 这样的渠道，那渠道就有议价权。如果你和做视频平台的朋友聊到这件事，可以问问他：生成媒体的价值到底沉淀在模型权重里，还是在推理和分发层？fal 的估值，其实给出了一个偏向后者的答案。这个问题没有标准答案，但值得每个做 API 的人认真想一想自己在链条上的位置。
第二条，OpenRouter 上主力模型价格出现集体调整，而且方向不一致，这点特别值得注意。具体看数字：DeepSeek V4.1 Flash 的输入价从每百万 token 0.30 美元降到 0.15 美元，Completion 也从 1.2 降到 0.6，等于下调了一半；Kimi K3 的 Completion 从 0.000015 降到 0.0000096，也是下调。但另一边，Qwen3 235B 的输入价从 0.00000009 涨到 0.00000014，Completion 从 0.00000055 涨到 0.0000008；Gemma 4 26B 的输入价也从 0.000000045 涨到 0.00000007。同时 OpenRouter 还新增了 grok-4.6 和 grok-4.7 的 batch 版本。你看，这不是一边倒的降价，而是有涨有跌。这说明什么？说明低价模型层的价格战，正在从"全面下探"转向"分层定价"。以前大家默认模型会一直变便宜，现在这个假设不成立了。API 平台在选型的时候，不能再假设单一模型会持续降价，得按品类、按用途分开算账。聚合平台的价格，其实比厂商官方定价更能反映真实供需，因为它是最灵敏的仪表盘。所以你可以问问对方：现在你们按什么信号做模型选型？是看官方价，还是看聚合平台的实际成交价？
第三条是个宏观信号，别跳过。日经报道，美国科技公司的表外 AI 相关债务，半年内膨胀了 90%，达到 3.2 万亿美元。Bloomberg 同期也发评论警告，说 AI 投资热潮需要更强的金融监管。这条为什么重要？因为算力扩张越来越依赖债务，而不是现金流。一旦融资窗口收紧，推理价格和 API 供给都会被动调整。这是判断明年模型 API 定价走势时，不能忽略的宏观变量。你可以拿这个问题去抛给对方：如果债务市场先于需求冷却，推理价格会先涨还是先崩？这个问题挺考验人对周期的判断，聊起来很有意思。
好，接下来是咱们最关心的赛道深挖。第一条，Replicate 把 MiniMax H3 Lite 和 Highspeed 打到五折，截止到年底。同时它把首页原来"Try Kling 4.0 from Kuaishou"的推广位给撤了。这两个动作放在一起看，很有意思。聚合平台用限时折扣做模型引流，是典型打法——先用折扣把开发者拉进自己的计费体系，再靠切换默认模型把人留住。对咱们做视频模型 API 的平台来说，这意味着第三方渠道的价格战，会直接压缩官方 API 的价格空间。年底之前，是一个明确的价格窗口。这里有个谈资角度：聚合平台用限时五折替模型方做拉新，模型方到底是赚了分发，还是被压了价？你如果和模型方的商务聊，可以问问他们怎么算这笔账——是看新增调用量，还是看单次调用的实际收入？
第二条，火山方舟把"接入三方工具"这一项，拆成了十多个具体的 Agent 工具入口。原来是一个笼统的"接入三方工具"，现在变成了 Codex、Claude Code、OpenCode、OpenClaw、Hermes Agent、TRAE、WorkBuddy、ZCode、DeepSeek Harness、Pi 等等具体条目，还新增了"接入 AI 工具"这个总分类。这条的重要性在于，模型平台的竞争维度正在变——从"谁的模型便宜"，转向"谁能被最多的 Agent 工具一键接入"。把 Claude Code、Codex 这类第三方编码 Agent 明确列为接入对象，说明平台在主动把自己做成 Agent 的工具后端。这对任何做模型 API 分发的平台，都是渠道策略上的直接参照。谈资角度是：模型平台开始把"被多少 Agent 工具原生支持"当成卖点，这个指标会不会取代 benchmark，成为选型的第一顺位？我觉得这个趋势值得盯，因为开发者选工具，越来越看"能不能直接用"，而不是"跑分高不高"。
第三条，MiniMax 的音乐 API 对新增用户永久关闭了，只保留存量付费用户。定价页显示，从 2026 年 8 月 20 日起，Music Generation 和 Lyrics Generation API 不再向新用户开放，存量付费用户可以继续用。价格方面，Music 3.0 是每首 0.15 美元，最长 5 分钟；Music 2.6 歌词生成每首 0.01 美元；Music 2.0 是每首 0.03 美元，多个旧版本已经标记为 discontinued。这条说明什么？音频生成 API 正在从"开放拉新"切换到"存量维护"，这跟视频、图像模型的持续扩张形成了鲜明对比。它提示多模态 API 平台，在品类扩张上要更谨慎——不是每个模态都能撑起一条独立的产品线。谈资角度：音乐生成，是不是第一个被证明"需求撑不起 API 生意"的生成模态？这个问题可以拿去和做多模态的朋友聊，看看他们内部怎么评估各个模态的投入产出。
接下来是 Agent 前沿。第一条，Anthropic 为 Messages API 推出了 Message Threads，长对话的首 token 延迟降低了大约 35%。它的机制是：不再每一轮都重发完整对话，Agent 只传增量变化。在 50 万到 100 万 token 的请求区间，time to first token 下降约 35%。这条为什么重要？因为长上下文 Agent 的成本和延迟大头，一直都在"重复传输历史"上。只传增量，等于把上下文管理从应用层下推到了 API 层，这会直接改变 Agent 框架的设计假设——记忆压缩、会话分片这些工程手段的必要性会下降。谈资角度是：上下文管理从应用层下沉到 API 层之后，Agent 框架的差异化还剩下什么？这个问题对做 Agent 产品的团队挺扎心的，但必须想清楚。
第二条，LangSmith 的 BYOC 在 AWS 正式可用了，Azure 和 Google Cloud 进入 Beta。BYOC 就是 bring your own cloud，客户可以把 traces、evals 和 Agent 部署留在自己的云账户里，由 LangChain 远程运营。这条重要在哪？Agent 可观测性平台长期卡在企业"数据不出账户"这条红线上。BYOC 把这个障碍拆掉了，意味着 Agent 评估与追踪，正在从 SaaS 玩具，变成能进受监管行业的采购项。谈资角度：Agent 的 trace 数据比模型权重更敏感，BYOC 会不会成为 Agent 基础设施的默认形态？我觉得大概率会，尤其是金融、医疗这些行业。
好，几条快讯快速带过。Anthropic 在研发 FlashProve，让任何人都能验证 AI 回复确实来自声称的模型，做的是模型身份溯源。OpenAI 的 Adam Fry 在发布会上披露，ChatGPT 的搜索查询量已经达到 Google 的 20%。Google 这边，对拒绝其 AI 功能的学校彻底关闭 Search 访问，K-12 学生账号的 Gemini、Gemini Notebook、Classroom 和 Search 会全部关闭。Postman 被指静默自动安装 AI 插件，还尝试共享全部 API 数据，GitHub issue 已经拿到 956 点热度、312 条评论。字节出了新规，限制员工使用 Claude、Codex 等外部 AI 工具，收紧权限，转向自研闭环。最后，Qwen Code 仓库泄露了 qwen4-max、qwen4-coder-plus、qwen4-omni-120b 等模型 ID，这些 ID 在 PR 里都解析到 262144 的上下文。
好，到了今天的观察和商业机会。今天最值得注意的组合信号是：分发层在涨价、在融资、在抢入口。你看，fal 估值翻倍、Replicate 用五折引流、火山方舟把接入工具列表拆到十多个 Agent 客户端，三件事指向同一个判断——生成媒体模型的竞争重心，正从"模型能力"转向"谁掌握开发者的调用入口"。与此同时，Anthropic 把上下文增量传输做进 API，LangSmith 把 Agent 追踪推进客户自己的云账户，说明 Agent 基础设施正在往"更省"和"更可审计"两个方向同时下沉。对做视频模型 API 的平台来说，最危险的位置是什么？是既没有模型代差、又没有分发入口的纯转售层。这个判断，你可以拿去和团队对齐一下战略。
那商业机会有两个方向。第一个，面向 Agent 工具生态做"视频生成原生接入"。火山方舟已经把 Codex、Claude Code、OpenCode 等十多个 Agent 客户端列为接入对象，但视频生成模型在这些工具里，几乎没有原生位置。这里有个空档：做一套让编码或通用 Agent 能直接调用视频生成能力的轻量 skill，或者 MCP 封装，抢在平台自己补齐之前占住入口。依据就是火山方舟价格页那个工具列表的变化。第二个，给聚合平台上的模型方做"折扣窗口套利与价格监控"。Replicate 对 MiniMax H3 Lite 和 Highspeed 打五折到年底，OpenRouter 上多个模型价格同月双向调整。你可以为视频模型 API 的采购方，提供跨平台实时比价和限时折扣提醒，帮他们在年底前锁定成本。依据就是 Replicate 和 OpenRouter 的价格页变动。
最后总结一句：当分发层开始同时收割需求红利和定价权，做 API 的人要么往上游走，握住模型代差，要么往下游走，握住开发者入口，中间那层纯转售的位置，会越来越窄。好，今天的早报就到这里，希望你在通勤路上有所收获，我们明天见。
