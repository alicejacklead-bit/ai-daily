早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 15 号，星期日。先报今天的这一句话：OpenRouter 上四款主力模型同步降价，DeepSeek 把全家桶拆成可以自由组合的 API，模型层正在从卖模型转向卖可组装的积木，API 平台的价格战才刚开始。今天重点讲三件事：第一，Anthropic 在史上最大 IPO 前夜承认明年有巨大不确定性，算力承诺已经堆到九千零一十亿美元；第二，聚合平台一夜之间四款主力模型同时降价，DeepSeek 把 App 能力拆成积木，这两件事合起来对做视频模型 API 的平台意味着什么；第三，Runway 开源了机器人模型 Praxis-1，视频模型的能力第一次直接外溢到具身智能。最后还有 Agent 前沿和几条快讯，咱们一条条来。
先看市场局势。Anthropic 距离史上最大 IPO 只剩几天，CEO Dario Amodei 在这个节骨眼上公开说，明年会发生什么有巨大的不确定性。他把购买算力称为公司面临的“最深的商业困境”，累计算力承诺已经接近九千零一十亿美元，而未来收入能不能覆盖这些成本，现在谁也说不准，IPO 本身就被定位成对冲不确定性的资金缓冲。这条为什么值得你留意？因为它标志着头部实验室的估值逻辑正在切换，从过去讲能力叙事，转到算力负债表。当最赚钱的模型公司都要靠 IPO 来做缓冲，下游 API 平台的采购议价和长约风险就都得重新算一遍。如果你跟做模型分发的朋友聊到这件事，可以问问他：如果算力承诺是负债而不是护城河，那模型公司的毛利结构到底该怎么看？这个问题现在没有标准答案，但谁先想清楚，谁在谈长约的时候就更主动。
第二条，Gemini 4 Carbon 拿下了 MathArena 榜首，但成本是 GPT-6.1 Sol 的十五倍。这是近期第一次没有 OpenAI 模型领跑 MathArena，Google 的 Gemini 4 Carbon 和 Anthropic 的 Fable 5.2 把 GPT-6.1 Sol 挤下了第一，但这两家的价格都显著更高。测试里还有个细节挺有意思，Gemini 无视时间限制，几乎从不放弃任务。这个行为特征会直接体现在 token 消耗上，对按 token 计费的 API 平台来说，意味着成本不可预测性上升。榜单第一和性价比第一正在分家，这是个趋势。聊模型选型的时候你可以抛一句：榜首模型贵十五倍，你们的 eval 里有没有“够用就好”这一档？很多团队其实没认真算过这笔账。
第三条，Anthropic 把 Claude Opus 5.5 设成了所有付费计划的默认模型，同时公开说旧提示词习惯在拖慢模型。官方指南的核心结论很直接：丢掉“think hard”这类指令，从 Medium effort 起步。另外，前研究员 Coxon 引用 IPO 路演材料说，Anthropic 已经能用原始所需算力的一小部分来重训 Mythos。默认模型换代加上提示词范式迁移，会同时抬高旧应用的 token 效率和迁移成本，这对做模型分发的平台是个机会，提示词兼容层可能成为新的产品位。你可以问问做应用的朋友：你们的 prompt 模板库上次按新模型重写是什么时候？多半是没重写过。
接下来是今天的重头戏，赛道深挖。第一条，OpenRouter 上四款主力模型同步降价。具体数字我念一下：DeepSeek V4.1 Flash 的输入价降了大约百分之八十三，从每 token 零点零零零零零零三美元降到零点零零零零零零五零七美元，输出从零点零零零零零一二降到零点零零零零零零二零二八；GPT-5.6 Sol 输入价降了约百分之九，从零点零零零零零四四降到零点零零零零零四，输出从零点零零零零二二降到零点零零零零二；Qwen3.5-9B 输入从零点零零零零零零一五八降到零点零零零零零零一零一；DeepSeek R1 那个版本也有微调。聚合平台上一夜之间四款主力同时降价，说明上游在通过分发渠道直接打价格战。对做视频模型 API 的平台来说，这意味着聚合层的比价会更快传导到自己的定价窗口，留给加价分销的空间被压缩。这里有个值得聊的问题：聚合平台同步降价，到底是上游在补贴渠道，还是渠道在倒逼上游？你下次跟海外创始人喝咖啡，可以拿这个当开场。
第二条，DeepSeek 开放了“全家桶”API，把官方 App 里的各项能力拆成可以独立调用的 API，开发者能自由组合拼装，而不是只能调用单一对话接口。这是把 C 端产品能力反向产品化成 API 积木，直接对标“模型即平台”的分发思路。对视频生成 API 平台的启示很明确：把产品里的编辑、多轮、后处理能力拆成可组合的端点，比只卖一次生成更有黏性。你可以问做视频平台的朋友：你们更愿意卖一个全能端点，还是一组能被 Agent 自由编排的积木？这个选择背后其实是商业模式的选择。
第三条，Runway 开源了机器人模型 Praxis-1，用 Apache 2.0 许可开放权重和源码。这个模型把视频训练中获得的知识迁移到机器人控制，在 Nvidia RoboLab-120 基准的 World Action Model 类别里排第一，但目前还无法自主规划复杂动作序列。这是视频生成模型公司第一次把视频理解直接变现成机器人控制能力，而且选择开源。对视频模型赛道的含义是，能力外溢的出口不止创作工具，具身智能可能是第二条分发路径。聊起来可以问：视频模型公司做机器人，是能力外溢，还是在找第二增长曲线？我倾向于后者，但开源这个动作说明他们想先把生态做起来。
再来看 Agent 前沿。LangChain 提出了一个概念叫“目标工程”，英文是 Goal Engineering，主张 Agent 的下一阶段不是执行单步指令，而是被赋予开放式目标后，自己拆解、推进、判断完成度。这解决的是“Agent 只能做被明确描述的任务”这个根本瓶颈。如果这个范式成立，Agent 产品的评估标准会从单步准确率转向目标完成率，对做 Agent 编排和 eval 的团队来说是范式变化。你可以问一句：你们现在衡量 Agent，是看每一步对不对，还是看目标有没有达成？这两个指标背后的产品哲学完全不同。
另一条，Vercel 发布了 UI SDK，提供五十多种 UI 行为，供编码 Agent 直接组装。Vercel Labs 以 Apache 2.0 发布 beta 版库，编码 Agent 可以把这些行为组合成可访问组件，覆盖 React、Vue、Svelte、Solid 和 Web Components，还提供了直接控制 UI 的桥接层。它解决的是 Agent 生成前端时“能写代码但拼不出可用界面”的问题，把 UI 从自由生成变成受约束的组装。对做 Agent 产品的团队，这是降低输出不确定性的实用手段。聊起来可以问：Agent 写前端，你更信任自由生成，还是受约束的组件组装？我的答案是后者，至少在可维护性上。
下面是几条快讯，快速带过。Vercel 社区在 Hacker News 上呼吁 fork 并维护 Deno，指向 Deno 的项目维护前景。Lovable 构建的应用被安全研究曝出泄露护照信息和超过二十万条私信，HN 热度五百三十九，做 Agent 生成应用的团队值得警惕。Nvidia 开发者博客给出实测，用 vLLM 在两台 DGX Station 上服务 GLM-5.3，达到每秒六百零七点八 token 的吞吐。斯坦福开源了 Memorilla，把文档集压成十六个 memory token，在冻结的 Qwen3-8B 上，用比全上下文少一百零八倍的文档 token，在 FactKG 上达到百分之八十四点三三。还有 Cmpnd 发布 dspy-wsp，把权重空间编程带进 DSPy，由前沿 LLM 读取小模型权重、在沙箱里修改并逐次验证，不需要梯度，单次运行大约五到十美元。
最后是今天的观察和商业机会。今天最值得记的信号，是“降价”和“拆积木”同时发生。OpenRouter 上四款主力模型一夜降价，DeepSeek 把 App 能力拆成可自由组合的 API，Anthropic 则用默认模型换代逼着所有人重写提示词。这三件事指向同一个方向：模型层的竞争已经从“谁更强”转向“谁更便宜、更好被编排”。与此同时，Runway 把视频模型能力外溢到机器人控制并开源，说明视频生成赛道的第二条出口可能不在创作工具里。对做视频模型 API 的平台，真正的风险不是某个模型降价，而是聚合层比价的速度超过自己调整定价的速度。
基于这个判断，今天有两个商业机会值得琢磨。第一个是面向 Agent 开发者的“提示词兼容层”或者叫“模型迁移托管”。Anthropic 把 Opus 5.5 设为默认，还公开说旧提示词习惯在拖慢模型，叠加 OpenRouter 上多款模型同时调价，团队每次换代都要重写 prompt 并重跑 eval，这个痛点非常具体。可以做一层托管服务，帮客户在新旧模型之间自动迁移提示词、对齐输出、给出成本对比，依据就是今天 Anthropic 的提示词指南和 OpenRouter 的价格变动。第二个是视频模型能力的“具身”出口打包。Runway 开源 Praxis-1，证明视频训练知识可以迁移到机器人控制，但它还无法自主规划复杂动作序列，这个缺口就是机会。可以面向机器人团队提供“视频模型加动作规划”的组合 API，把视频生成平台的多轮编辑和条件控制能力，包装成机器人训练数据和控制器接口，依据是 Praxis-1 在 RoboLab-120 上的榜首表现和它的规划能力缺口。
好，今天就到这里。一句话总结：模型层在降价、在拆积木，视频模型在找出路，API 平台要比的已经不是模型强弱，而是调整定价和编排能力的速度。我是 Andy，我们明天见。
