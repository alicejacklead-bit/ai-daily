早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 13 日，星期五。先报今天的这一句话：黄仁勋辞职叠加民主党启动国会调查，Nvidia 从“AI 叙事锚点”变成“不确定性来源”，而这恰好是视频模型 API 平台重排供应商、抢占开发者心智的窗口期。
今天信息量很大，我们重点讲三块：第一，Nvidia 这场突如其来的权力真空，会怎么传导到算力采购和 API 吞吐；第二，视频和图像生成赛道的价格表在同一天发生了结构性变化，火山方舟、MiniMax、OpenRouter 三家一起动手；第三，Agent 这一侧，Google 把“判断”这件事单独拆出来做成了一个便宜的 API，这个信号值得你认真听。好，我们开始。
先看市场局势。今天最大的一条，毫无疑问是 Nvidia。11 月 12 日，Nvidia 宣布黄仁勋即刻辞去 CEO、总裁和董事职务，由 Colette Kress 出任临时 CEO。董事会此前已经就他与一名疑似中国间谍的婚外关系启动了独立调查，路透社同一天还报道，他存在第三段与 Nvidia 员工的婚外关系。消息公布之后，公司市值蒸发大约 1.4 万亿美元。紧接着，众议院民主党人对 Nvidia 的对华销售、以及它和特朗普政府的往来发起了国会调查，这是间谍传闻爆发以来的第二次调查。
这件事为什么重要？因为 Nvidia 是全球 AI 算力事实上的唯一“总供应商”，现在它进入了一个没有接班计划的权力真空期。短期的算力采购决策，会被政治和合规审查拖慢。而对下游的模型公司来说，GPU 供给的不确定性会直接传导到 API 的吞吐和价格上。如果你和做视频平台的朋友聊到这件事，可以问问他：如果 Nvidia 的新管理层把更多产能优先给美国本土大客户，你们明年的推理扩容计划怎么排？这个问题问出去，基本就能听出对方对供应链的真实焦虑程度。
第二条还是 Nvidia 的余波。黄仁勋离任之后，Nvidia 对开源 AI 的一系列承诺，包括那笔 129 亿美元收购 Hugging Face 的交易、开放权重模型、以及反对监管限制的游说，全部进入不确定状态。Hugging Face 的 CEO 公开表态，说会继续为开源而战，但外界已经开始质疑这笔收购能不能按原条件完成。
这条对在座各位的意义在哪？Hugging Face 是开放权重模型最重要的分发渠道，里面包含大量视频和图像模型。收购如果生变，开源模型的托管、推理和商业化路径会出现一段空窗期，而聚合平台和自建推理的需求会被推高。这里有个很好的谈资：开源模型的“中立分发层”到底该由谁来当？Nvidia 当股东、Hugging Face 独立运营，你更愿意押哪一边？这个问题在海外创始人圈子里现在正热。
第三条，neocloud 厂商 Nebius 抛出了 400 亿美元的扩张计划，靠客户预付款和借款来融资。同时它一处微软数据中心的交付出现延迟，外界开始质疑它的融资模式。
你要注意，neocloud 是视频和图像模型 API 平台最现实的算力来源之一。用预付款撑资本开支，意味着这些平台会被长期合约绑定，未来 12 个月推理单价还能不能往下探，取决于这批厂商能不能顺利交付。跟人聊天时可以抛这个角度：客户预付款本质上是把算力风险转嫁给了模型公司，你觉得这种结构在需求增速放缓的时候，会先崩在哪一环？
好，接下来是我们最关心的赛道深挖部分，今天这三条，条条都跟你的定价和产品设计直接相关。
第一条，火山方舟上线了 doubao-seedance-2.5 和 2.5-flash，视频价格改成按 token 分档，flash 档最低给到 2.21 元。价格页上 flash 档一共四组数字：2.21、0.44、2.42 到 9.42、5.44 到 21.17。更关键的是新增了一条说明：Seedance 2.0 和 2.5 系列在输入包含视频的时候，存在最低 token 用量限制，最低用量跟分辨率、宽高比、输出时长都相关，官方还配了价格计算器。图像这一侧，新增了 doubao-seedream-5-5，出现 0.05 和“P 小于等于 2.61M 时 0.13”两档报价，同时删掉了旧版 Seedream 按像素分档的 0.30 和 0.60 那两行。
这条为什么给五星？因为它标志着视频生成从“按条计价”转向“按 token 计价加最低消费”。对平台来说，这意味着你必须做用量预估和成本护栏，否则视频输入场景会悄悄吃掉你的毛利。而 Seedream 5.5 的报价档位整体下移，直接压低了图像编辑的 API 底价。这里有个很有意思的产品设计问题，你可以拿去问同行：按 token 计价加最低用量限制，会让客户更愿意传视频，还是更不敢传视频？我的判断是，这个设计其实是在筛客户，它筛掉的是那些随便试试的小客户，留下的是有明确预算的商用场景。
第二条，MiniMax 开源了一款 SOTA 生图模型，原生 4K 输出，大约 10 秒出图，单张成本约两毛钱。官方说它在开源模型里达到 SOTA，还展示了 CAD 拆解这类精细控制能力。
开源加单张两毛，这个组合把图像生成的 API 毛利空间又压了一次。对做聚合分发的平台来说，这类模型很适合放进低价档做引流，但利润要靠 4K 高分辨率档和企业级 SLA 来保。谈资角度给你一个：开源 4K 生图都打到两毛一张了，闭源图像 API 还能靠什么收溢价？是一致性、编辑能力，还是合规？这个问题基本能测出对方对自己产品护城河的理解深度。
第三条，OpenRouter 的模型表大改。新增了 google/gemini-4-hydrogen，prompt 是 0.0000015，completion 是 0.0000075，image 也是 0.0000015，另外还有 batch 半价版。同时上架了 kimi-k2.5、kimi-k3.1-pro、minimax-m3.1-flash、qwen3.5-9b 等等。价格变动里有两个方向特别值得注意：deepseek-v4.1-flash 的 prompt 从 0.000000022 上调到 0.0000003，completion 从 0.0000004 上调到 0.0000012，输入价大概涨了 13.6 倍；而 kimi-k3.1-pro 的 prompt 从 0.000002 下调到 0.0002375，降得非常狠。
聚合平台的价格表就是行业定价的实时温度计。DeepSeek 这个低价档大幅回撤、Kimi 高端档大幅下探，说明两件事：“极低价推理”的补贴期在收尾，而长上下文和 Agent 场景的定价战才刚刚开打。你可以问对方：聚合平台上同一个模型的价格一周能翻十几倍，你们到底怎么决定把哪个模型放在默认位？这背后其实是选品和毛利策略的问题。
好，进入 Agent 前沿。今天第一条，Google 上线了 Gemini Decisions API，由 Gemini Decision 模型驱动，定位是“快速、校准的多模态决策”。单次请求最多可以判定 1000 个封闭式问题，定价是每百万输入 token 0.10 美元，输出免费。Google 还说这个决策模型在 9 项测试里拿下 7 项第一，准确率最高 92.2%。
这条为什么重要？因为 Agent 里大量的环节，本质上都是“分类、路由、要不要继续”这种封闭判断，用大模型来做又贵又慢。现在把这类判断抽成一个专用 API，而且输出免费，等于给 Agent 的决策层单独定了价，这会催生一批“便宜判断加贵生成”的混合架构。谈资角度：如果判断层的成本接近零，Agent 的瓶颈就从模型能力变成了流程设计。你可以问问对方，你们现在还有多少环节在用大模型做 if/else？这个问题问出来，往往能问出一堆技术债。
第二条，AWS 发布了 AWS Emulator，一个免费、CC0 许可的本地 AWS API 仿真器，基于 438 个 API 模型构建，覆盖 200 多个服务。最炸的是，全部代码由自主 Agent 编写，上线时通过了 42857 项公开保真测试中的 56.6%。
这条同时证明了两件事：Agent 能写出可运行的大规模基础设施代码；以及“Agent 产出的代码质量”已经可以用量化的保真度来衡量。对做 Agent 产品的人来说，这是一个可以复用的评测范式。谈资角度很直接：56.6% 的保真度，你会把它当“能用”还是“不能用”？这条线其实定义了 Agent 交付的验收标准，值得跟做 Agent 的朋友好好聊聊。
下面快速过几条快讯。模型侧，Gemini 4 Hydrogen 上线即超越更大的 Argon，在 Artificial Analysis 智能指数上接近 Claude Sonnet 5.5 而且更便宜，但单任务成本大约是 GPT-6.1 Sol 的 2.5 倍，Agentic coding 还是偏弱。语音侧，ElevenLabs 发布 Scribe v3 和 Scribe v3 Live，在嘈杂和串话场景下准确率略胜 OpenAI、Google 和微软，但速度慢好几倍，价格大约是对手的两倍。监管侧，澳大利亚拟立法强制前沿模型接受独立审计，新设监管机构负责审计并对违规重罚，堪培拉选择先立国内法再进国际谈判。合规侧有个很扎眼的基准叫 ScrapeBench，测的是主流 AI Agent 对 robots.txt 和服务条款的合规率，结果低于 5%，闭源开源普遍表现极差。最后，CopilotKit 开源了 OpenBot 1.0，MIT 许可、可自托管，定位是 AI 同事工作区，每个 Bot 动作先过策略检查、再进审计日志。
好，到了今天的观察和商业机会，我们聊得随意一点。
今天所有信号其实指向同一件事：算力和分发这两端同时在松动。Nvidia 的领导层真空，让 GPU 供给和 Hugging Face 收购都变成了变量；而 OpenRouter 和火山方舟的价格表在同一天告诉我们，低价推理的补贴在退潮，视频和图像这一侧开始用“按 token 加最低消费”和“开源低价模型”重新分层。对视频生成 API 平台来说，真正的竞争点正在从“能不能调用最强模型”，转向“能不能把贵模型和便宜模型编排进同一条工作流”。而 Gemini Decisions API 输出免费，又把这条路线的成本结构压低了一档。我个人判断，未来几周会出现一批“判断用决策模型、生成用视频模型”的混合产品，这个方向值得你盯紧。
商业机会我讲两个。第一个，是视频 API 的成本护栏产品。依据就是火山方舟这次对 Seedance 2.0 和 2.5 引入的“输入含视频时的最低 token 用量”，而且用量随分辨率、宽高比、时长变化。做 API 聚合或转售的平台，需要一个前置的用量估算和预算熔断层，帮客户在下单前就算清一条视频的真实成本。这是个很具体的产品缺口。
第二个，是开源图像模型的“高端档”包装。依据是 MiniMax 开源 4K 生图做到单张约两毛，加上 Seedream 5.5 报价档位下移这两条，闭源图像 API 的底价已经被击穿。机会在于把开源模型包成带一致性编辑、商用授权和企业级 SLA 的高价档，服务那些不能直接用开源权重、但有预算的品牌和电商团队。
最后总结一句：当算力锚点开始摇晃，胜负手就不再是谁能调用最强模型，而是谁能把贵和便宜编排成一条稳定的工作流。好，今天的早报就到这里，我们明天见。
