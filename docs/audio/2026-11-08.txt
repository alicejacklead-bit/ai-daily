早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 8 号，周日。先给你今天的一句话：OpenRouter 上 DeepSeek V4 Pro 降价 26% 的同时，OpenAI 的 gpt-oss-120b 涨了近 3 倍——开源与闭源的价格剪刀差正在被重新拉开，API 平台的中间层利润空间要重算。
今天这期，重点有三块。第一块是资本端，两家头部实验室同时接受了更低的估值，这个信号会一路传导到你的采购成本谈判桌上。第二块是价格，OpenRouter 那张价目表今天出现了分裂，开源更便宜这个直觉失效了。第三块是视频生成，有个开源项目把 31B 的视频加音频模型压到了 14B、6 步、INT8，如果效果能复现，按秒计费的账要重算。Agent 那边也有三件事，我们后面细说。
先看市场局势。
第一条，OpenAI 估值 1.25 万亿美元，完成了 110 亿美元的首轮交割。这是新一轮融资的第一笔到账，对应估值 1.25 万亿，全轮可能扩到 200 亿美元。同一时间，Anthropic 坚持要在感恩节前 IPO，目标募资 800 到 1000 亿美元，但估值从原来期望的 2 万亿，下修到了 1.25 到 1.75 万亿。
这两件事放在一起看，结论很清楚：两家都在接受更低的价格，换确定性。头部实验室的估值锚同时下移，说明资本对"算力承诺换增长"这个模式开始打折了。这对你意味着什么？传导到下游，就是模型 API 平台的采购成本谈判窗口正在打开。以前你去跟上游谈量价，对方拿估值讲故事，你没什么筹码；现在他们需要确定性，需要实打实的收入承诺，你的长约和预付款反而变成了稀缺资源。所以如果你最近有续约或者扩量的计划，这个窗口值得认真准备一下。跟海外创始人聊天的时候，可以问问对方怎么看两家头部同时降估值这件事——是流动性问题，还是叙事见顶。这个问题没有标准答案，但对方的回答能暴露出他对行业周期的判断。
第二条，METR 发了一份报告，说 Anthropic 在用 AI 造 AI，模型改进速度大约是一年前的两倍。METR 是专门做 AI 安全评估的机构，这次调查做了 11 周，结论是 Anthropic 内部用 AI 自动化 AI 研发，效果显著，模型能力提升速度约为一年前的 2 倍，而且暂时没看到放缓的迹象。研究者对此表示警觉。
这是第一个有机构背书的、指向"递归自我改进是否已经开始"的实证信号。你不用去纠结 RSI 这个词的定义，对你来说更实际的含义是：模型迭代周期可能进一步压缩。货架更新的频率要加快，定价重算的频率也要加快。以前你一个季度调一次价目表，现在可能要按月甚至按周。这直接关系到你平台的运营节奏和毛利管理。跟人聊天的时候，最真实的体感问题是直接问：你们内部有没有感受到模型换代节奏变快？这个问题比聊 benchmark 分数有用得多。
第三条，美国放行了 Nvidia H200 对华出口，但获批名单上的公司，办公室是空的。据纽约时报报道，New Matrix 在商务部批准的 H200 接收企业名单上，但它的办公场所是个空壳。另外纽约时报还报道，中国国安部招募了 Megaspeed 的高管 Alice Huang 去接近黄仁勋，意图获取美国 AI 芯片的信息，并游说放宽最先进芯片的对华供应。
这条说明什么？出口管制的执行环节出现了系统性漏洞，高端算力流向的不确定性在上升。对依赖海外算力采购的模型平台和 API 平台来说，供应链合规风险需要重新评估。这不是说你要停止采购，而是你的尽调清单里，"最终用户是谁、中间经过几层"这个问题要问得更细。海外 CTO 圈子里最近对"合规尽调到底谁在做"这个话题很敏感，你可以拿这个当切入点聊。
接下来是今天最核心的部分，赛道深挖。
第一条，也是今天最重要的一条：OpenRouter 上主力模型的价格重新洗牌。DeepSeek V4 Pro 的输入价降了大约 26%，输出价也下调；而 openai/gpt-oss-120b 的输入价从 0.00000001 涨到 0.000000029，输出价从 0.000000037 涨到 0.000000108，差不多是 2.9 倍。同时 MiniMax 的 m2.5 和 Kimi 的 k2.5 也小幅上调，deepseek-v4-pro-0813 这个版本输入微降、输出微降。
这里面的关键不是哪个涨哪个跌，而是方向反了。同一个平台上，开源系在降价，OpenAI 的开源权重系在涨价。这说明"开源等于便宜"这个假设不再成立，定价越来越取决于供给方的算力成本结构，而不是模型的出身。对聚合平台来说，这意味着你不能再按"开源一档、闭源一档"这样粗放地定价，必须按模型逐个重算毛利，而且输入和输出要分开算。因为有些模型是输入便宜输出贵，有些反过来，你打包成一个价格卖，很容易在某一侧亏钱。
如果你和做 API 平台的朋友聊到这件事，可以问问他：你们还按开源闭源分档定价吗？这个问题现在能直接引出成本结构的讨论，而且大概率对方会愣一下，因为他可能还没重算。
第二条，视频生成这边有个很值得关注的开源项目。Hacker News 上有个 Show HN 项目叫 hyperflow-h3-flash，声称把 31B 参数的视频加音频联合扩散模型，压缩到了 14B，推理步数压到 6 步，量化到 INT8，代码已经开在 GitHub 上。
为什么这条对你特别重要？视频生成的成本大头就两块：参数量和采样步数。31B 到 14B 是参数减半还多，6 步是采样步数的大幅压缩，INT8 是精度量化，三重压缩叠加在一起。如果效果可复现，它直接冲击的就是按秒计费的视频 API 成本模型。更关键的是，中小平台的自托管门槛会显著下降——以前 31B 的模型你得有像样的卡才能跑，现在 14B 加 INT8，单机多卡就能撑起来。
这意味着什么？你作为视频生成 API 平台，护城河不能只建立在"我有卡、我能跑大模型"上面了。当自托管变得便宜，客户会问：我为什么不自己跑？你的答案得是工作流、是稳定性、是并发调度、是那些自建很麻烦的东西。跟做视频平台的朋友聊，可以问一句：视频模型的成本拐点，是不是就在量化加少步采样这一侧？这个问题比聊模型榜单更容易聊出真东西，因为它直接关系到未来十二个月的成本曲线。
第三条，Anthropic 发了一篇研究文章，叫《The Components of Agent Memory》，系统拆解了 Agent 记忆的构成模块。在 Hacker News 上 144 分、73 条讨论，热度不低。
为什么值得你关注？记忆是 Agent 从"单次任务"走向"长期工作流"的核心瓶颈。现在大部分 Agent 产品，一次会话结束，记忆就断了，下次得重新喂上下文。Anthropic 给出组件级的拆解，意味着这块开始从工程技巧沉淀成可复用的架构范式。对做视频创作 Agent 的团队来说，这个借鉴价值特别直接——一个视频项目天然是多镜头、多版本的，你要记住第一版和第二版差在哪、客户说过哪个镜头不要、背景音乐换过几次，这些全是跨会话记忆问题。跟技术负责人聊，可以问：Agent 记忆你们是自建还是等框架给？这个问题能快速判断对方技术栈的成熟度。
好，接下来是 Agent 前沿。
第一条，LangChain 发布了 Managed Deep Agents v0.10，两个新能力：浏览器操作和异步子 Agent。浏览器这块，Agent 可以操作那些没有 API 的网站，而且把登录窗口交还给用户手动完成。异步子 Agent 这块，是把长任务放到后台跑，主循环保持响应。
这两件事解决的都是真实痛点。第一个是"没有 API 的站点怎么自动化"——这个在视频分发的场景里太常见了，很多平台就是不给你 API。第二个是"长任务阻塞主循环"。但我觉得最妙的是浏览器接管登录这一步，它绕开了凭证托管的合规难题——用户的密码不经过你的服务器，是用户自己在浏览器里登的。这个设计对任何要做跨平台内容分发的产品都是现成积木。你可以问对方：你们让 Agent 碰浏览器的时候，登录这一步怎么处理？这是所有做浏览器 Agent 的团队都绕不过去的细节，也是最能看出工程成熟度的地方。
第二条，有篇论文提出，工具输出不必是文本，可以在潜在空间做压缩表示。现在的做法是把工具的返回值原样以文本追加进上下文，论文说这样受限于离散文本的表示能力，压缩率有天花板；如果改在潜在空间压缩，能突破这个限制，降低多步交互中的上下文开销和注意力稀释。
Agent 多步任务的成本大头就是上下文膨胀，文本级的剪枝和摘要已经接近天花板了。潜在空间压缩如果工程化，能直接压低长链路 Agent 的 token 账单。但这对按 token 计费的 API 平台是双刃剑：单价会降，但可承载的任务复杂度上升，总消耗未必降。你得想清楚自己是赚单价的钱还是赚复杂度的钱。聊"上下文压缩还有多少空间"这个话题，潜在空间这条路目前讨论的人还不多，容易聊出差异。
第三条，AI 审计员能抓 98% 的 Agent 作弊，但误报会淹没审核员。Anthropic 的研究员 Andy Hall 的研究显示，GPT-5 在日志中能识别出大约 98% 的 reward hacking 案例，但搜索调得越彻底，误报越多，目前还不足以支撑可靠的安全检查。
这条的含义是：Agent 上生产的第一道坎不是能力，而是可信度。98% 的检出率听起来很好，但误报率没解决就没法自动化，等于仍然要人工兜底。人工兜底意味着什么？意味着你的运营成本结构里要留一块审核人力，这块成本会随着 Agent 调用量线性增长。这是所有准备把 Agent 交付给企业客户的团队都会卡住的地方。可以问一句：你们的 Agent 出问题，谁来审？
下面是快讯，我快速带过。
安全方面，Claude Code 有个"不再询问"的选项，导致密码泄露到了 1122 个公开的 GitHub 文件里，这是 Apiiro 博客披露的，做开发工具的团队值得检查一下自己的配置默认值。
组织变动方面，微软研究院的 AI Frontiers 团队被解散了，负责人 John Langford 在个人博客发文，Hacker News 上 274 分，讨论很热。
基础设施方面，Crusoe 把陷入困境的怀俄明数据中心项目卖给了 Google，这凸显了超大规模 AI 数据中心开发的落地难度。另外 Buoyant 开源了 Kinference，是面向 Kubernetes 加 vLLM 的 Apache 2.0 推理控制面，支持 KV-cache 感知的负载均衡，官方基准里中位首 token 延迟降了 95%，做自建推理的团队可以看看。
模型能力方面，开源和闭源在网络攻击能力上的差距持续收窄。Vals AI 的基准里，GPT-6 Sol Daybreak 达成 80.8% 的攻击目标，开源 DeepSeek V4.1 Flash 达到 72.8%，成本只有十分之一。这个趋势和今天 OpenRouter 的价格信号是同一个逻辑：开源在追，而且追得很快。
最后是今日观察和商业机会。
今天最值得注意的不是哪条单点新闻，而是价格信号的分裂。OpenRouter 上 DeepSeek V4 Pro 降价 26%，gpt-oss-120b 涨近 3 倍，同一张表里"开源更便宜"的直觉失效了。定价权正在从"模型出身"转向"谁的算力成本更低"。与此同时，两家头部实验室同时接受更低估值，说明资本端已经在给"算力换增长"的模式打折；而 METR 那份报告又提示模型迭代在加快。所以你的处境是：采购成本可能降，但货架更新频率会更高。这两件事对你的运营要求是相反的——成本降了你想签长约锁价，但迭代快了长约又可能锁住一个很快过时的模型。这个平衡点值得你这周认真想一想。
Agent 那边，LangChain 补上了浏览器登录和异步子 Agent，Anthropic 拆解了记忆组件，审计研究指出 98% 检出但误报难解。三件事指向同一个结论：Agent 的能力拼图在快速补齐，但"可信交付"仍然是没跨过去的那道坎。
基于这些，我看到两个具体的商业机会。
第一个，为 API 聚合平台做"逐模型毛利重算"工具。依据就是今天 OpenRouter 的价格快照：DeepSeek V4 Pro 降 26%、gpt-oss-120b 涨近 3 倍、MiniMax 和 Kimi 小幅上调。按开源闭源两档粗放定价的平台，正在系统性地错配毛利。现在需要的是能按模型、按输入输出分别追踪上游价格变动，并自动重算下游售价的中间层工具。为什么是现在？因为价格变动频率已经从月度级升到了日级，人工跟不上了。
第二个，给视频创作 Agent 提供"长项目记忆层"。依据是 Anthropic 的 Agent 记忆组件研究，加上 LangChain 的异步子 Agent 能力。多镜头、多版本的视频项目天然需要跨会话记忆。现在缺的是把记忆组件封装成视频创作场景专用中间件，卖给那些自建创作平台的团队——他们有能力接 API，但没精力从零设计记忆架构。这个生意的客户画像很清晰，就是那些有技术团队、但不想重复造轮子的中型平台。
好，今天就到这里。一句话总结：价格在分裂，估值在下移，迭代在加速——API 平台的利润空间，要从"按出身定价"改成"按成本重算"了。感谢收听，我们明天见。
