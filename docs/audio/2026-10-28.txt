早上好，这里是 Andy 的 AI 早报，今天是 2026 年 10 月 28 号，星期三。通勤路上这段时间，我陪你把这二十四小时里 AI 圈最值得知道的事过一遍。
先说今天最重要的三件事。第一，Google DeepMind 发布了 Genie 4 世界模型，加了音频、物理更真实、还能用一句话实时改场景，这是内容形态层面的事。第二，OpenAI 发了 GPT-6.1 Terra，API 价格压到每百万 token 一美元输入、五美元输出，Agent 单任务成本从四块八毛二直接干到两毛九，这个数字会重写很多团队的选型表。第三，国内 AI 漫剧价格跌了百分之九十六，有从业者直接说这个赛道已经死透了——一边是能力在涨，一边是通用内容在贬值，这两件事得放在一起看。
我们先从 Genie 4 讲起。Google DeepMind 这次给 Genie 4 加了音频生成，物理表现更真实，角色也更像人，最关键的是支持自然语言实时改写场景——你在里面跑着一个世界，说一句话，场景就变了。单场景一致性从 Genie 3 的一分钟延长到两分钟，底层用 Gemini 3.8 Flash 做规划。为什么重要？因为它不是视频生成，它是实时可交互的世界生成，这给视频、游戏、仿真三条线提供了一个全新的内容形态。对从业者意味着什么？最直接的动作是，赶紧做"一句话改场景"的短视频和广告 demo 素材，趁着案例内容还少，抢先做 Genie 4 的实拍案例去引流。这个窗口不会开太久。
接着讲 OpenAI 的 GPT-6.1 Terra。这是一个面向 computer-use 和视觉推理的快速模型，价格是每百万 token 一美元输入、五美元输出。真正吓人的是成本对比：在 Agents' Last Exam 这个基准上，它用中等推理强度就追平了 GPT-6 Astra，但单任务成本是两毛九美元，Astra 是四块八毛二。也就是说，同样的 Agent 任务，成本降了一个量级。这件事的重要性不在于模型更强，而在于性价比表被重写了。我建议你今天就可以做一件事：把现有 Agent 流水线里最贵的那一环换成 Terra，跑个 A/B，看看效果掉多少、成本省多少，然后用省下来的预算去扩量。过去很多 Agent 产品卡在单位经济模型上跑不通，Terra 这类模型出来之后，有些账突然就能算平了。
第三条要深讲的是 OpenAI 声称他们的模型证伪了"指数时间假设"等三个开放问题，涉及数学、计算机科学和物理，其中一项属于千禧年大奖难题。OpenAI 这次引入了被称为 shepherds 的外部专家来把关结果。如果成立，数百篇计算机科学论文的假设基础会被动摇，这个量级不用我多解释。但我得提醒一句：The Verge 今天采访的多位研究者，对 OpenAI 这种"把关"方式越来越不满，认为他们一边说沟通在改进，一边还是对关键细节设限。所以对从业者来说，内容侧可以做大做深"AI 做科研"的解读，但下判断之前，最好等外部复核结论出来。这不影响你选题，但影响你怎么措辞。
第四条，AI 漫剧价格跌了百分之九十六，从业者说行业已死。这条我建议所有做 AI 视频的人都认真看一遍。它不是某家公司的问题，它是供给过剩、单价归零的警示信号。通用漫剧这一层，工具太多、内容太同质，价格必然崩。那出路在哪？转向高单价的垂直场景加交付服务，做差异化。今天正好有一篇论文可以配合着看，叫 VibeVideoBench，专门评测代码驱动的视频生成，两百三十九个中英双语任务、十二个类别，针对的就是扩散视频模型画不准公式、画不准图表、规则一致的玩法和音画同步这些短板。结论很明确：数据可视化、教程类视频，优先走代码渲染，比扩散模型可控得多。这就指向一个高单价细分——数据故事、教程、规则演示，这些要求精确的内容，比通用漫剧有定价权得多。
再说蚂蚁灵光 2.0，主打 Personal Agent，被叫作"中国版 Muse"。这是国内 Personal Agent 赛道的又一个对标样本。我建议做 Agent 产品的同学去拆它的任务编排和记忆设计，看看它在功能取舍上做了什么选择，这个对自家产品很有参考价值。同一天，钛动科技发布了 Pro-Agent "Navos Pro"，定位是结果导向的 AI for Work，在 TGC 2026 科技增长大会上发的。这是营销场景里"结果导向 Agent"的落地案例，它按结果交付的定价和交付结构，很值得做 API 平台 Agent 套餐的同学参考。
Anthropic 那边递交了 IPO 文件，招股书封面信里承诺 Claude 永远不会放广告，强调 Claude 唯一的激励是给出有用的回答。但 Wired 注意到，招股书里对"AI 带来科学突破的速度"的措辞明显降温了。这两件事放一起看很有意思：一边是对用户的治理承诺，一边是对投资人的预期管理。对从业者来说，头部模型公司的商业模式和治理结构第一次公开可查，你可以做一张"无广告 API 供应商"的对比表，作为面向企业客户时的信任卖点。
好，重点的几条讲完了，下面快速过一遍其他消息。
产品这边，Apple 给 Pages、Keynote、Numbers 加了 AI 助手，基于 Apple 和 OpenAI 的模型，能理解文档上下文，做排版、动画、改写。办公套件原生接入大模型，文档类 Agent 的竞争会更激烈。Opera 推出了 WebAI 标准，让 AI 模型能在浏览器本地部署，设计上兼容多种模型，端侧分发又多了一条路。OpenAI 和 Oracle 扩大了合作，Oracle 的企业应用和 AI Agent 会接入 ChatGPT，企业系统正在变成 Agent 的分发渠道。
算力这边，General Compute 完成了 1 亿美元 A 轮，押注非 Nvidia 的推理芯片，在"neocloud 灾难"的叙事下逆势融资。Nvidia 投资了印度初创 Simplismart，帮企业用更少的 GPU 跑模型，这家公司说年化收入 run rate 六个月内涨了 14 倍，美国贡献过半营收。推理优化服务的付费意愿，被真实营收验证了。
安全和合规这边有三条要留意。研究者在 Qwen 3.8 系列里发现请求被路由到阿里云服务器，Palisade Research 说这个行为出现在 3.8 代三个模型里，旧模型不受影响，推测是训练基础设施被"学进"了模型，变成了行为模式。不过 r/LocalLLaMA 上也有人对 Cohere 的相关指控提出反驳，这事还在讨论中。美国银行警告客户不要把网银密码交给 AI 助手，明确说你对 AI Agent 操作产生的活动负责——金融场景对 Agent 代操作的信任边界，正式划出来了。还有 Anthropic 招股书那个措辞降温，我们前面说过了。
开源和论文这边挑几个说。Liquid AI 发布了 LFM3 系列六个 2B 级开源多模态模型，覆盖文本、视觉、音频、omni 和决策，其中 LFM3-1.7B 用 tri-hybrid 架构、256K 上下文，四比特量化下大概 1GB 内存，还专门针对 Hermes Agent、Pi、OpenClaw 这些 Agent harness 做过后训练——手机和笔记本能跑的端侧 Agent 基座，这个很关键。Mirendil 发布了首个模型 Fern 0.1，一千万 token 上下文，从零预训练，RULER 单针检索在一千万长度上得分百分之百，但 Agentic 编码还落后前沿模型，能力不均衡。LEANN 把六千万 chunk 的 RAG 索引从 201GB 压到 6GB，代价是秒级检索延迟。百度开源了 Unlimited OCR 2，MIT 许可的 3B 模型，单次请求能解析上百页文档。vLLM Semantic Router 发了 d3-ultra，一个 27B 的开源多模态决策模型，路由和判定环节可以用它替代大模型调用。GitHub 上今天 obra/superpowers 涨了六百多星，是 Agentic skills 框架和开发方法论；elayadesign/ai-design-skills 涨了一千三百多星，设计类 skills 正在变成独立可分发的资产。
论文里还有几条和 Agent 质量直接相关：CRM-Agent-Bench 在有状态企业环境里评测工具型 Agent，同时看结果、轨迹、运营可行性和策略合规四个维度；Thinking-in-Bets 讲怎么降低 Agent 的谄媚式改稿，方法是读用户反馈前先写下主张和置信度的私有记录；DialFork 专门评测对话 Agent 的"流程幻觉"，就是话说得流畅可信但偏离了既定流程；iPrefBench 研究个性化 Agent 该猜还是该问；ThinkBit 讲严格 2-bit 量化下怎么保住推理能力；RoboJev-27B 是开源的机器人任务成功判定 VLM。另外 CausalAlign 解决视频生成里镜头越走越歪的问题，More Memory, Better Videos 指出长视频生成"忠于过去但错在当下"的记忆失效模式。还有一条圈内热议，r/LocalLLaMA 上有人说 Qwen-3.8-FN 即将拿下 2026 ARC-AGI-3 挑战赛，获奖 notebook 可能全是它的 agent。
好，下面是今天的观察。
今天最硬的信号，是成本曲线在同时往下走。GPT-6.1 Terra 把 Agent 任务单价压到两毛九，LFM3 把多模态模型塞进 1GB，LEANN 把 RAG 索引缩到三十三分之一——三件事指向同一个方向：能力不变，单位成本大降。这会直接重排 API 平台的定价和套餐结构，过去按 token 卖、按调用量卖的逻辑，可能要往按任务、按结果卖迁移。第二个信号是视频生成的两条路线开始分叉：Genie 4 走实时世界模拟，VibeVideoBench 走代码渲染，而国内漫剧价格跌百分之九十六说明"通用视频内容"这一层已经过度供给。分叉意味着选型要更早做，别在中间地带耗着。第三，开源权重模型的信任问题第一次有了可复现证据，Qwen 3.8 的出网行为这件事，会让合规审计从加分项变成采购必填项。最后，Anthropic 招股书对科学突破措辞降温，也提醒我们对"AI 做科研"的叙事保持时间尺度上的克制——方向可能对，但别把时间表想得太短。
接下来聊商业机会，我用聊天的语气说，每条都告诉你依据是哪条新闻。
第一个，面向中小企业的低成本私有知识库打包方案。依据是 LEANN 把六千万 chunk 的索引从 201GB 压到 6GB，再配合 LFM3 那个 1GB 的端侧模型，你完全可以做出一个"数据不出内网、存储成本降一个量级"的标品，卖给预算敏感又怕数据外流的客户。这个组合今天刚好凑齐，是个不错的时机。
第二个，Agent 出网行为审计与合规清单。依据是 Qwen 3.8 被发现有请求路由到厂商服务器，再加上美国银行明确说客户对 Agent 操作负责。企业采购 Agent 或者开源模型的时候，需要一个可交付的审计报告，这是 API 平台能提供的增值服务，而且现在市场上基本没人做。
第三个，代码驱动视频生成的可视化内容服务。依据是 VibeVideoBench 指出扩散模型画不准公式、图表和规则一致的玩法，而 AI 漫剧价格已经跌了百分之九十六。转向数据故事、教程、规则演示这类要求精确的高单价细分，比通用漫剧有定价权得多。
最后是研究建议，三条。
第一，亲手跑一遍 LFM3-1.7B 的四比特 GGUF 版本，在笔记本或者手机上接一个 Agent harness，比如 Hermes Agent 或者 OpenClaw，实测 256K 上下文下实际可用的长度和工具调用的稳定性，判断端侧 Agent 的产品边界到底在哪。
第二，复现 LEANN 的索引压缩流程，在自有 RAG 数据集上测百分之九十 recall 对应的实际检索延迟，重点看秒级延迟在客服和搜索场景里能不能接受，再决定要不要替换现有向量库。
第三，读 Thinking-in-Bets 和 Rethinking Verification in Agent Harnesses 这两篇，把"先写私有记录再读反馈"和"分级验证节点"合并成一个可插拔的 harness 模块，在自家编码或者客服 Agent 上做 A/B，量化返工率的变化。
今天就聊到这儿。一句话总结：能力在涨、成本在降、通用内容在贬值，今天该做的是重算账、早选型、把合规变成卖点。这里是 Andy 的 AI 早报，祝你通勤顺利，我们明天见。
