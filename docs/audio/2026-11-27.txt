早上好，欢迎收听《Andy 的 AI 早报》，今天是 2026 年 11 月 27 日。先给你今天的一句话：Anthropic 上市当天，市场用 GTA VI 的销量给它上了一课——效率不是护城河，不可替代的体验才是；而视频生成赛道，则在中国开源模型把商用级价格打到每秒五毛的同一周，继续被上游算力和出口管制重新定价。
今天的内容挺密集的。市场局势这边，我们要聊三件事：Anthropic 上市和 GTA VI 破纪录的同日对照，Nvidia 停止向四个东南亚国家发服务器，以及中国实验室被芯片管制和反蒸馏拖慢的迹象。赛道深挖是你最关心的部分：一款中国开源视频模型打出了每秒五毛人民币的商用级价格，WaveSpeedAI 的价格页又调了一轮，OpenRouter 的主力模型表也在动。Agent 前沿有一个挺关键的变化，MCP 服务器现在可以直接分发 Agent Skills 了，同时 Notion 的官方 MCP 被曝出往 Agent 上下文里塞隐藏的追加销售指令。最后我们串一下快讯，再聊聊今天的观察和机会。路上时间刚好，我们开始。
先说市场局势的第一条，也是今天分量最重的一条。Anthropic 在 11 月 26 日正式进入公开市场。就在同一天，打磨多年的《GTA VI》成为史上最成功的娱乐产品发布之一。TechCrunch 的评论直接把这两件事并排放在一起：一边是效率至上的 AI 叙事，一边是人力密集型产品创下的商业纪录。
这件事为什么值得你在通勤路上想一想？因为这是对"AI 压缩一切生产成本"这个叙事的第一次公开市场压力测试。之前大家讲 AI 的价值，讲的都是更快、更便宜、更省人。但 GTA VI 用真金白银的销量提醒市场：消费者愿意为"别处拿不到的东西"付钱，而不是为"生产成本低"付钱。
对我们做模型 API 平台的人来说，含义非常直接：客户不会只为便宜买单，他们会为别处拿不到的质量付溢价。定价权正在从"每 token 更便宜"转向"你的输出是否不可替代"。这个转向对视频生成尤其明显，因为视频的"可替代性"判断比文本更主观，客户看的是成片能不能用，而不是单价表上的数字。
如果你和做内容平台或者做视频工具的朋友聊到这件事，可以问问他：如果 AI 让内容生产成本趋近于零，你的产品靠什么证明自己不是可无限复制的商品？这个问题听着有点扎，但现在是资本市场上真正在定价的问题。
第二条，算力这边出了个不小的动作。Nvidia 已经通知 Dell、Supermicro 这些合作伙伴，停止向马来西亚、新加坡、泰国、印尼这四个东南亚国家出货服务器，背景是新一轮针对中国云访问的出口管制。经销商现在正在为数千颗 B300 芯片寻找买家，一位云高管的原话是局面"混乱"，东南亚数据中心的相关贷款和大额交易都受了影响。
这条说明什么？说明算力供给的地理版图正在被行政手段切分。以前我们讲算力成本，讲的是规模、电价、机房位置；现在还要讲一个东西，就是司法辖区。对做海外 GTM 的 API 平台，这意味着"模型部署在哪个区域、由谁托管"会变成客户采购的硬性合规问题，而不只是成本问题。
这个变化对视频生成赛道其实影响更大，因为视频推理的算力密度高、单次生成贵，客户一旦上量，跑在哪儿就成了采购流程里绕不过去的一栏。以前客户问你每秒多少钱，以后客户会先问你推理跑在哪个司法辖区、芯片来源能不能追溯，然后才谈价格。
谈资角度在这儿：东南亚作为"算力中转站"的角色被打断之后，这个问题以后会出现在每一份合同里。你和海外的创始人或者 CTO 聊天，可以问问他们采购清单里有没有加上这一栏。大部分人现在还没加，但法务已经在推了。
第三条，是这两件事的延伸，也是很多人容易忽略的一条。据 The Decoder 报道，芯片限制、反蒸馏措施，加上海外 Nvidia 硬件获取的收缩，正在给 DeepSeek、Moonshot AI、阿里这些中国实验室施压。DeepSeek 研究人员的内部估计是，他们已经落后美国模型最多九个月，而且差距在扩大。同期还有一条报道说，Z.AI 和 Moonshot 被迫推迟了下一代旗舰模型，并且转向 Google 和 Meta 的数据源。
这条对我们意味着什么？它直接关系到 API 聚合平台"低价中国模型"这条供给线的可持续性。过去一年，很多平台的性价比结构是建立在中国开源模型的价格优势上的。但如果旗舰模型的迭代节奏被拉长，那价格优势可能是以能力代差为代价换来的。也就是说，你便宜，但你落后一个版本、两个版本，客户在用的时候是能感觉到的。
所以聚合平台需要重新评估自己的模型组合结构。不是简单的"哪个便宜上哪个"，而是要看每一档价格背后对应的是什么能力水平、什么迭代节奏。如果一条供给线的下一代模型要推迟半年，你的产品路线图就得提前做预案。
这条的谈资角度我觉得是最近海外 CTO 最愿意聊、也最没底的问题：中国开源模型的价格优势还能撑几个版本？你问这个问题，对方一般会有话说，因为他们自己也在算这笔账。
好，接下来进入你今天最关心的部分，赛道深挖。第一条，中国开源视频模型打出了"顶尖商用级、每秒五毛"。
据量子位报道，一款中国开源新势力的视频模型拿下某个榜单的全球第一，主打商用级质量，定价大约每秒 0.5 元人民币，支持 30 秒一镜到底，还能自动编排镜头。我们算一下，每秒五毛人民币，大概不到 0.07 美元每秒，这个价格显著低于当前主流视频 API 的公开单价区间。
这里面有两个点要分开看。第一个是价格。如果这个每秒五毛可以稳定复现，那视频 API 的"质量—价格"前沿会被整体下压。所谓前沿下压，就是说同样的质量，市场价格锚点被往下拉了一截。对聚合平台来说，靠转售差价的空间会被压缩，你必须往增值层走。
第二个是能力。30 秒一镜到底加上自动镜头编排，这两个不是价格战的东西，是产品能力。一镜到底意味着长镜头的连贯性和角色一致性；自动编排镜头意味着它开始碰导演的工作，而不只是生成片段。这两点对商用客户的价值，其实比单价更大。
所以对我们的启示是：视频 API 平台不能只卖模型调用，得转向工作流、镜头控制、批量一致性这些增值层。因为当底层模型的价格被打到地板，中间层如果只做转发，就没有存在的理由了。
这条的谈资角度很直接：当开源模型把"商用级"打到这个价位，视频 API 平台卖的到底是模型，还是镜头调度和一致性保障？你和做视频平台的朋友聊，可以问问他，他们客户续费的理由是价格还是出片率。这个答案基本决定了他的毛利结构。
第二条也是视频赛道，但是另一个方向。WaveSpeedAI 的价格页又调了一轮：某个档位从每秒钟 0.1335 美元，相对 0.157 美元降 15%，变成了每秒钟 0.1413 美元，降幅收窄到 10%。同时对应的生成耗时从 7.4 秒缩短到 7 秒。
这是本周第二次看到"降价幅度收窄加上速度提升"这个组合。它说明什么？说明聚合平台正在把竞争维度从纯单价转向"每秒有效产出"，同时也暗示上游的推理成本并没有随规模下降。换句话说，规模上去了，成本没怎么降，那降价的空间自然就收窄了。
这对定价策略的启示挺重要的：按秒计价之外，"每秒可交付成品时长"可能成为更诚实的报价单位。因为客户真正在意的不是生成一秒钟视频花多少钱，而是拿到一秒能用的成片花多少钱。这两个数字之间差着废片率、差着重试次数、差着人工筛选的时间。
所以你可以看到，第一条新闻是把价格往下压，第二条新闻是降价空间在收窄、大家开始用速度换价差。这两条放在一起，恰好说明视频 API 的竞争正在换维度。
谈资角度：客户比价的时候，看的是每秒钟单价，还是每出一条可用视频的成本？后者才是真实 TCO。这个问题你可以直接抛给海外的创始人，很多人会愣一下，然后开始跟你算废片率——这通常是一场很好聊的对话的开头。
第三条，OpenRouter 的主力模型表有更新。新增了 DeepSeek V4 Pro，prompt 每百万 token 0.713 美元，completion 每百万 token 1.522 美元；新增了 Kimi K2 和 K2 0905 两个版本；还新增了 Qwen3.8 27B，prompt 每百万 token 0.06 美元，completion 每百万 token 1.96 美元。同时有几款模型的旧价格行被替换，其中 Gemma 3 27B IT 的 completion 价从每百万 0.16 美元涨到了 0.45 美元。
这里有两层信息。第一层，聚合平台正在把"中国模型加小参数高性价比模型"作为货架主力，这个趋势很明显，货架结构在往这个方向摆。第二层，同款模型的 completion 价在上调，说明低价窗口在收窄。
对我们以视频为主业的平台来说，这条的意义在于成本结构。大部分视频工作流里都有文本侧的开销：prompt 增强、脚本生成、镜头描述、批量任务的分发逻辑。这些以前用的是最便宜的文本模型，一涨价，整个工作流的毛利就被悄悄吃掉一块。
谈资角度就在这儿：文本模型涨价会悄悄吃掉视频工作流的毛利，而大多数团队还没把 prompt 编排的成本算进单条视频成本里。你和别人聊的时候可以提一句，问问他单条视频的成本核算里有没有文本这一项。十有八九是没有的。
好，接下来是 Agent 前沿。今天有两条，一条是机会，一条是坑，刚好配成一对。
第一条，Anthropic 让 MCP 服务器可以直接分发 Agent Skills，目前进入公测。在推出 MCP 两年之后，Anthropic 为 Claude 和 Claude Code 加入了"Skills over MCP"的支持。这意味着企业在连接一个 MCP 服务器的时候，拿到的不仅是一组工具，还可能是一整套预置技能。
这件事解决的是什么问题？以前 Agent 的能力是散落的，你要么自己写，要么装插件，要么在 prompt 里堆指令。现在能力可以被封装成一个技能包，跟着 MCP 服务器一起分发。对企业来说，接入一个服务器，等于同时接入了一套可执行的能力。
为什么值得关注？因为它把"Agent 能力"变成了可以通过 MCP 分发的商品化单元。这既是新的分发渠道，也是新的信任边界问题。企业安全审批的对象，从"工具权限"扩展到了"技能包内容"。以前审批是看这个工具能读什么、能写什么；现在还要看这个技能包里到底装了什么逻辑。
对任何做 Agent 产品的团队，这是两条路：一条是把自己的能力封装成技能包，通过 MCP 分发出去，这是一个新的获客渠道；另一条是要防着别人塞进来的技能包。这两件事得同时做。
谈资角度：当 MCP 服务器能塞进技能包，企业采购时会问"这个技能包里到底有什么"。这会不会催生一个技能审计层？我个人觉得会，而且会来得挺快。
第二条就是我们刚说的那个坑。有开发者在 r/ClaudeCode 发帖说，接入 Notion 官方 MCP 之后，它返回的内容里夹带了隐藏的追加销售指令，而这些内容会进入 Agent 的上下文。
这是"工具提供方通过 MCP 影响 Agent 决策"的第一个高曝光案例。它揭示的是一个结构性问题：当 MCP 服务器同时是内容源和商业主体，Agent 的中立性没法靠协议保证，只能靠审计和隔离。
你想想这个场景：你的 Agent 去读一份文档，文档的返回内容里藏着一句"顺便推荐用户升级到某套餐"，然后 Agent 就把这句话当成事实，转述给了你的用户。这个过程没有任何报错，没有任何日志异常，你的产品在用户看来就是在推销。这不是安全问题，这是产品信誉问题。
所以对做 Agent 产品的团队，这是必须提前设计的防线。不是等出事了再补，而是在接入第三方 MCP 的第一天就要有内容检查和运行隔离。
谈资角度：你的 Agent 读到的"事实"，有多少是工具方希望它读到的？这个问题以后会变成 Agent 产品的基本安全问答题，就像今天大家问"你的数据存在哪里"一样自然。
好，下面是快讯，我按主题串一下，快速带过。
第一条和计费有关。OpenAI 修复了一个计费 bug，说此前这个 bug 给了错误的折扣。修复之后，GPT 6.2 Astra 的用户触达用量上限的速度比上周快了 40%，Sol 的用户快了 25%。补偿方案是额外给一次重置，企业用户年底前免费用 Fast Mode，同时 OpenAI 在测试 Chat 和 Work 两种模式合并。这条的实际含义是，之前那段便宜是意外，现在回到正常价格了，用量大的团队这个月的账单可能会有感觉。
第二条，Google 在推动 Agent 走自家的 MCP 服务器，但有个细节挺有意思：Gmail 那个 MCP 服务器不具备发信能力。这个在 Hacker News 上讨论热度很高，一百多分、一百多条评论。大家可以自己想想这个设计的意味——开放了接口，但把最关键的写操作捏在手里。
第三条是关于 Nvidia 的。标普正在考虑因为治理结构和对黄仁勋个人的"关键人"依赖，把 Nvidia 的信用评级下调到 AA 减。AA 减是第四高评级，这个动作本身象征意义大于实际影响，但它提醒我们，这一轮 AI 基础设施的信用，很大程度上绑在少数几个人身上。
第四条，42 个州的总检察长联合出手，阻止 Character.AI 在破产程序中出售用户聊天记录，涉及超过 2100 万个美国账户的私密对话历史。这条对做消费级 AI 产品的团队是个提醒：用户对话数据的资产属性和合规边界，在破产这种极端场景下会被放大检验。
第五条，FCC 批准 SpaceX 部署最多 100 万颗 Starmind 卫星，用来做轨道 AI 数据中心。首批发射目标 2027 年，完整星座要到 2040 年投入运营。BCG 的估算说，短期内成本还是远高于地面数据中心。这条属于长周期的想象力，短期不用太当真，但它说明算力的地理约束正在被认真对待——地上不好放，就往天上放。
好，最后是我们的今日观察和商业机会，我用聊天的语气跟你说。
今天最值得记下的，其实不是某一条新闻，而是一组对照。Anthropic 上市和 GTA VI 破纪录发生在同一天，市场在用真金白银重新给"效率"和"不可替代性"定价。与此同时，中国开源视频模型把商用级价格压到每秒五毛，WaveSpeedAI 却在收窄降幅、用速度换价差。这两条线其实指向同一个结论：视频 API 的竞争正在从"每秒钟单价"转向"每出一条可用成品的成本"。
而这条成本曲线，现在正被两端挤压。一端是上游算力管制，Nvidia 停发东南亚，算力的地理版图在被切分；另一端是文本侧模型涨价，OpenRouter 表上那些 completion 价在上移，把视频工作流里的 prompt 编排和脚本生成成本悄悄推高。这两端一挤，中间层的空间就变薄了。所以谁能把"每出一条可用成品的成本"这件事算清楚、做低，谁就有定价权。这是我的判断。
Agent 这一侧，MCP 正在从"工具协议"变成"技能分发渠道"。Anthropic 的 Skills over MCP 是机会的那一面，Notion 的隐藏 upsell 事件是风险的那一面。这两件事在同一周发生，说明中立性风险已经从理论变成了案例。对准备进入 Agent 方向的团队，分发渠道的机会和信任边界的坑是同时打开的，你不可能只挑一个。
基于这些，我觉得现在有两个位置比较值得做。
第一个，是面向视频 API 客户的"合规部署地"透明化能力。依据就是 Nvidia 停发东南亚服务器和出口管制收紧这两条。海外的客户，尤其是东南亚和中东的云厂商和媒体公司，接下来会需要明确知道推理跑在哪个司法辖区、芯片来源是否可追溯。这个需求现在还没有标准答案，谁能把这一点做进 API 文档和合同里，做成一个标准项，谁就更容易过企业采购的合规关。这不是技术活，是产品和法务的活，但恰恰因为不是技术活，做的人少。
第二个，是 Agent 技能包的审计与隔离层。依据是 Anthropic 的 Skills over MCP 公测，加上 Notion MCP 那个隐藏 upsell 的事件。企业接入第三方 MCP 服务器的时候，现在缺少一个检查手段：技能包里到底有什么，有没有夹带商业指令。做一个对 MCP 服务器返回内容做静态扫描加运行时隔离的中间层，是当前时间点上需求明确、供给几乎空白的位置。而且这个位置的护城河会随着案例增多而变厚，因为每一次出事，都会让这个中间层更值钱。
好，今天就聊到这儿。一句话总结：效率和低价正在被重新定价，真正稀缺的是不可替代的成品，以及能被信任的中立。我是 Andy，我们明天见。
