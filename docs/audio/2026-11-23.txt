早上好，欢迎收听 Andy 的 AI 早报，今天是 2026 年 11 月 23 号，星期一。先报今天的这一句话：低价推理供应商，正在被证明是 API 分发生意里最脆弱的一环。安全公司 Dragos 用两百万次假请求，扒出了偷密钥、偷看请求内容的转售商，OpenRouter 随后一口气下架 3 家供应商、125 个端点。对所有做模型 API 聚合的人来说，这是一记关于供应链信任的警钟。
今天的内容，我给大家铺三条主线。第一条是信任和评测，除了刚才说的 Dragos，还有 METR 关于评测跟不上模型能力的警告，以及 GPT-6.2 Astra 在透明度上落后 Claude 这件事。第二条是价格结构的分化，WaveSpeedAI 又调价了，OpenRouter 上一批小模型反而在涨价。第三条是 Agent 的输入形态在变，Perplexity 出了个 Monitor API，Google 在 Gemini 里做了 Tool Retrieval。咱们一条一条来。
先看市场局势。今天最重的一条，就是 Dragos 这个事，我多说两句。Dragos 的做法是往 AI 推理链路里投放了两百万次伪造的请求，结果发现了至少 3 家被入侵的推理供应商、数百个被窃取的 AWS 密钥，还有一批所谓的转售商，实际上在直接读取客户的请求内容。你注意，这不是模型厂商自己的问题，是中间层的问题。OpenRouter 的反应也很快，直接移除了 3 家供应商和 125 个端点。
这件事说明什么？说明聚合平台的核心资产其实是信任，不是价格。过去两年大家拼的是谁路由得更便宜，可一旦低价路由被证明可能偷密钥、偷看 prompt，价格战就得让位给合规和审计能力。对做 API 分发的平台来说，供应商审计、请求隔离这些东西，以前被当成成本，现在应该当成卖点来做。这里给你一个谈资角度：如果你和做 API 聚合或者做视频平台的朋友聊到这件事，可以问他一句，你们怎么验证下游的推理供应商不读客户的 prompt？我跟你讲，多数人是答不上来的，这个问题一问，天就聊开了。
第二条，METR 发了一份报告，核心意思是模型能力的提升速度，已经快过专家测试它们的能力了。报告提到 Opus 5.5、GPT-6 Astra 这些前沿模型，在研究类任务上进步非常快，但越来越难测量。现有数据没法排除 AI 研发出现危险加速的可能。不过 METR 也提醒，常见的测试方法可能反而高估了模型的实际能力。
这条为什么值得关注？因为评测体系一旦跟不上能力，监管、企业采购、选型，都会转向自建评测加第三方审计。对模型 API 平台来说，评测的透明度和可复现的 benchmark，正在变成获客材料，而不是技术文档里的一个附录。你和创始人聊天的时候可以聊一句，你们内部评测还信公开 benchmark 吗？这是当下最真实的一种焦虑，问出来对方一般都有话说。
第三条还是模型层面。评测显示，GPT-6.2 Astra 和 Sol 的回答比前代更短、更直接，但同时也更不愿意承认自己不确定。而 Anthropic 的 Claude 在透明度上明显领先。这条的趋势意义在于，模型竞争正在从谁更强，分化成谁更可信、谁更适合放进生产环境。透明度差异会直接影响企业级的 API 选型，也正好给聚合平台做按任务类型路由提供了理由。谈资角度送你一个：你可以问创始人，你们更怕模型答错，还是更怕它不承认自己不确定？这个问题特别容易引出真话。
接下来是今天的重点，赛道深挖，这部分咱们讲透一点。
第一条，WaveSpeedAI 的价格页又调了。快照显示，原来两档单价降幅是 5%，现在扩大到了 10%。具体说，0.05 美元每秒那一档，从 0.0475 降到 0.045；0.075 美元每秒那一档，从 0.0713 降到 0.0675。但注意，降价的代价来了，两档对应的生成耗时从 21 秒和 14 秒，变成了 22.2 秒和 14.8 秒。
这是非常典型的以时间换价格。对视频生成 API 平台来说，它说明单位算力的成本压力还在，价格战已经打到延迟这个非价格维度上了。对下游的创作平台来说，选型的时候不能只看每秒单价，得把每秒单价乘上实际耗时一起算，才是真正的出片成本。这里可以问一句，你们客户更在意每秒单价，还是更在意从首帧到出片的实际等待时间？很多团队其实没算过这笔账，你一问，他回去就得重新算。
第二条，OpenRouter 的主力模型表上，六款模型同时调价，而且涨跌分化很明显。kimi-k3.1-pro 输入从每百万 token 0.253 美元降到 0.2403，输出从 8.8 降到 8.4023；qwen3.8-27b 输入从 0.06 降到 0.035，输出从 1.96 降到 1.5。但另一边，gemma-3-4b-it、gpt-oss-20b、qwen3.5-27b、qwen3.6-35b-a3b 这四款，是输入输出双向涨价。
同一张表上，开源小模型集体涨价，旗舰模型在降价，这说明什么？说明低价小模型的需求正在被 Agent 场景拉起来，而头部模型还在以价换量。对 API 平台来说，这意味着按场景分层定价，比全线最低价更现实。小模型涨价这件事，很多人还没注意到，你在饭桌上抛出来，特别容易接话。
第三条，Perplexity 推出了 Monitor API。它做的事情是把网页搜索变成按计划运行的监控：按计划去搜网页，用自己的判定模型过滤掉无关结果，只在出现相关变化的时候，通过 webhook 通知 Agent。这也是 Perplexity 在聊天机器人越来越同质化的情况下，转向开发者工具做差异化的一步。
这条对咱们听众特别重要，因为它改变的是 Agent 的输入模式，从主动调用变成被动接收事件。搜索从一次性查询，变成了常驻的触发器。对 API 平台来说，这类事件型 API 是比聊天补全粘性更高的分发形态，值得当成一个品类来盯着。谈资角度是，你可以问对方，你们的 Agent 是主动去查，还是等着被事件叫醒？这个问题背后其实是两种完全不同的架构。
好，进入 Agent 前沿。
第一条，Google 在 Gemini API 里预览了 Tool Retrieval。它解决的问题很具体：Agent 的工具一多，每个工具的参数 schema 都要塞进上下文，又贵又占地方。Tool Retrieval 让 Agent 把庞大的工具库挂在待命状态，只在需要的时候加载某个工具的参数 schema，而且整个过程在一次 Interactions API 请求里完成。
这为什么值得关注？因为工具数量一多，schema 就把上下文预算吃光了，这是 Agent 规模化最真实的瓶颈之一。Tool Retrieval 等于把工具选择本身变成了一个检索问题。对 API 平台来说，这是一个新的差异化维度。你可以和人聊，工具超过 50 个之后，你们怎么处理 schema 塞爆上下文？这个问题现在问，正当时。
第二条是一个实测，挺扎心的。有人把 AI 编程 Agent 放进一个模拟的开发岗位里，有同事、有项目看板、有不完整的交接，要求它们自主推进，并且可靠地关闭待办 ticket。结果呢，即便是 Opus 5.5 和 Astra，完整解决的任务也不到十分之一。模型能很快完成清晰、独立的指派，但一旦作为自主开发者，就会失去线索。
这条直接戳破了 Agent 能替代开发者的叙事。真正的缺口不在单点能力，而在长流程的状态管理和上下文交接。对做 Agent 产品的团队来说，这就是路线图优先级最直接的依据。谈资角度是，问一句，你们的 Agent 在被打断、交接之后，还能接回原来的任务吗？
下面是快讯，我按主题串一下，快速带过。
治理和监管这块，OpenAI 的首席科学家谈了怎么给 AI 发展限速，前提是大家先就怎么测速度达成一致，这其实和前面 METR 那条是一条线。硬件这边，NVIDIA 发布了 Alpamayo 2 Edge，一个 2B 级别的推理 VLA，在 DRIVE AGX Thor 上从像素到轨迹的延迟是 160 到 190 毫秒，端侧自动驾驶这条线还在往前走。
内容版权这块有个案例，《以撒的结合》的开发商从 Repentance Plus 里移除了 AI 音乐，原因是之前玩家发现 Suno 的元数据，然后在 Steam 上差评轰炸。工具链方面，Hugging Face 发布了 harness adapters，可以把模型适配到自己的 harness 上，提升性能、降低成本。开源侧，obra/superpowers 单日涨了 785 个 star，HKUDS 的 CLI-Anything 单日涨了 687 个 star，主打让所有软件 Agent 原生。
最后是今日观察和商业机会，咱们聊得随意一点。
今天最值得记的一条线，是信任与评测。推理供应链被扒出偷密钥、偷看请求，METR 又说评测跟不上能力，这两件事其实指向同一个结论：模型 API 生意的竞争重心，正在从价格和模型数量，转向可审计、可复现、可解释。第二条线是价格结构在分化，WaveSpeedAI 用延迟换降价，OpenRouter 上小模型涨价、旗舰降价，说明单一的低价叙事已经撑不住了。第三条线是 Agent 的输入形态在变，Perplexity 的 webhook 触发和 Gemini 的 Tool Retrieval，都在把 Agent 从主动调用推向事件驱动加按需加载。这三条线合起来，就是 API 平台从卖 token 转向卖可靠性和编排能力的过渡期。
商业机会我看两个。第一个，是面向视频生成 API 的供应商审计和请求隔离能力。Dragos 这件事已经证明低价路由存在偷密钥、读 prompt 的风险，而视频生成的客户往往要上传原始素材，敏感度更高。谁先把请求不落地、供应商可审计做成能展示的合规卖点，谁就能吃到对安全敏感的企业客户和创作平台。这个依据就是今天 Dragos 和 OpenRouter 下架这条新闻。
第二个，是按每秒单价乘实际耗时来打包的视频生成定价和路由层。WaveSpeedAI 降价伴随延迟上升，说明客户真正关心的是出片总成本，不是标价。做一个按任务类型、时长、画质自动选供应商和档位的路由层，把延迟和价格一起优化，对中小创作平台来说是刚需。依据就是 WaveSpeedAI 价格页这次的变动。
好，今天就聊到这儿。一句话总结：模型 API 的竞争，正在从谁更便宜，变成谁更可信、谁更会编排。感谢收听 Andy 的 AI 早报，我们明天见。
