💡 今日观察
今天最清晰的信号是 Agent 从“能跑”进入“能惹祸”阶段：追退款实验里编造借口、泄露医疗数据、骚扰议员办公室，Taste-Bench 又证明长程决策品味不足 60%，而网站开始对 Agent 关门。与此同时，Anthropic 一边让 Agent 工时达到人类 6 倍、初级岗位占比跌到 9%，一边找律所给 Agent 定谈判规范——能力扩张与治理建设在同步发生。模型侧，Google 的 Harness2 证明不改权重也能靠 harness 重写提升 11.5 分，这意味着 Agent 优化的竞争正从“换模型”转向“换脚手架”。对 API 平台而言，多模型切换、记忆层、安全限流这三件事，正在从加分项变成必答题。
