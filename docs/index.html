🌐 市场局势

Dragos 用 200 万次假请求揭出 AI 推理供应链漏洞，OpenRouter 下架 3 家供应商、125 个端点
安全公司 Dragos 通过投放两百万次伪造 AI 请求，发现至少 3 家被入侵的推理供应商、数百个被窃取的 AWS 密钥，以及一批"转售商"实际上在直接读取客户的请求内容。OpenRouter 随后移除了 3 家供应商和 125 个端点。
💼 问对方"你们怎么验证下游推理供应商不读客户 prompt？"，多数人会答不上来。
★★★★★ 聚合平台的核心资产是"信任"，一旦低价路由被证明可能偷密钥、偷看 prompt，价格战就会让位于合规与审计能力。对做 API 分发的平台，这意味着要尽早把供应商审计、请求隔离做成卖点而非成本。

💡 Today's Take

🎯 Low-cost inference providers are proving to be the most fragile link in the API distribution business — Dragos used two million fake requests to expose resellers stealing keys and snooping on requests, and OpenRouter delisted 3 providers and 125 endpoints in one go. This is a supply-chain trust wake-up call for anyone doing model API aggregation. The thread most worth noting today is "trust and evaluation": the inference supply chain was caught stealing keys and snooping on requests, and METR says evaluations can't keep up with capabilities—both point to the same conclusion: the competitive focus of the model API business is shifting from "price and number of models" to "auditable, reproducible, explainable." The second thread is the diverging price structure: WaveSpeedAI trades latency for lower prices, while on OpenRouter small models go up in price and flagships go down, showing that a single low-price narrative can no longer hold. The third thread is the changing input form of Agents: Perplexity Monitor's webhook triggers and Gemini's Tool Retrieval are both pushing Agents from "active invocation" toward "event-driven + on-demand loading." Together, these three threads mark a transition period in which API platforms move from "selling tokens" to "selling reliability and orchestration capability."

💰 Opportunities

  • "Vendor auditing and request isolation" capability for video generation APIs: The Dragos incident proves that low-price routing carries the risk of stolen keys and prompt reading, while video generation customers often upload raw footage, making sensitivity even higher. Whoever first turns "requests never land, vendors are auditable" into a demonstrable compliance selling point can win security-sensitive enterprise and creator platform customers. Basis: the Dragos / OpenRouter delisting incident.
  • A video generation pricing and routing layer packaged as "per-second unit price × actual elapsed time": WaveSpeedAI's price cuts came with higher latency, showing that customers really care about "total cost per finished video" rather than the list price. Building a routing layer that automatically selects vendors and tiers by task type, duration, and quality—optimizing latency and price together—is a must-have for small and mid-sized creator platforms. Basis: changes on the WaveSpeedAI pricing page.
