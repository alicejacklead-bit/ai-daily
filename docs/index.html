💡 今日观察

今天最硬的信号是价格：GPT-6.1 Terra 把中端 API 价格砍半还拿到 48 分，配合 Meta 950 亿美元增发、SpaceX 400 亿 GPU 融资，说明推理供给还在猛加，中端价位会持续被压。第二条线是 Agent 的"围墙"开始出现——The RealReal 直接封 Agent，而 Kolab 论文指出人类真正需要的是可中途改计划的协作，不是全自动。第三条是安全与溯源成为新基建：NVIDIA SkillSpector、OS 级包防火墙、以及"Git 记录不了 AI 贡献"的研究，指向同一个缺口。内容侧则相反：AI 长片票房遇冷，但短剧剧本、设计交付、社媒排期这些短周期场景在快速成熟。

💰 商业机会

  • 面向做 Agent 电商的团队：商家开始封 Agent（The RealReal 一条），需要一个"跨商家可用性探测 + 自动降级到人工/开放接口"的路由层，现在做正卡在需求爆发前。
  • 面向高校实验室与投稿作者：PaperFormalizer 证明 Lean 形式化可以接进写作流程，而期刊/资助方已在要求 AI 披露（What Git Does Not Record），可做"投稿前 AI 贡献审计 + 形式化自检"的订阅工具。
  • 面向非英语市场的 API 转售/聚合商：分词器税被量化后，统一美元定价在高 token 语言上会亏，可做按语言分档的定价与配额产品，把成本差异转成定价优势。

🧭 研究建议

  • 亲手复现 Token Collapse：拿 G-Retriever 在三个小图上跑一遍，确认软提示 token 塌缩是否在你的数据上出现，再决定知识图谱方案要不要换。
  • 试 MultiAgent-OPD 的联合训练思路：用一个小 Leader + 两个子 Agent 做蒸馏对比实验，看端到端训练相比手工编排在成本和成功率上的实际差距。
  • 用 RoboJudge-Bench 给手上任意一个视频生成模型打一次分，重点看物理合理性与指令忠实度的分歧点，这比看 demo 更能判断能否进生产。

💡 Today's Take

Today's hardest signal is price: GPT-6.1 Terra halved mid-tier API pricing while scoring 48, and together with Meta's $95 billion share issuance and SpaceX's $40 billion GPU financing, it shows inference supply is still ramping hard and mid-tier pricing will keep getting squeezed. The second thread is the emergence of Agent "walls"—The RealReal outright bans Agents, while the Kolab paper points out that what people really need is collaboration where plans can be changed mid-course, not full automation. The third is that safety and provenance are becoming new infrastructure: NVIDIA SkillSpector, OS-level package firewalls, and the research showing "Git cannot record AI contributions" all point to the same gap. The content side is the opposite: AI feature films are flopping at the box office, but short-cycle scenarios like short-drama scripts, design delivery, and social media scheduling are maturing fast.

💰 Opportunities

  • For teams building Agent commerce: merchants are starting to block Agents (the RealReal item), creating a need for a routing layer that "probes cross-merchant availability + automatically degrades to human/open APIs"—building it now lands right before demand explodes.
  • For university labs and submitting authors: PaperFormalizer proves Lean formalization can plug into the writing workflow, and journals/funders are already requiring AI disclosure (What Git Does Not Record), so a subscription tool for "pre-submission AI contribution audit + formalization self-check" is viable.
  • For API resellers/aggregators in non-English markets: now that the tokenizer tax has been quantified, uniform USD pricing loses money on high-token languages, so language-tiered pricing and quota products can turn cost differences into a pricing advantage.

🧭 Worth Exploring

  • Reproduce Token Collapse yourself: run G-Retriever on three small graphs to confirm whether soft-prompt token collapse occurs on your data, then decide whether to change your knowledge graph approach.
  • Try MultiAgent-OPD's joint training idea: run a distillation comparison experiment with one small Leader + two sub-Agents to see the real gap between end-to-end training and manual orchestration in cost and success rate.
  • Score any video generation model you have with RoboJudge-Bench once, focusing on where physical plausibility and instruction faithfulness diverge—this tells you more about production readiness than watching demos.
