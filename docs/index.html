🌐 市场局势

Anthropic IPO 定价 $83/股，估值 $1.5 万亿
Anthropic 于 11 月 18 日正式为 IPO 定价，A 类普通股每股 $83，高于此前预期区间，按完全稀释口径估值 $1.5 万亿。官方新闻稿由 Anthropic 自己发布，AP、WSJ、TechCrunch 均同步报道。
💼 可以问对方——当模型公司变成上市公司，它还会为了抢 API 份额继续降价吗？
★★★★★ 前沿模型公司第一次以万亿级估值进入公开市场，意味着模型公司的估值锚从"私募叙事"转为"公开市场定价"，此后所有 AI 公司的融资和估值都要参照这个基准，API 平台的采购成本与供应商稳定性也会被资本市场重新审视。
Anthropic · AP · WSJ · TechCrunch
Google 一个月内发第四款 Gemini：Gemini 4 Neon，$3/$15 定价高于前代
Gemini 4 Neon 定位软件开发、知识工作与科研，支持文本、图像、视频、音频与 PDF，上下文窗口 100 万 token，定价为每百万输入 token $3、输出 $15，高于此前 Gemini 4 系列。HN 上讨论热度 391 分。
💼 一个月发四款模型，是能力真的在加速，还是发布节奏在抢 IPO 窗口的注意力？
★★★★☆ Google 用"一月四款"的节奏把前沿模型变成快消品，但 Neon 定价上探说明能力分层正在变成价格分层——便宜档留给 Flash 类模型，前沿能力单独溢价，这对聚合平台的模型选型和成本结构是直接冲击。
The Decoder · Google DeepMind · Hacker News
微软自研 MAI 七款模型替换外部模型，Code 2 以 40% 成本达到 GPT-6.1 Sol 的 98%
微软 AI 部门 MAI 在 Ignite 上发布覆盖代码、安全、图像、语言与路由的七款模型，官方称 MAI Code 2 达到 GPT-6.1 Sol 98% 的性能、成本仅 40%，目标是在企业里 7×24 跑 Agent。
💼 如果微软这类大客户都自研，独立模型 API 平台的长期客户到底是谁？
★★★★☆ 最大的模型买家开始用自研替换外部采购，这是"模型商品化"最明确的信号——当分发方自己造模型，纯模型 API 供应商的议价权会被持续压缩，平台型公司必须靠多模型聚合和场景绑定建立护城河。

🎬 赛道深挖

Hugging Face 把模型请求全部路由到 OpenRouter，自带 API Key 模式取消
Hugging Face 现在通过 OpenRouter 路由语言模型请求，由 OpenRouter 自动选择最便宜或最快的供应商；面向语言模型的 bring-your-own API key 模式将下线。据 OpenRouter 数据，新路由把容量错误降低了 46%。两家公司都面临数十亿美元级别的收购。
💼 当路由自动选最便宜的供应商，模型平台还剩下什么差异化——延迟、稳定性，还是独占模型？
★★★★★ 这是分发渠道的一次结构性合并——开源模型最大的入口和最主流的聚合路由合成一条链路，独立 API 平台若不在价格或延迟上有硬优势，会被自动路由直接跳过；同时"BYO key"模式退场，说明聚合层正在收拢定价权。

★★★★☆ 视频生成 API 的价格战从"整数档"进入"个位数百分比"的精细下调阶段，且图像侧开始用 4.0 新模型替换旧模型档位——说明供给端在按模型代际重排价格带，平台若不跟进重算毛利，很容易被单边挤压。

💡 Today's Take

🎯 Anthropic completes IPO pricing at $83/share and a $1.5 trillion valuation, marking the peak of frontier-model capitalization; on the same day, DeepSeek V4.1 Flash's input price on OpenRouter rises 5.9x—compute costs are shifting from "model companies burning cash on subsidies" to "API callers footing the bill." What's most noteworthy today isn't Anthropic's $1.5 trillion, but two "downstream" events that happened on the same day: Hugging Face handing all model requests over to OpenRouter for routing, and Microsoft replacing externally procured models with in-house ones. The upstream is capitalizing, the downstream is consolidating and building in-house, and the independent model API platforms in the middle layer are being squeezed from both sides. WaveSpeedAI's fine-grained 5%–10% price cuts precisely show that video APIs have entered a attrition phase of "rearranging price bands by generation"—only whoever gets the launch slot for a new model has pricing power. The two items on the Agent side today (the framework supply chain being hijacked, and the multi-Agent coordination benchmark) point to the same thing: this direction is shifting from "can it run" to "can it be trusted and measured."

  • A "short-clip video inference" tier for consumer-facing creation platforms: Demand for things like Suno Visuals' "song → lip-synced short video" is high-frequency, short-duration, and low-unit-price, while existing video APIs mostly focus on long clips billed by the second. Based on Suno Visuals' launch and WaveSpeedAI's -10% video tier price cut trend, one could start with a lightweight tier billed by "number of clips + resolution" to serve music, podcast, and social tool customers.
