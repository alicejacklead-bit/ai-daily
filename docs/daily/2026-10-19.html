💡 今日观察

今天最清晰的信号是 Agent 从“能不能做”转向“做得对不对、贵不贵”：Anthropic 停止招初级员工的实证、465 美元退款实验的失控、Taste-Bench 的低正确率，三件事共同说明 Agent 已进入真实业务但可靠性仍是短板。与此同时，Harness2、LEASH、MAI-Gym、FDE-Gym 等一批“不重训模型、只优化 harness 与环境”的工作集中出现，说明推理侧工程化正成为新的竞争焦点。视频生成侧，EdenLive 把实时世界模型压到消费级显卡，ForcingBooster 与 Gen4P 则分别从加速和复用角度降低成本，生成类 API 的单价还有下探空间。监管上，德国法院判 Google 为 AI 回答负责、Anthropic 高门槛安全法案、Meta 抓取条款争议，三条线都在收紧“AI 输出即公司内容”的责任边界。

💰 商业机会

  • 面向企业客服与退款场景的“Agent 行为护栏”中间件：今天 465 美元退款实验暴露了消息轰炸、敏感信息泄露、编造借口三类失控，而 Anthropic 正在与律所制定谈判规范。现在做一层可插拔的频率限制、敏感信息过滤与人工升级网关，卖给已部署客服 Agent 的企业，时机正好。
  • 基于 Harness2 / LEASH 的“Agent 推理优化即服务”：两者都证明不改权重即可显著提升 Agent 表现或降低成本（Harness2 单步 +11.5 分，LEASH 做弱到强升级）。对预算敏感的中小 Agent 团队，提供托管式 harness 调优与模型分级调度，按节省的 token 分成。
  • 为 API 平台做 ChatGPT 插件与 Claude Code 插件双分发：Stack Overflow for Agents 靠 ChatGPT 插件实现最高 10 倍 Agent 创建增长，Anthropic 官方插件目录也在扩张。把平台的模型能力封装成两个生态的插件，是当下最低成本的开发者获客路径。

🧭 研究建议

  • 亲手复现 LEASH 的弱到强升级逻辑：用一个小的开源模型做默认执行、一个前沿模型做升级，在 GUI 任务上测不确定性阈值对成本与成功率的影响，判断是否值得接入自家 CUA 产品。
  • 精读并跑通 Harness2 的测试时 harness 重写：在 WorkBuddy-Bench 或自有任务集上验证“单次精炼提升 11.5 分”是否可复现，重点看它对不同基座模型（GLM-5 之外）的泛化性。
  • 用 FDE-Gym 的 95 个交付任务对现有 Agent 做一次压力测试，特别关注“澄清模糊需求”和“发现未声明约束”两类子任务，这往往是企业交付失败的真正原因，也是产品差异化的切入点。
