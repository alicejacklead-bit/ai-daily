## 📄 重要论文

- **Training the Whole Agent, Not Just the Model（HarnessAdapt-RL）**：在 RL 训练中同时训练策略并自适应调整 agent harness——针对修复策略缺陷由冻结教师生成任务级机制技能，针对跨任务交互问题由独立教师建模。
  - 重要性：★★★★★ / 5
  - 核心价值：把 harness 纳入训练目标，coding agent 训练范式的一次结构性改动。
  - 应用价值：自训 coding agent 时把工具调用与修复流程参数化，作为可学习变量。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.28069)

- **Self-Credit：用组内重缩放为长程 Agentic RL 做信用分配**：从稀疏结果奖励中通过自生成摘要（带对早期步骤的引用）构造稠密监督信号。
  - 重要性：★★★★★ / 5
  - 核心价值：长程任务的稀疏奖励难题有了端到端解法，无需额外标注。
  - 应用价值：多步 Agent 训练可先接 Self-Credit，替代人工 reward shaping。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.28388)

- **EAU：环境—Agent—用户协同进化，训练以用户为中心的 Agent**：指出用户模拟器随机性与工具不可靠是训练不稳定主因，主张三者共同演化而非只做 reward shaping。
  - 重要性：★★★★★ / 5
  - 核心价值：多轮对话 Agent 的训练信号来源被重新定义。
  - 应用价值：客服/销售 Agent 训练时同步迭代用户模拟器，避免过拟合固定脚本。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.16523)

- **Evolving Agent Interfaces（Agent S4）**：主张界面设计本身应成为 Agent 能力，让 computer-use agent 自主构建并选择接口，而非沿用人类界面。
  - 重要性：★★★★★ / 5
  - 核心价值：Agent 效率瓶颈从模型转向界面，可能催生“为 Agent 设计的产品”。
  - 应用价值：为自家 SaaS 提供 Agent 专用接口（批量 API 而非逐格点击），抢占接入位。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.28601)

- **Muse Glimmer 30B：开源端侧 Agentic 模型**：30B 因果 LM + 感知编码器，支持文本与图像输入，主打多步推理、可靠工具调用与失败恢复，量化后可在消费级设备本地运行。
  - 重要性：★★★★★ / 5
  - 核心价值：端侧 Agent 有了专门设计的开源权重，隐私敏感场景可行。
  - 应用价值：可在本地设备跑工具调用 demo，验证离线 Agent 的产品形态。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.24628)

- **PVBench：用物体级物理测量量化视频生成的真实性**：覆盖 46 个维度，检验生成物体是否遵守几何、运动学、动力学与守恒律，区别于粗粒度 VLM 打分。
  - 重要性：★★★★★ / 5
  - 核心价值：视频生成评测从“好看”转向“物理可信”，给模型对比提供硬指标。
  - 应用价值：视频生成产品可用 PVBench 维度做对外评测页，替代主观 demo 展示。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.26711)

- **Joints, Camera, Action! 为任意骨骼共生成 3D 运动与视频**：视频模型能生成逼真动作，但无法把动作回放为可复用的 3D 运动；该工作直接共生成视频、3D 运动与配准相机。
  - 重要性：★★★★★ / 5
  - 核心价值：视频生成与 3D 资产管线打通，动画与游戏工作流受益最大。
  - 应用价值：动画/游戏客户可做“视频→可回放 3D 动作”的增值功能预研。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.28632)

- **SpecKCast：用谱卡尔曼预测加速扩散模型推理**：针对 DiT 在去噪步间的特征外推，指出既有方法对空间频率不同的特征统一外推是次优的。
  - 重要性：★★★★★ / 5
  - 核心价值：图像/视频生成的推理成本有望进一步下探，直接影响 API 定价空间。
  - 应用价值：自建视频生成服务可评估特征缓存+预测组合，压低单条视频成本。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.26837)

- **On the Limits of Scale：视觉语言模型存在逆缩放**：跨 4 个模型家族 19 个模型、8 个多模态 benchmark，发现同一家族内更大模型在特定子任务上反而更差。
  - 重要性：★★★★★ / 5
  - 核心价值：选型不能只看总榜，子任务级别可能出现规模越大越差。
  - 应用价值：做多模态选型时按业务子任务自建小评测集，而非依赖聚合榜单。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.27360)

- **Specter：量化 + 多步投机卸载，实现快速 MoE 推理**：用轻量量化 draft 模型在设备侧保持高保真专家激活模式，缓解 PCIe I/O 瓶颈。
  - 重要性：★★★★★ / 5
  - 核心价值：单卡跑大 MoE 的可行路径，直接关系到自托管成本。
  - 应用价值：显存不足的团队可用其思路评估“量化 draft + 专家卸载”组合。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2511.14102)

- **Épi：可持续、自我改进的自主研究 Agent**：结合持久研究历史、分层记忆、分支与独立评审，跨 session 延续实验，由固定 verifier 评估，已产出 120 项记录性结果。
  - 重要性：★★★★★ / 5
  - 核心价值：自主科研 Agent 的记忆与评审结构可复用，不止于 demo。
  - 应用价值：可借鉴其“固定 verifier + 分支探索”结构做内部实验自动化。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.24944)

- **AEON：统一视频与 3D 世界模型**：视频生成模型外观真实但 3D 不一致，3D 生成模型几何一致但静态不真实，AEON 试图兼得两者。
  - 重要性：★★★★★ / 5
  - 核心价值：世界模型的两条路线开始合流，是长期基础设施级方向。
  - 应用价值：做 3D/场景生成产品的团队应跟踪其开源进展与可复现性。
  - 来源：[arXiv](https://arxiv.org/abs/2610.28631v1)
