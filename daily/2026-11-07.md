### 商业机会
- **面向视频生成 API 的"batch/非实时"定价层**：OpenRouter 今天在文本侧密集上线 batch 档位，而视频生成天生是长任务、天然可异步。依据 OpenRouter 模型表新增 deepseek-v4-flash-0731:batch、minimax-m3:batch、qwen3.8-27b:batch 等条目，做视频 API 的平台可以率先把"标准/批量/预览"三档拆开，抢在聚合平台之前定义视频侧的定价结构。
