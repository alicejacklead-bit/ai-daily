## 📄 重要论文

- **Kolab：长时程工作中人机协作的基准**：指出人类在长任务中更看重"持续交互与改计划"而非 Agent 一次做对，而现有 Agent benchmark 几乎只测自动化。
  - 重要性：★★★★★ / 5
  - 核心价值：为"协作型 Agent"提供评测口径，纠正只追自动化分数的偏差。
  - 应用价值：产品侧把"中途可改计划"做成显性功能，并用 Kolab 指标对外证明。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.21109)

- **PaperFormalizer：作者在环的论文 Lean 形式化**：从 LaTeX 源码出发构建陈述依赖图，逐条审查忠实性/歧义/正确性，再形式化并证明，帮作者补上证明漏洞。
  - 重要性：★★★★★ / 5
  - 核心价值：把形式化验证接进真实写作流程，而非事后重写。
  - 应用价值：可做"论文投稿前自检"工具，面向高校与实验室按篇收费。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.31810)

- **Speculative Diffusion is a Tale of Two Tradeoffs**：对比投机解码的"无损"与扩散 LLM 通过降质换速度的"有损"加速，厘清两条加速路线的取舍。
  - 重要性：★★★★★ / 5
  - 核心价值：为扩散 LLM 的推理加速提供理论边界，选型时不再混用两套假设。
  - 应用价值：推理服务按任务容忍度分别配置无损/有损加速档位。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.31819)

- **MultiAgent-OPD：分层多 Agent 系统的端到端训练**：把 on-policy 蒸馏与强化学习结合，联合训练共享参数的 Leader 与子 Agent，缓解最终答案对子 Agent 反馈间接的问题。
  - 重要性：★★★★★ / 5
  - 核心价值：多 Agent 从"手工编排"走向"可联合训练"，工程范式可能切换。
  - 应用价值：在自建 Agent 编排层里先试蒸馏小模型替代子 Agent，压推理成本。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.23234)

- **DraMaze：面向微短剧剧本的多 Agent 生成流水线**：用未来感知记忆缓解剧情机制收敛与套路复用，兼顾多样性与长程连贯。
  - 重要性：★★★★★ / 5
  - 核心价值：短剧是 AI 内容变现最快的品类之一，此工作直击"越写越像"的痛点。
  - 应用价值：短剧/短视频团队可直接借鉴其记忆结构做分集大纲生成。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.32002)

- **RoboJudge：用多模态模型给具身视频生成当裁判**：构建 RoboJudge-Bench，系统评估 MLLM 判断与人类在物理合理性与指令忠实度上的一致性。
  - 重要性：★★★★★ / 5
  - 核心价值：视频生成进入"可自动打分"阶段，评测从主观走向可复现。
  - 应用价值：视频生成产品内置自动质检分，作为交付前的质量门禁。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.27782)

- **SliderEdit++：让图像编辑的滑杆真正连续可控**：提出 SlideBench 系统研究滑杆跳变与非单调问题，改进滑杆轨迹，减少多滑杆互相干扰。
  - 重要性：★★★★★ / 5
  - 核心价值：细粒度可控性是图像编辑工具从"玩具"到"生产力"的关键。
  - 应用价值：图像编辑产品把"强度滑杆"做成核心交互并公开对比 demo。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.14253)

- **MMVistaReason：多模态推理的开放数据后训练配方**：针对数据质量不均、监督构造低效、难度失衡与跨域干扰，给出覆盖分析型与真实场景推理的开放后训练方案。
  - 重要性：★★★★★ / 5
  - 核心价值：开源多模态推理有了可复现的后训练 recipe，降低追赶门槛。
  - 应用价值：中小团队可基于此配方微调自有垂类多模态模型，省去数据摸索。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.01352)

- **On-Policy Self-Training：无数据的模型自我改进**：仅靠粗粒度主题描述驱动自生成问答与特权推理示范，摆脱对真实 QA 对与人工题集的依赖。
  - 重要性：★★★★★ / 5
  - 核心价值：后训练的数据门槛进一步降低，小团队也能做自我进化。
  - 应用价值：用自家产品日志的主题标签做无标注自训练实验，验证增益。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.32770)

- **What Git Does Not Record：AI 辅助研究的溯源可读性**：审计两个同一作者、同一领域的仓库，发现 Agent 留下的规则文件与草稿痕迹无法回答"AI 到底贡献了什么"。
  - 重要性：★★★★★ / 5
  - 核心价值：AI 使用披露要求正在落地，但现有工程记录体系答不上来。
  - 应用价值：做"AI 贡献审计"插件，自动记录 Agent 改动供投稿/合规使用。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.28655)

- **Token Collapse：文本图软提示的病理行为**：深入分析 G-Retriever，在三个 benchmark、三个 GNN 上发现图软提示 token 塌缩，削弱图结构注入效果。
  - 重要性：★★★★★ / 5
  - 核心价值：图 + LLM 的主流方案存在系统性缺陷，选型前需重新验证。
  - 应用价值：知识图谱类产品先做小规模复现测试，别直接照搬 G-Retriever。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.31572)

- **FocusVLA：用未来意图引导动态视角路由**：发现现有 VLA 模型未充分利用多视角互补性，策略倾向固定视角，提出按未来意图动态路由视角。
  - 重要性：★★★★★ / 5
  - 核心价值：多视角输入从"全喂"转向"按需选"，直接省算力。
  - 应用价值：机器人/具身产品在推理端做视角裁剪，降低单步延迟。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.31423)

- **FLORA：扩展机器人数据引擎的开放模型套件**：同时覆盖结果奖励、过程奖励与带时间戳描述，用于 GR00T 训练，在 WGO-Bench 与奖励基准上达 SOTA。
  - 重要性：★★★★★ / 5
  - 核心价值：机器人数据标注从零散工具走向工业级统一引擎。
  - 应用价值：具身团队可复用其标注口径，减少自建数据管线的重复投入。
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.31779)
