### 今日观察
今天最清晰的信号是"Harness 层正在独立成层"：Factory Droid 1.0 主打模型无关，Vercel 的 agent-desktop 用无障碍树替代像素，EasyProver 靠 Agent 编排而非训练就逼近基准饱和——能力增量越来越多来自外壳而非底座。与之呼应的是供给侧收紧：Anthropic 一边扩水印一边留漏洞，一边封禁"触及训练更大模型"的账号，模型 API 的"用途合规风险"首次成为选型变量。融资端，OpenAI 只募到目标的三分之一，意味着补贴与价格战的持续性要打折，而 Agent Sandbox 每天千万次创建说明需求侧仍在加速。一句话：需求在涨、供给在收紧、资本在退潮，中间层的工程能力是最确定的套利空间。

### 商业机会
- **多模型路由与合规隔离层**：Anthropic 封禁"触及训练更大模型"账号、Claude 拦截游戏逆向、水印可绕过，说明企业需要一个统一网关来做用途分流、账号隔离与输出溯源。依据：Anthropic 封号与游戏逆向拦截两条新闻。
- **Agent 沙箱的托管服务**：Agent Sandbox 每天上千万次创建、冷启动成为新瓶颈，中小团队自建隔离环境成本高。可做"按次计费的安全执行环境"，主打低时延与快照恢复。依据：InfoQ Agent Sandbox 报道与 Vercel agent-desktop 开源。
- **"每通过任务成本"基准服务**：Factory 用 4.73 美元/通过任务来定义编码 Agent 性价比，但市面上缺横向可比数据。可做第三方评测，按任务类型给出成本-成功率曲线，卖给做 Agent 选型的企业。依据：Factory Droid 1.0 与 Terminal-Bench 4 数据。

### 研究建议
